# Batch 4 功能角色分析：模拟经营 / 工程反馈 / 瓶颈升级

## 批次概览

Batch 4 涵盖 12 款模拟经营/工程反馈类游戏。与 Batch 3 的「少资源高压 RTS」截然不同，此批次的核心是「生产链/瓶颈诊断/系统可视化」。资源种类多（5-20+种），但不以种类复杂度为卖点——而是以「玩家能看见系统哪里坏了」为核心乐趣。

## 1. Factorio

**角色分布（估算）**：P:10% / C:35% / S:30% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 电力采矿机 | **P** | 矿脉→矿物（铁/铜/煤/石/铀），从环境提取，净产出为正 |
| 抽油机/水泵 | **P** | 油田→原油、水域→水，无限或有限速率的环境产出 |
| 石炉/钢炉/电炉 | **C** | 矿物→板材（1:1转化），核心冶炼转化 |
| 组装机 I/II/III | **C** | 多种原料→成品（齿轮/电路/科学包等），最核心的转化节点 |
| 化工厂/炼油厂 | **C** | 流体→流体（原油→石油气/轻油/重油），多产出分流管理的 C |
| 离心机 | **C** | 铀矿→铀-235/铀-238，概率性分选转化 |
| 传送带/机械臂/管道/火车/机器人 | **S** | 物流系统！不产不转资源，但决定资源的流速和可达性——Factorio 的 S 占绝对核心 |
| 电线杆/变电站 | **S** | 电力网络覆盖，解锁机器的空间可达性 |
| 信标+插件 | **S** | 不改变资源流方向，但乘法级提升相邻机器的转化效率 |
| 实验室 | **K** | 消耗科学包→研究进度→解锁科技，经典 K（吃资源换系统能力） |
| 炮塔/城墙 | **K** | 消耗弹药/能量→消灭虫族，吃资源换防御状态 |
| 火箭发射井 | **T** | 消耗火箭部件+卫星→发射=通关，资源的终极消费归宿 |

**角色特征**：**C+S 双极高（35%+30%=65%）**。Factorio 本质是一个「转化网络绑定在物流支持系统上」的游戏。P 极少（只需采矿机和水泵），K 和 T 都是辅助角色。真正的主角是——「这根铁板传送带为什么慢了？」玩家90%的时间在处理 C 的瓶颈和 S 的布局。

**可迁移洞察**：不要照搬流水线，但必须迁移「瓶颈自生成目标」的机制。文明 Roguelite 的「瓶颈 overlay」可以让玩家看到——信仰流动在哪个节点卡住了？哪个路线是最弱环节？玩家的治理目标不由任务列表给出，而由瓶颈自然浮现。

## 2. Oxygen Not Included

**角色分布（估算）**：P:10% / C:35% / S:35% / K:10% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 藻类制氧机 | **C** | 藻类→O₂，消耗藻类产出氧气（藻类从环境采集→P，制氧机本身是C） |
| 电解器 | **C** | H₂O→O₂+H₂，水和电→氧气+副产物氢气 |
| 人力/煤炭/天然气/氢气/石油发电机 | **C→P 边界** | 燃料→电力，形态转化——但电力是其他C的输入，本质是**C** |
| 蒸汽涡轮机 | **C** | 高温→电力（热量→电力，废热回收），判**C** |
| 太阳能板 | **P** | 光照→电力，无需输入的直接环境产出，判**P** |
| 种植箱/水培砖 | **C** | 水/泥土/光→作物（卡路里），转化效率取决于温度窗口 |
| 电烤架/燃气灶 | **C** | 生食→熟食（卡路里+士气加成），品质升级的 C |
| 水泵/气泵/管道/通风口 | **S** | 流体传输网络，不产不转但决定所有物质的流向和速率 |
| 筛水器/脱盐器 | **C** | 污染水→净水（污染转化），ONI 物质循环闭环的关键 C |
| 液冷器/空调 | **S** | 温度管理——不产不转资源，但控制系统运行条件（温度窗口），纯 **S** |
| 自动化传感器/开关/逻辑线 | **S** | 减少手工干预，提高系统效率和可靠性 |
| 研究台→超级计算机→虚拟天象仪 | **K** | 消耗资源（水/泥土/数据磁盘）→研究点数→解锁科技 |
| 时空裂隙/火箭 | **T** | 终局出口——复制人离开小行星=通关 |

**角色特征**：**C+S 双极高（35%+35%=70%），S 权重为全批次最高**。ONI 即使去掉管道/自动化也能运行——但 S 的高比率来自「系统滞后性」设计：温度 invisible-rising、CO₂ 下沉、病菌扩散都需要 S 层（温度 overlay、气体管道、隔离墙）来可视化和管理。没有 S 的建筑 = 玩家看不见系统危机 = 没有诊断乐趣。

**可迁移洞察**：文明演化项目最该迁移 ONI 的不是液体管道，而是 **overlay 层**。文明的隐性变量——合法性流失、阶层怨气累积、符文污染扩散、信仰裂解、心灵噪声——必须做成可切换的 overlay（热力图/流向图），让玩家「看见看不见的危机」。S 类建筑的文明类比 = 文明诊断工具和可视化面板。

## 3. RimWorld

**角色分布（估算）**：P:20% / C:25% / S:30% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 种植区/水培盆 | **P** | 土壤/光照→植物生食，从环境产出 |
| 采矿/深钻 | **P** | 山体/地下→钢铁/零部件/石材，有限但有深度 |
| 屠宰台 | **C** | 动物尸体→肉+皮（分类分解），经典 C |
| 炉灶/营养膏合成机 | **C** | 生食→熟食/营养膏，品质转化的 C |
| 裁缝台/锻造台/机械加工台/装配台 | **C** | 原料→装备/武器/零件，工作台级的转化链 |
| 药物实验室 | **C** | 草药→药品→高级义肢，加工链 |
| 雕塑台 | **C→S 边界** | 原材料→雕塑（艺术品），产出的是「美观度」——一种不直接参与资源流的（状态量）→虽然美观度影响殖民者心情→心情影响工作效率→但雕塑本身是转化而非消耗→判**C** |
| 墙壁/门/地板 | **S** | 温度隔离、美观、路径控制——空间基础设施 |
| 发电机/电线/电池 | **S** | 能源网络（电网），不产不转，改变机器可达性和运行能力 |
| 空调/加热器/通风口 | **S** | 温度调节——改变系统运行环境条件 |
| 睡眠点/床/娱乐设施 | **S** | 恢复殖民者状态（休息/娱乐需求），系统效率恢复而非资源流 |
| 研究台→高科技研究台 | **K** | 殖民者智力劳动→研究点→解锁科技，消耗「殖民者时间」换取系统能力 |
| 医疗床/生命体征监测仪 | **S** | 提高治疗效率，不产不转，改变系统参数 |
| 飞船结构/引擎/传感器 | **T** | 终极终端——建造飞船逃离星球=胜利条件 |

**角色特征**：**S 最高（30%），P+C 均匀分布。RimWorld 是「S 承载了玩家 60% 的操作」的游戏——墙壁温度区隔、电网、娱乐设施、房屋布局、存储区规划，全部是 S 层。** 战斗本身是 K+T 的混合（袭击消耗弹药→干掉袭击→获得喘息期），但建筑端的主角是 S。

**可迁移洞察**：把「文明失败」人格化。RimWorld 的系统故障不是红字警告，而是殖民者发疯、纵火、逃跑、社交冲突。文明 Roguelite 可以设计——当符文污染超标时，不是弹出「污染+10」，而是「祭司团首席宣布工业线亵渎圣纹，号召信众抵制工坊」——系统压力通过代表性主体「说话」。

## 4. Dwarf Fortress

**角色分布（估算）**：P:15% / C:35% / S:30% / K:15% / T:5%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 地下农场 | **P** | 地下土壤→植物（不需要阳光！），环境产出 |
| 采矿 | **P** | 山体→矿石/石材/宝石，分层无限但有深度风险 |
| 狩猎/钓鱼/伐木 | **P** | 野生动植物→食物/木材 |
| 熔炼炉 | **C** | 矿石→金属条，高温冶炼转化 |
| 锻炉（武器/盔甲/金属工艺） | **C** | 金属条→武器/盔甲/工具，锻造转化 |
| 厨房/蒸馏室 | **C** | 生食→熟食、植物→酒（酒精是矮人的「燃料」），加工转化 |
| 屠宰场 | **C** | 动物→肉+皮+骨+脂肪（多产出分解转化） |
| 纺纱机/织布机/裁缝店/皮革坊 | **C** | 纤维/皮→线→布→衣服/皮甲，多层纺织链转化 |
| 木工坊/石工坊/玻璃窑/窑炉 | **C** | 原料→家具/容器/工艺品 |
| 机械工坊 | **C** | 石块→机械零件（水车/闸门/陷阱组件），高级 C |
| 卧室/餐厅/办公室/酒馆/神殿/图书馆 | **S** | 满足矮人个人需求和心情，维持系统运行效率（情绪稳定=工作效率） |
| 水闸/水泵/排水管/岩浆泵 | **S** | 流体工程——控制水/岩浆流向，不产不转但重塑物理世界 |
| 吊桥/陷阱/笼子/城墙 | **S** | 空间防御，物理隔离而非消耗资源消耗 |
| 兵营/靶场 | **K** | 矮人时间→战斗技能训练，消耗时间换能力 |
| 神器锻造（矮人灵感） | **K→T 边界** | 一次性不可控的消耗+产出神器→神器改变房间质量和矮人幸福度→但核心是一次性的高价值产物，判**K** |
| 无固定终局 | **T** | DF 没有 formal terminal，T ≈ 5%。「深挖到地狱/糖果」是最接近的终局目标，但不是设计意图上的 T |

**角色特征**：**C 最高（35%），T 几乎为零。这是 12 款游戏中唯一「没有正式胜利条件」的游戏。** C 极高是因为 DF 的全连接产业网络——每个工作室依赖其他工作室的产品，形成 8-10 步的复杂转化链。S 同样高是因为矮人需求系统（卧室/餐厅/神殿/酒馆/图书馆）占据了大量建筑类型。

**可迁移洞察**：不要照搬 DF 的复杂度，但要迁移「可追溯的文明事故链」。文明崩溃不应是「随机事件触发数值归零」——而应是「边疆矿脉被过度开采 → 符文污染升高 → 教团解释为神迹 → 工业派压制 → 异端叛乱 → 首都法阵失控」的因果链，每一步都可在日志/视觉中追溯。

## 5. Frostpunk

**角色分布（估算）**：P:20% / C:15% / S:25% / K:30% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 煤矿/采煤机 | **P** | 矿脉→煤炭，从环境产出 |
| 锯木厂/钢厂 | **P** | 冻林→木材、铁矿→钢铁，环境采集 |
| 猎人小屋/温室 | **P** | 冻原→生食（猎人）或水+热量+时间→食物（温室），前者纯P、后者偏C，综合判**P** |
| 炊房 | **C** | 生食→口粮（效率转化：更多份数/更少食材），经典 C |
| 工坊 | **K** | 消耗工程师时间→科技进度。工程师时间不是材料资源，但仍然是「可分配人力资源→进度」的消耗→判**K** |
| 发电机 | **K→C 边界** | 输入煤炭→输出热量。热量是资源吗？在 Frostpunk 中，热量是「将空间变为可生存状态」的关键量——它改变了所有其他 P/C 的运行条件。因为热量本身不参与下游转化→判**K**（煤炭被「吃」掉换成生存状态） |
| 蒸汽枢纽/加热器 | **S** | 不消耗额外煤炭（或微耗），扩展/增强热量覆盖范围，纯 **S** |
| 帐篷→工棚→房屋 | **S** | 隔热等级提升，降低煤炭消耗率→改变系统效率而非资源流 |
| 医疗站/医务所 | **S** | 恢复劳动力状态，不产不转资源，维护系统健康 |
| 法典（秩序线/信仰线） | **K** | 每次签署消耗「道德资本」（希望/不满）+冷却时间→获得新治理能力和建筑。法典本质上是一个 K 系统——吃道德资源换治理能力 |
| 侦察队/前哨站 | **S→P 边界** | 解锁外部资源获取→拓展了 P 的地图范围→判**S**（核心是解锁能力） |
| 终局暴风雪 | **T** | 所有煤炭/食物/医疗/希望的最终消费归宿——活过暴风雪=胜利 |

**角色特征**：**K 极高（30%），为全批次最高。** 原因：(1) 发电机是 K 而非 C——热量不是「被转化」而是「被消耗」；(2) 法典树本身就是 K——吃道德资源换治理能力；(3) 工坊消耗工程师时间=另一种 K。Frostpunk 的核心不是「生产→转化→终局」而是「消耗→消耗→消耗→撑过审判」。

**可迁移洞察**：路线选择应设计为「道德-物理兑换」。法典树的二择设计（选A锁B）可以直接迁移为文明路线选择——选择工业化→生产力+50%→劳工不满+30%→需要新机制压制或安抚（新的K节点产生）。每次路线选择=改变一种资源的成本，引入一种新类型消耗。

## 6. Timberborn

**角色分布（估算）**：P:20% / C:20% / S:30% / K:20% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 水泵（河流→水） | **P** | 从环境提取水，无限但有旱季归零风险 |
| 农田/水生农场 | **C** | 水+土地+时间→作物，依赖灌溉链的 C |
| 林场 | **P** | 种植→树木，nurture-based 的 P（不是采集而是培育） |
| 伐木工小屋 | **P** | 树→原木，环境采集 |
| 锯木厂 | **C** | 原木→板材，1级加工转化 |
| 齿轮工坊/造纸厂 | **C** | 板材→齿轮、原木→纸张，2级加工转化 |
| 磨坊/面包房 | **C** | 小麦→面粉→面包，食物加工链 |
| 水坝/防洪闸 | **S** | 改变水流方向+蓄水能力，不产不转但改变整个水文系统——最核心的 **S** |
| 水箱（小型/中型/大型） | **S** | 水资源缓存，不产不转但改变旱季生存能力 |
| 灌溉塔 | **S** | 水→土地湿润，本质是水的分配（资源可达性）→判**S** 而非 C |
| 平台/楼梯/桥梁 | **S** | 垂直空间解锁——不产不转，但改变所有建筑的空间可用性 |
| 水车/风车/引擎 | **S→C 边界** | 水流/风→电力（资源形态转化），但电力仅用于驱动机器→本质是 C 的输入→判**C** |
| 发明家小屋/瞭望塔 | **K** | 海狸劳动时间→发明点数→科技解锁，经典 K |
| 屋顶花园/神殿/泥浴 | **S** | 提升幸福度→影响工作效率，间接提高系统效率的 S |
| 旱季生存 | **T** | 旱季结束时仍有足够水=阶段性胜利，最终的 T 是「所有旱季都活过」 |

**角色特征**：**S 最高（30%），核心是水利工程 S 层。** Timberborn 的 S 不是 Factorio 式的「物流效率」或 ONI 式的「系统可视化」，而是「地形改造」——水坝改变了河流物理形态，平台改变了 Z 轴建设能力。S 不是服务的配角，而是生存的主角（没有水坝=旱季全灭）。

**可迁移洞察**：周期审判+可预判布局。旱季是定期来临的，预告给了玩家准备时间。文明 Roguelite 可设计类似周期——月蚀期（符文污染暴露）、朝圣季（信仰网络过载）、征税季（边疆忠诚被审判），平时的选择在审判期集中结算。关键在于「可预判」——玩家能看到倒计时，知道 3 回合后危机来临，可以提前布局。

## 7. Banished

**角色分布（估算）**：P:30% / C:20% / S:25% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 采集小屋/狩猎小屋/捕鱼码头 | **P** | 森林/草原/水域→食物，环境采集 |
| 农田/果园/牧场 | **P** | 种植+养殖→食物+资源，环境培育型 P |
| 伐木小屋/采石场/矿场 | **P** | 树→原木、地表→石/铁，环境采集（采石场/矿场无限但慢） |
| 伐木场 | **C** | 原木→柴火（取暖燃料），1:1 转化 |
| 铁匠铺 | **C** | 原木+铁→工具，工具是一切工作效率的乘法器 |
| 裁缝店 | **C** | 皮革/羊毛→衣服，冬季生存必需品 |
| 酿酒厂 | **C** | 水果→酒（贸易/幸福），价值升级转化 |
| 房屋（木屋→石屋） | **S** | 石屋更暖（降低柴火消耗），间接改变资源流速→判 **S** |
| 学校 | **S** | 儿童→受教育成人（所有工作效率+50%），不耗资源的纯系统效率提升——Banished 最重要的 **S** 建筑 |
| 草药屋/医院 | **S** | 维持人口健康，恢复系统状态 |
| 教堂/墓地 | **S** | 维持幸福度，防止快乐度过低导致效率下降 |
| 市场 | **S** | 均匀分配资源给各区域，提高物流效率而非生产/转化 |
| 贸易站 | **S→P 边界** | 用盈余换稀缺品（种子/牲畜），解锁原本不可用的 P 类型→判**S**（核心是解锁能力） |
| 市政厅 | **S** | 统计数据+接受移民，纯信息/管理能力 |
| 人口稳定循环 | **T** | Banished 无正式胜利条件，T 是「城镇不崩溃」——模糊的生存终端 |

**角色特征**：**P 最高（30%），唯一的「无科技树」设计。** Banished 的解锁不由科技驱动，而由人口里程碑驱动。P 高是因为「资源获取建筑」几乎涵盖了所有初期建筑类型——采集/狩猎/钓鱼/伐木/采矿/农田/牧场——7 种纯 P 建筑。S 也很重要但没有像 Factorio/ONI 那样的物流网络，S 的核心是「学校」这一个效率超级节点。

**可迁移洞察**：人口驱动的解锁系统和「延迟反馈」。Banished 的年龄结构是最残酷的设计——今天不造学校，10 年后全是低效劳动力；今天建太多房子，10 年后人口爆炸→食物崩溃。文明 Roguelite 可迁移为——制度选择的后果在 3-5 回合后才显现（类比代际延迟），让玩家的早期选择成为 3 回合后的危机源。

## 8. Mini Metro

**角色分布（估算）**：P:15% / C:30% / S:30% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 车站（乘客生成点） | **P** | 车站自动生成乘客（需求生产），不同形状=不同类型的 P |
| 线路（连接车站→运送乘客） | **C** | 将「乘客堆积（压力）」转化为「已运送（消解）」，抽象但不失为 C |
| 隧道/桥梁 | **S** | 连接被水域隔离的车站，解锁空间可达性——最关键的空间 **S** |
| 车厢（追加到线路） | **S** | 提高线路运力（流速），不产不转但改变 C 的转化速率 |
| 换乘枢纽 | **S** | 降低换乘等待时间，提高网络效率 |
| 每周奖励选择（线路/车厢/隧道） | **K→S 边界** | 消耗「升级机会」（一种行动资源）→获得新 S 节点→但升级机会本身不可再生（1次/周）→判**K** |
| 车站过度拥挤 → 游戏结束 | **T** | 所有运输努力的最终检验标准 |

**角色特征**：**C+S 双高（30%+30%），极度抽象化。** Mini Metro 是「用最短的元素列表实现最大决策压力」的典范——只有车站（P）、线路（C）、隧道/车厢/枢纽（S）、每周奖励（K）。没有二级资源、没有升级链、没有数值面板。压力一眼可见（哪个站堆积了乘客），操作极其有限（只能拉线和放车厢），但决策深度来自空间拓扑和时机选择。

**可迁移洞察**：文明网络抽象的极致参考。文明 Roguelite 可以将城市/阶层/派系/圣地抽象为「站点」，法令/信仰/符文流向抽象为「线路」，异端/污染/不满抽象为「拥堵的乘客」——玩家不是在管理 20 个数值，而是在调整节点间的连接。抽象不可怕——只要压力一眼可见。

## 9. Mini Motorways

**角色分布（估算）**：P:15% / C:30% / S:30% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 房屋（车辆生成点） | **P** | 房屋产生前往目的地的车辆（需求生产），颜色匹配=目的地类型 |
| 目的地（商场/办公楼等） | **P→T 边界** | 目的地是需求的接收端——车辆到达=压力消解。同时也是 T 的触发器（需求未满足→倒计时结束=失败），判**P**（需求生成器）+**T**（失败触发器） |
| 道路 | **C** | 车辆在道路上行驶=需求→满足的流动通道，抽象 C |
| 桥梁/隧道 | **S** | 穿越水域/山脉的空间连接 |
| 高速公路 | **S** | 大容量快速通道，空间级别的支持节点 |
| 红绿灯/环岛 | **S** | 交通管理——不运送车辆，但改变道路交叉处的流通效率 |
| 每周奖励选择（道路/高速/红绿灯等） | **K** | 消耗不可再生的升级机会→获得新 S 节点 |
| 目的地倒计时归零 | **T** | 终端失败条件 |

**角色特征**：**与 Mini Metro 几乎一致的结构，但增加了「布局债务」维度。** 早期随手画的路，5 分钟后成为整个网络的瓶颈。Mini Motorways 的核心乐趣是「直面自己的空间技术债务」——你被你自己早期的选择困住了。

**可迁移洞察**：早期路线选择应留下可见的「空间债务」。文明 Roguelite 中——早期选择工业集中→后期符文路线会遇到污染/空间债务；早期依赖教团维稳→心灵路线会遇到解释权债务；早期边疆自治→统一飞升会遇到离心债务。路线债务应在地图/节点连接上可视化，而非只是数值修正。

## 10. Opus Magnum

**角色分布（估算）**：P:10% / C:40% / S:20% / K:20% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 试剂（输入位置） | **P** | 元素原子从输入位置自动出现（谜题给定），环境「供应」 |
| 机械臂（抓取+移动原子） | **C** | 将原子从输入→移动到处理位置，空间位置转化——不仅是移动，更是将「存在」转化为「可用位置」 |
| 雕文（转化原子类型） | **C** | 水→盐、铅→锡等，元素类型转化 |
| 结合雕文（粘合原子） | **C** | 两个原子→一个大分子，合并转化 |
| 轨道（引导机械臂运动路径） | **S** | 改变机械臂的运动路径和速度，不直接转化但改变 C 的效率 |
| 活塞/多臂配置 | **S** | 扩展机械臂能力范围，解锁新的空间可达性 |
| 编程指令（周期序列） | **S** | 指令本身不消耗资源（只是组织机器行为），但决定了 C 的效率——纯 **S** |
| 循环周期（时间成本） | **K** | 每个机械臂动作消耗 1 周期，周期总数=解决方案的「消耗量」 |
| 目标分子（输出验证） | **T** | 产物的最终验证——必须精确匹配目标分子的结构=谜题完成 |

**角色特征**：**C 为全批次最高（40%）**。Opus Magnum 几乎全部是转化！没有传统意义上的「资源采集」（P 只是谜题给的固定输入），没有「物流网络」（S 只是轨道和活塞），核心就是把输入原子经过一系列精确的转化（移动/变换/结合）变成目标分子。S 在这里不是效率加成，而是「编程能力」——更好的 S = 更优雅的转化序列。

**可迁移洞察**：解法可比较性。Opus Magnum 的成就感来自对比最优解——成本最低？周期最少？面积最小？最优雅？文明 Roguelite 应允许玩家比较不同路线的解法——同一粮食危机，工业方案（机械灌溉=高效率+高污染）、符文方案（季节法阵=稳定+消耗信仰）、教团方案（禁欲配给=社会稳+压制创新）、心灵方案（共享饥饿=降暴动+侵蚀个体边界）。每种解法有不同的代价形态。

## 11. Dyson Sphere Program

**角色分布（估算）**：P:10% / C:35% / S:25% / K:15% / T:15%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 采矿机 | **P** | 矿脉→矿物（铁/铜/石/煤/硅/钛等），从环境提取 |
| 抽油机/水泵/气态巨星收集器 | **P** | 原油/水/氢/重氢，从环境收集 |
| 熔炉 | **C** | 矿物→板材/磁铁/玻璃等，1级加工 |
| 制造台 | **C** | 多原料→半成品（电路板/齿轮/处理器等），2-3级组装 |
| 化工厂/精炼厂/粒子对撞机 | **C** | 流体/高级材料的深度转化，最复杂的 C 节点 |
| 传送带/分拣器 | **S** | 物流基础层——决定物料流向和流速 |
| 星际物流塔/行星物流站 | **S** | 跨星球物流——解锁多星球生产的核心 **S**，类似 Factorio 的火车+机器人的融合 |
| 电网（发电机/太阳能/核能/戴森球电力） | **S→P 边界** | 电力网本身是 S（不参与资源流），但戴森球产生的能量某种意义上=终极 P |
| 研究站（消耗科学矩阵） | **K** | 科学矩阵→科技解锁，吃复杂多层产物换系统能力 |
| 戴森球组件/框架/太阳帆 | **K→T 边界** | 消耗巨量资源建造戴森球空间结构→戴森球本身是终局目标，这些组件是「用于 T 的 K」 |
| 戴森球完成 | **T** | 终极工程终端——所有生产链的最终消费归宿 |

**角色特征**：**T 比 Factorio 更高（15% vs 10%），因为在星球表面就可以看到戴森球逐渐成形——T 有「持续的近端可见反馈」，而非只在发射火箭那一刻。** C+S 结构与 Factorio 高度相似，但跨星球物流增加了 S 的空间尺度。

**可迁移洞察**：宏大终局必须有近端反馈。心灵飞升/文明超越等宏观目标不能只在结尾显示一段文字——必须有近端可建设/可看到的进展：梦境节点逐渐连通、城市意识同步率提升、个体抗拒区缩小、旧制度节点被逐个替换。玩家每一步都能在「文明地图」上看到终局目标的结构逐渐成形。

## 12. Satisfactory

**角色分布（估算）**：P:10% / C:35% / S:25% / K:15% / T:15%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 采矿机（不同等级） | **P** | 矿脉→矿物，纯度决定产出速率，无限矿物但有节点速率上限 |
| 抽油机/水泵/资源井 | **P** | 原油/水/氮气，环境提取 |
| 熔炉 | **C** | 矿物→锭，基础冶炼 |
| 构造器 | **C** | 锭→板材/线材/杆材/混凝土等，1级加工 |
| 组装器 | **C** | 2-3种零件→高级零件（强化铁板/转子/模块化框架等） |
| 制造商 | **C** | 4种零件→终端级产品（计算机/重型框架/电机等） |
| 精炼厂/搅拌机/粒子加速器 | **C** | 流体/高能级材料的深度转化 |
| 传送带/管道/电力线/电力杆 | **S** | 物料和能源连接层 |
| 卡车/火车/无人机 | **S** | 中远距离运输，S 的空间尺度升级 |
| 超管/喷气背包/滑索 | **S** | 玩家自身移动系统（减少行走时间=提高干预效率），纯 S |
| 电力系统（生物质/煤/燃油/核能） | **S** | 能源供给网络 |
| MAM（分子分析机） | **K** | 消耗材料/零件→解锁替代配方和功能，经典 K |
| AWESOME 水槽 | **K** | 多余产物→优惠券点数→装饰/材料，逆向消耗（K 产出是装饰性/便利性） |
| 太空电梯 | **T** | 分阶段交付终端产品→解锁新 Tier+新星球，阶段性的 T（每次交付=一次微型 T） |

**角色特征**：**与 DSP 几乎完全相同的分布结构，但多了「空间具象化」维度——第一人称视角让玩家站在自己的 C-S 网络中观察它运行。** 太空电梯是极好的「阶段性 T」设计——不是一次性火箭发射，而是分 8 个阶段每次交付更大的货物量，每次交付都解锁新能力和新区域。

**可迁移洞察**：文明路线应在空间上留下痕迹。Satisfactory 的工厂是「你会站进去看它运转的东西」。文明 Roguelite 也应让路线选择不只是面板选项——工业路线让地图上出现工厂区，符文路线让矿井边出现法阵，教团路线让学校变成神殿，心灵路线让城市间出现意识连接塔——让玩家「看见自己的文明变成了什么」。

## Batch 4 批次综合

### 角色权重雷达图描述

```
             P (Production)
                 20
                 |
                 |
         S ---- 28 ---- C
        (Support)  |  (Conversion)
                15 |
                 |
            K ----- T
       (Konsumption) (Terminal)
```

**批次均值（估算）**：
- **P: 16%** — 低，环境采集是基础但不是核心
- **C: 31%** — 次高，转化链是最核心的玩法驱动
- **S: 29%** — 最高，物流/管道/电网/存储/温度控制/空间平台/overlay
- **K: 17%** — 中等，研究+建造为主要消耗形式
- **T: 11%** — 中低，6款有明确终局目标，6款为开放式生存

### 批次内共性模式

1. **C+S 双核主导（合计 60%）**：12/12 款游戏的核心都是「转化网络绑定在支持系统上」。与 Batch 3（RTS）的「C 是主角但 S 是约束」不同，Batch 4 的 S 是赋能（物流/管道/电网/overlay）而非限制（人口上限）。

2. **P 由外部约束而非内部需求驱动**：Batch 4 的 P 多为无限矿脉（Factorio/DSP/Satisfactory/ONI 间歇泉/DF 无限挖），P 的紧张感来自「速率上限」而非「储量上限」。这与 Batch 3 的「有限矿脉」形成鲜明对比。

3. **K 是研究驱动的线性消耗，不是战斗驱动的竞争消耗**：本批次 K 的主要形式是「投入资源→研究→解锁科技」。与 Batch 3 的 K（战斗消耗+升级）不同，Batch 4 的 K 更被动、更线性，不需要与对手竞赛。

4. **T 的二元分化**：6款有正式 T（Factorio 火箭、DSP 戴森球、Satisfactory 太空电梯、Frostpunk 终局暴风雪、ONI 时空裂隙、Mini Metro/Motorways 失败条件），6款无正式 T（RimWorld 飞船可选、DF 开放结局、Timberborn 海狸天堂、Banished 人口稳定、Opus Magnum 单关即终）。T 的有无不决定游戏好不好玩——Frostpunk 的 T 是高潮、DF 的「无 T」是哲学。

5. **Mini Metro/Motorways 是极端值——用极简资源结构实现了高压决策**：P（车站/房屋）、C（线路/道路）、S（隧道/桥梁/枢纽）、K（每周选择）、T（拥堵失败）——总共 5 类互动元素却能产生极高决策密度，为文明 Roguelite 的「极简资源方案」提供了最干净的参考。

### 2-3 个最值得迁移的角色设计模式

#### 模式 1：瓶颈自生成目标（Factorio + ONI + DSP）
> **核心**：玩家 80% 的时间在处理 C 链上的瓶颈——而不是管理 P 端的数值增长。目标不由任务列表给出，而由系统自然浮现：「铁板传送带为什么空了？」→ 上游瓶颈 → 诊断 → 修复 → 流量恢复 → 新瓶颈出现。
> **迁移**：文明状态的「瓶颈 overlay」——不显示「粮食+5/回合」，而显示「粮食从农田流向城市的速度被运输线路瓶颈卡住」。每个瓶颈自动生成下一步目标。系统设计的关键不是资源种类数量，而是资源流是否可视化。

#### 模式 2：overlay 化隐性变量（ONI + Frostpunk）
> **核心**：ONI 的气体/温度/病菌 overlay、Frostpunk 的热力图——让不可见变量变成可视化空间层，让玩家从「猜发生了什么」变成「诊断哪里坏了」。
> **迁移**：文明 Roguelite 至少需要 4 个 overlay：(1) 解释权流向——谁在定义文明意义？(2) 路线债务——过去选择留下哪些结构性代价？(3) 污染/噪声扩散——符文、工业、心灵的副作用如何扩散？(4) 主体忠诚度——哪些阶层/派系会执行/抵制/扭曲命令？

#### 模式 3：周期性审判 + 可预判布局（Timberborn + Frostpunk + Mini Metro）
> **核心**：危机不是突然出现吓你一跳，而是提前预告，让你有 3-5 回合（或 3-5 天）准备。考验的是你的「预判布局」，而非你的「即时反应」。
> **迁移**：设计 3-4 种「周期性文明危机」——月蚀期（符文污染暴露）、朝圣季（信仰网络过载）、征税季（边疆忠诚被审判）、梦潮期（心灵噪声冲击个体）。每种危机提前 3 回合预告，玩家可以在预告期内用治理注意力布局应对方案（加固防线/疏导流量/镇压叛乱/开放自治），审判来临后统一结算——制造分钟级期待和决策高峰。
