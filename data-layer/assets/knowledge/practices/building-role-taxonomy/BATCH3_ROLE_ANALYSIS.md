# Batch 3 功能角色分析：RTS / 少资源高压决策

> 框架版本：00_FRAMEWORK.md | 分析日期：2026-07-30
> 来源数据：batch3_resource_formulas.md, BATCH3_rts_low_resource_pressure_initial.md, FINAL_AUDIT_BY_GAME.md

---

## 批次概览

Batch 3 涵盖 10 款以「少资源、高压力、快决策」为特征的 RTS/策略游戏。这些游戏的资源种类普遍偏少（1-4 种），复杂度由时间压力、空间争夺、注意力分配和信息不对称提供，而非资源种类。

---

## 1. StarCraft II

**角色分布（估算）**：P:20% / C:30% / S:25% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 指挥中心/孵化场/星灵枢纽 | **P** | 生产SCV/工蜂/探机（劳动力=持续产出器），净产出为正 |
| 补给站/王虫/水晶塔 | **S** | 不产不转资源，提高人口上限（解锁规模能力），改变系统容量 |
| 兵营/重工厂/星门 | **C** | 矿+气→作战单位（资源→军事力量），核心转化节点 |
| 工程站/军械库升级 | **S→K 边界** | 消耗矿/气提升单位属性，属于「吃掉资源换战斗力提升」→**K** |
| 科技实验室/反应堆 | **S** | 提高兵营产出效率（不改变资源流本身，改变流速） |
| 感应塔/雷达 | **S** | 信息收集——不产资源但改变决策质量和注意力分配 |
| 矿骡/加速 | **P/S 边界** | 矿骡凭空产更多矿→**P**；加速提高建筑效率→**S**，综合判**P**（净产出增加） |
| 精炼厂/吸收器/萃取器 | **C** | 将采矿劳动力（一种采集位）→高能瓦斯（另一种资源），判**C** |

**角色特征**：**C 和 S 双高**。真正决定胜负的不是「有多少矿」，而是「矿的转化速率」（产能建筑数）和「信息/空间支持系统」（侦察+视野+地图控制）。P 只占总体的 20%——矿脉有限且农民效率有上限。

**可迁移洞察**：文明 Roguelite 不应模仿 SC2 的多建筑暴兵，应模仿其「转化瓶颈」——治理注意力的转化速率（生产建筑类比）决定文明响应速度，而非注意力总量。信息支持系统（侦察类比）可转化为「文明 overlay」让玩家看到隐性压力。

## 2. Age of Empires II

**角色分布（估算）**：P:30% / C:25% / S:20% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 城镇中心 | **P** | 生产村民（劳动力采集器），四资源均从环境获取 |
| 磨坊/伐木场/采矿场 | **P/S 边界** | 本身不产出，但让采集点可投递→判**S**（提高资源流效率） |
| 农田 | **C** | 木材→食物（60木→175食，持续再生），净转化非净产 |
| 兵营/靶场/马厩/攻城武器厂 | **C** | 食物+黄金+木材→军事单位，经典转化 |
| 铁匠铺科技 | **K** | 消耗资源→提升全军攻防，典型的「吃资源换战斗力」 |
| 房屋 | **S** | 提高人口上限（系统容量解锁） |
| 大学科技 | **S** | 解锁建筑血量/射程/速度等系统参数，不直接参与资源流 |
| 市场 | **S** | 买卖资源本质是转化→但设计意图是「调节不平衡」而非主要生产链→判**S** |
| 奇观 | **T** | 站住200年=胜利，资源的最终消耗归宿 |
| 时代升级 | **K** | 消耗 food+gold → 解锁新时代，典型的「吃资源换系统能力」 |

**角色特征**：**P 最高（30%）**，经济扩张是 AoE2 的核心。四种资源分别暗示四种战略路线（食物→骑兵/村民、木材→弓兵/海军、黄金→高级兵/科技、石头→防御/奇观），是「资源 = 路线暗示」的典范设计。

**可迁移洞察**：每种「文明路线」（工业/符文/教团/心灵）可以各自吸引一种治理行动（类比资源采集），玩家分配不同比例的行动即暗示路线偏好——不需要 8 种资源，用 2-3 种治理行动的流向即可表达路线选择。

## 3. Warcraft III

**角色分布（估算）**：P:15% / C:30% / S:20% / K:25% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 城镇大厅（采金/伐木） | **P** | 生产农民→金+木，但矿有限（金矿耗尽需迁移） |
| 祭坛 | **P/C 边界** | 复活英雄消耗金+木→「生产」英雄单位→但英雄一旦存在即可独立成长，判**P**（英雄是独特生产物） |
| 兵营/车间/古树 | **C** | 金+木→常规单位 |
| 农场/地洞/月井 | **S** | 人口上限+特殊功能（月井回蓝回血），判**S** |
| 英雄练级（野怪→经验→等级） | **K** | 野怪是不可再生地图资源，击杀→经验→英雄成长，典型的「吃地图资源换战力」 |
| 宝物 | **S** | 不消耗资源，提供永久或限时增益，改变英雄能力参数 |
| 主基地升级 | **S** | 解锁高级单位和科技，提高系统容量（不直接产/转资源） |
| 科技研究（攻防/技能） | **K** | 金+木→单位属性提升，一次性消耗换永久增益 |
| 维持费系统 | **S** | 食物超阈值→金收入下降→降低资源流速→判**S**（反向调节系统效率） |

**角色特征**：**K 异常高（25%），远超典型 RTS**。核心原因是英雄系统——野怪是不可再生地图资源，经验是一条独立于矿/木的消耗链。维持费机制是对 P 端流速的负反馈调节。整个经济模型是「小 P，大 C，高 K 的克制循环」。

**可迁移洞察**：文明 Roguelite 的「代表性主体」（大工程师/教宗/心灵领航者）可以类比英雄——他们不是可再生的普通单位，而是不可替代的「能力乘法器」。主体成长（类比经验→等级）应消耗有限地图资源（类比野怪），而非无限再生的治理注意力。

## 4. They Are Billions

**角色分布（估算）**：P:25% / C:20% / S:25% / K:15% / T:15%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 猎人小屋/渔夫小屋/农场 | **P** | 从环境产出食物（地块→持续产出），净产出为正 |
| 采石场/锯木厂/油田平台 | **P** | 矿脉→石材/木材/石油，有限但持续产出 |
| 房屋（产生殖民者和金币） | **P** | 居民→金币（凭空产金，通过人口系统），净产出为正，判**P** |
| 兵营/工程中心（造兵） | **C** | 金币+资源→军队单位 |
| 仓库 | **S** | 存储容量+资源产出加成，纯系统效率提升 |
| 市场/银行 | **S** | 金币产出效率乘法器，不产不转资源 |
| 泰斯拉塔（电力网） | **S** | 扩展建筑可用范围，解锁空间能力 |
| 城墙/塔/陷阱 | **S→K 边界** | 本身不消耗资源维持，但在尸潮中消耗（僵尸攻击→防御耐久）→判**S**（核心功能是空间阻隔，非资源消耗器） |
| 研究（石工/农场科技） | **K** | 消耗金币+资源→永久升级，吃资源换系统能力 |
| 尸潮审判（机制级） | **T** | 所有资源积累最终用于「在尸潮中存活」——周期的终端检验 |

**角色特征**：**P+S 均匀分布，T 权重异常高（15%）**。尸潮是定期结算的「终局微型化」——每一波尸潮都是一次局部胜利条件检验。S 高是因为空间防御（城墙/塔）是核心机制，占据了大量建筑类型。

**可迁移洞察**：文明危机可以设计为「定期尸潮式审判」——每隔 N 回合，所有文明路线的压力同时爆发（符文污染扩散、异端起义、生态崩溃），此前积累的所有资源必须在这几个回合集中转化为「防线」。T 不是终局才出现，而是周期性出现的微型终端。

## 5. Bad North

**角色分布（估算）**：P:10% / C:5% / S:30% / K:35% / T:20%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 房屋（防守成功→金币） | **P** | 守住房屋=金币产出，但本质是「已完成 K 后的奖励」→判**P**（战斗奖励作为生产） |
| 小队单位（初始+招募） | **P** | 战斗中存活的单位=后续战役的资产，不消耗不转化 |
| 升级（金币→单位强化） | **K** | 吃金币换战斗力，一次性消耗，不退不转 |
| 补充兵员（金币→恢复人数） | **K** | 死亡是永久不可恢复的，但幸存单位的兵员补充也是消耗金币 |
| 地形（高地/窄道） | **S** | 改变防御效率，不耗资源 |
| 技能（指挥官技能） | **K** | 有冷却但无资源消耗→严格来说应判**S**（无资源流的纯能力解锁），但因技能决定胜负→判**S** |
| 岛屿消耗（守过=不能重来） | **T** | 空间本身作为不可逆消耗品——终局是「没有更多岛屿可守」 |

**角色特征**：**K 极高（35%），S 极重（30%），几乎没有 C**。这是一款「几乎不转化、大量消耗+支持」的游戏。金币只用于两种事情：升级（K）和补充（K）。所有决策都是「这次消耗之后，下次还有多少？」没有流水线、没有转化链。

**可迁移洞察**：文明节点/主体可以设计为「永久不可恢复」——灭亡的阶层不能复活、被摧毁的城市只剩遗址。这种设计迫使玩家的每次 K 都是高度紧张的选择。Bad North 证明了「没有 C 的游戏同样可以极度紧张」。

## 6. Creeper World

**角色分布（估算）**：P:25% / C:15% / S:30% / K:20% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 收集器（地形→能量） | **P** | 放置在有高度差的地形上→持续产出能量，净产出为正，经典**P** |
| 反应堆 | **P** | 更高效率的能量生产节点 |
| 中继节点 | **S** | 扩展能量网络范围，不产不转资源，纯系统连接支持 |
| 加农炮/迫击炮 | **K** | 消耗能量→消灭 creeper（敌人），典型的「吃资源换进度」 |
| 护盾 | **S** | 消耗能量但产出「保护区域」——一种状态，判**S** |
| 地形改造器 | **S→K 边界** | 升高/降低地形消耗大量能量，产出是「可建设新区域」或「阻断敌人流动」→阻断敌人流动=K、创造新建设区域=S，综合判**S**（战略空间扩展） |
| 消灭所有释放源 | **T** | 能量的最终归宿——用于推进前线，消灭所有敌人=胜利 |

**角色特征**：**S 极重（30%）**。中继网络、护盾、地形改造占据了大量建筑类型。游戏本质是「建造能量网络→扩展网络→用能量消灭流体敌人」。S 和 K 的博弈是核心（分配到攻击还是扩展网络？）。

**可迁移洞察**：文明压力可以设计为「流体扩散」（类比 creeper）——符文污染、梦境噪声、异端思潮不是离散事件，而是持续扩散的流体。玩家的治理注意力（类比能量）必须在「感染区域→S（修建防线/净化节点）」和「消灭污染源→K（消耗注意力根除）」之间分配。

## 7. Tooth and Tail

**角色分布（估算）**：P:25% / C:35% / S:15% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 磨坊（粮食自动产出） | **P** | 指挥官吃资源点→磨坊持续产食物，净产出为正 |
| 农场（阵营特殊） | **P** | 更高效的食物生产建筑 |
| 兵营/对应巢穴 | **C** | 食物→作战单位，单一资源的转化方向决定战略 |
| 科技建筑 | **K** | 食物→解锁或升级单位能力 |
| 地堡/防御塔 | **S→K 边界** | 建造消耗食物（一次性C），产出是空间控制（S状态）→综合判**S**（核心功能是空间防御） |
| 摧毁敌方指挥建筑 | **T** | 所有单位的最终消耗归宿 |

**角色特征**：**仅一种资源（食物），但 C 极重（35%）**。单一资源系统的深度来自「转化方向选择」——食物可以变兵（C 军事）、变科技（K 能力）、变防御（S 空间），每种转化方向是互斥的。没有二级货币的转换效率差异，所有差异来自转化方向的时间窗口。

**可迁移洞察**：证明「单资源可以驱动深度战略决策」。如果文明 Roguelite 只用「治理注意力」一种资源，深度来自：(1) 转化方向（用来维稳/发展/扩张/改革？）、(2) 转化时机（现在花还是攒着？）、(3) 转化位置（前线节点还是后方节点？）。

## 8. Dune: Spice Wars

**角色分布（估算）**：P:20% / C:25% / S:25% / K:15% / T:15%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 香料精炼厂 | **P** | 沙虫威胁区域→香料产出，高风险的 P |
| 风塔 | **P** | 环境→水资源 |
| 村庄建筑（各种采集） | **P** | 人力+区域→资源产出 |
| 军事建筑（兵营/工厂） | **C** | 资源→军队单位 |
| Landsraad 投票权 | **S** | 不消耗不产生资源，改变外交影响力（解锁政治能力） |
| CHOAM 市场 | **S→C 边界** | 价格浮动买卖香料→如果只是买卖算 C，但设计意图是「全局价格机制调节」→判**S** |
| 研究（科技树） | **K** | 知识资源→科技解锁 |
| 刺杀/霸权/CHOAM/政治 | **T** | 多路径胜利条件，每个都是资源的最终归宿 |

**角色特征**：**最均衡的分布之一，T 异常高（15%）**。Dune 有 4 种胜利条件（刺杀/霸权/CHOAM/政治），每种 T 消耗不同的资源组合。S 重是因为 Landsraad+CHOAM 两个政治-经济支持系统占据了大量机制空间。

**可迁移洞察**：多胜利路线意味着多 T 路径——文明 Roguelite 可以设计工业胜利（生产最大化）、符文胜利（符文网络覆盖）、教团胜利（信仰统一度）、心灵胜利（个体意识融合）四条 T 路径，每条 T 有不同的资源消耗结构，让路线选择不只是「玩法不同」而是「终点不同」。

## 9. Kingdom Two Crowns

**角色分布（估算）**：P:25% / C:15% / S:25% / K:25% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 农场 | **P** | 农民种植→自动化金币产出（旱季减速），经典 P |
| 弓箭手打猎 | **P** | 白天自动猎兔→持续金币流 |
| 商人/宝箱 | **P** | 一次性或周期性的金币注入 |
| 投币招募（弓手/工人/骑士） | **C→K 边界** | 1金币→1个公民，公民本身是生产单位（弓手打猎产金/工人建造）→净产出取决于后续分配→判**C**（公民是可分配资产，不是消耗品） |
| 铁匠铺（升级工具） | **K** | 消耗大量金币→永久提升单位战斗力/效率，经典 K |
| 城墙/箭塔 | **S** | 空间防御——阻止怪物进入核心区，不产不转资源 |
| 坐骑/隐士升级 | **S** | 解锁新能力（如吸引更多公民、进入新区域），改变系统容量 |
| 摧毁传送门 | **T** | 金币→军事力量→摧毁传送门=胜利推进，资源的最终归宿 |

**角色特征**：**单资源（金币），极高仪式感的投币交互**。所有操作 = 投金币，没有菜单、没有二级资源。P+K 双高：白天积攒的金币在夜晚转化为防御（钱包→城墙血量→守住=没亏）。K 重是因为每次升级都需要大量金币（相当于一次性巨额投资）。

**可迁移洞察**：文明 Roguelite 的「治理注意力」可以做成投币式——每次选择消费 1 注意力，投向不同节点（工业/符文/教团/边疆/心灵）。操作复杂度为 1，决策深度由系统的连锁反馈提供（一个节点的投入→改变 3 个相邻节点的状态→下回合的危机从新的位置浮现）。

## 10. Diplomacy is Not an Option

**角色分布（估算）**：P:30% / C:25% / S:20% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 理由 |
|------|------|------|
| 农场/采石场/伐木场/矿场 | **P** | 多资源采集建筑，从环境产出 |
| 兵营/攻城工坊 | **C** | 资源→军事单位、防御器械 |
| 城墙/箭塔/陷阱 | **S** | 空间防御，不产不转资源 |
| 研究（科技升级） | **K** | 资源→永久能力提升 |
| 最终波生存 | **T** | 所有物质的最终消耗归宿 |

**角色特征**：**P 最高（30%），标准纯塔防资源结构**。P 优先→C 单位→S 防线→K 升级的经典循环。与 They Are Billions 类似但少了扩张 vs 防御的空间博弈，更偏向「在固定区域内优化防线」。

**可迁移洞察**：DINA 的迁移价值低（纯塔防维度），但它验证了一个模式：**P 端的经济压力可以完全由一个持续增强的外部敌人驱动**。如果文明 Roguelite 引入外部敌人（而非纯内生危机），可以参考这种「敌我资源竞赛」的节奏——但不是主要方向。

## Batch 3 批次综合

### 角色权重雷达图描述

```
             P (Production)
                 30
                 |
                 |
         S ---- 20 ---- C
        (Support)  |  (Conversion)
                10 |
                 |
            K ----- T
       (Konsumption) (Terminal)
```

**批次均值（估算）**：
- **P: 21%** — 中等，RTS 的经济采集是基础但非主角
- **C: 25%** — 最高，RTS 的核心是「把资源变成军队」
- **S: 24%** — 次高，空间控制+人口上限+效率科技
- **K: 19%** — 中等，升级+消耗主要发生在战斗层面
- **T: 12%** — 低但恒定，每款游戏都有明确的胜利/失败条件

### 批次内共性模式

1. **C 是绝对主线**：10/10 款游戏的核心玩法都是「资源→转化→军事力量」。C 的角色数量远超 P，因为真正重要的问题不是「够不够资源」而是「转化得够不够快」。

2. **S 承担的是「约束而非赋能」**：人口上限（补给站/房屋/食物）更像是对 P 端产出的限速器。S 在 RTS 中的核心作用是「让玩家不能无限爆兵」，而非 Factorio 式的「让系统更高效运转」。

3. **T 被「微缩化」为周期性审判**：传统认知中 T 是「终局火箭」，但 RTS 用「战斗胜负」替代了火箭发射——每一场战斗都是局部 T。They Are Billions 的尸潮和 Bad North 的岛屿都是「微型终端」的典范。

4. **P 的有限性制造压力**：矿脉有限（SC2）、金矿耗竭（WC3）、岛屿不可重打（Bad North）——P 不是无限的，这与 Batch 4 的无限矿物形成对比。

5. **Bad North 和 Kingdom Two Crowns 是两个极端值**：前者 K 极高（35%）、无 C；后者 P+K 双高。它们分别展示了「少资源系统」的两个方向——一个是「每份消耗都是永久损失」，一个是「投币式经济+日夜审判」。

### 2-3 个最值得迁移的角色设计模式

#### 模式 1：C 的转化瓶颈化（SC2 + AoE2 + Tooth and Tail）
> **核心**：不让玩家管理「有多少资源」，而让玩家管理「以多快的速度把资源变成有效的形式」。
> **迁移**：治理注意力的转化速率 = f（路线上的节点数量 × 每个节点的转化效率）。玩家不是在攒注意力，而是在疏通「注意力→文明效果」的瓶颈。

#### 模式 2：微型终端 T（They Are Billions + Bad North + Kingdom Two Crowns）
> **核心**：不让 T 只在终局出现一次，而是将 T 分割为多个周期性/局部性的结算点。
> **迁移**：设计「文明危机周期」——每 N 回合，所有路线同时承受压力结算，此前积累的所有资源在结算时被「审判」。这创造了分钟级期待和目标生成器。

#### 模式 3：不良资产 P（Bad North + WC3 野怪 + Kingdom Two Crowns 投币）
> **核心**：P 不是越多越好，某些 P 是「有限不可再生的战利品」——用完了就没了，下次必须找新的。
> **迁移**：设计「有限治理事件」——每个文明节点只能被处理 N 次（类比野怪/岛屿），迫使玩家不断寻找新的治理对象和策略。这制造了「地图消耗」的紧张感，让每局文明路线不可逆地向前推进。
