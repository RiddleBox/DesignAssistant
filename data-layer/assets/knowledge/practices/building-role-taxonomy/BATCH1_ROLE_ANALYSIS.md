# Batch 1 五角色分类分析

> 非传统多资源采集的短循环 — 9款游戏的建筑/科技/卡牌按 P/C/S/K/T 角色分类

---

## 1. Stacklands

**角色分布**（估算）：P:20 / C:45 / S:10 / K:20 / T:5

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 浆果丛卡 + 村民拖入 | P | 村民从浆果丛凭空产出浆果卡（净产出正） |
| 卡包购买（金币→随机卡） | C | 金币转化为不确定卡牌，形态改变 |
| 合成配方（木材+石头→篝火） | C | 多种卡牌组合为一张新卡，经典转化 |
| 进阶合成（铁矿石→熔炉→铁锭→铁剑） | C | 多层转化链，每一层都是形态改变 |
| 房屋/仓库 | S | 提供空间容量，不直接参与资源流但改变系统上限 |
| 村民食物消耗 | K | 定期吃掉食物卡，无食物→死亡（不是T，因为可控/可恢复） |
| 工具耐久消耗 | K | 每次使用降级或消失，换取操作效率 |
| 怪物卡击败→战利品 | K | 消耗武器+村民时间→随机战利品+安全 |

**角色特征**：C 极高 — Stacklands 的本质是"卡牌组合转化器"，几乎所有乐趣都在发现配方和转化链。P 很少且都和村民劳动力绑定（没有自动产出机制）。

**可迁移洞察**：文明Roguelite可以把"科技发现"做成 C-heavy 卡牌组合系统——将不同文明节点卡拖放组合，产出新的制度/技术/事件卡，每局配方池随机生成。

## 2. Slipways

**角色分布**（估算）：P:35 / C:40 / S:20 / K:0 / T:5

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 星球固有产出 | P | 每颗星球自动生产其标签资源（净产出正） |
| 连接线（星球A→星球B） | C | 将A的产出"转化"为B的需求满足，本质是供给→消费的传导 |
| 科技升级 | S | 改变连接效率/星球产出乘数，不直接产资源但提升全网络效率 |
| 星球升级（需求满足后） | S | 升级本身不产新资源但解锁新的产出类型和连接槽位 |
| 连接数上限 | S（约束） | 瓶颈资源，限制每颗星球参与网络的程度 |
| 需求未满足 | K（负向） | 不满→停滞→网络卡死，但无资源被"吃掉" |

**角色特征**：独特在 K≈0 — Slipways 几乎没有"消耗资源换取效果"的机制。游戏压力来自"连接规划失误导致的网络阻塞"，而非资源枯竭。T也极弱（没有明确"胜利条件"，分数排行即终端）。

**可迁移洞察**：文明网络可以做成纯 P+C+S 模型——取消资源消耗，让挑战来自"如何让文明节点间的关系自洽"。如果文明节点间供需不平衡→系统熵增→文明崩溃风险。适合做"治理注意力"为核心资源的游戏。

---

## 3. Thronefall

**角色分布**（估算）：P:25 / C:5 / S:15 / K:45 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 经济建筑（农场/磨坊/港口） | P | 每回合产出金币（从游戏系统凭空产出） |
| 建造行为本身（金币→建筑） | K | 一次性金币消耗换取长期建筑能力或每回合收入 |
| 防御建筑（箭塔/炮塔/城墙） | K | 消耗金币→提供防御力（非资源性产出，是安全状态） |
| 军营（兵营/靶场） | K | 消耗金币→训练单位（单位是消耗品，战中会阵亡） |
| 住房 | S | 增加人口上限→解锁更多建筑槽（改变系统容量） |
| 英雄装备选择 | S | 改变战斗效率但不直接产资源 |
| 最终波存活 | T | 全关最强敌人波→所有前期决策的最终验证 |

**角色特征**：K 极高 — Thronefall 的核心循环是"白天消耗金币建建筑→夜晚验证建筑投资的有效性"。几乎所有建筑选择都是 K 行为（用金币换存活率/战斗力），P 建筑的存在只是为了下一轮有更多金币用于 K。

**可迁移洞察**：文明Roguelite可以设计为 K-heavy 模型——每个时代的主要行动是"消耗治理注意力换取对时代危机的应对能力"，P 行为的角色是"为下一轮的 K 提供更多筹码"。

## 4. Reigns

**角色分布**（估算）：P:0 / C:45 / S:15 / K:35 / T:5

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 事件卡选择（左/右） | C/K | 边界情况 — 同意增税：财政+15人民-10 是 C（一种状态转化为另一种）；拒绝：可能触发后续惩罚事件是 K |
| 四条状态条（教会/人民/军队/财政） | — | 本质不是"资源"而是"生存指标" |
| 事件链触发机制 | S | 某些选择解锁/锁定后续事件类型，改变可选事件池 |
| 王朝系统（死亡→新统治者） | S | 重置状态条但保留解锁的事件链和成就，相当于"软重置+继承" |
| 状态条归零/爆满 | T | 任何条到 0 或 100→统治者死亡，是明确的终端触发 |

**角色特征**：P=0 — Reigns 是唯一一款 P 为 0 的游戏。没有任何"凭空生产资源"的机制，所有状态变化都是零和/非零和的重新分配。核心张力来自"如何在四条边界之间保持平衡"。

**可迁移洞察**：文明Roguelite可以采用 P=0 模型——不做资源采集，只做状态平衡。用少量状态维度（稳定度/阶层满意/信仰凝聚力/技术扩散）替代多资源，每次治理选择同时影响 2-3 个维度，生存=所有维度保持在安全区间。

## 5. Cultist Simulator

**角色分布**（估算）：P:10 / C:40 / S:15 / K:25 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 工作槽（健康→金钱） | C | 将健康（实体卡）转化为金钱卡（形态改变，可能附带伤病负面产出） |
| 研究槽（理性+文献→秘传） | C | 复合卡牌转化为高阶知识卡 |
| 谈话槽（秘传+熟人→信徒） | C | 知识和人际关系转化为追随者 |
| 入梦槽（激情/理性→影响卡） | P（边界） | 凭空产生影响卡，但需要消耗"时间"（计时槽），可视为带风险的P |
| 仪式槽（秘传+追随者+影响→效果） | C/K | 如果是召唤新实体→K（消耗换取新单位）；如果改变状态→C |
| 恐惧/证据积累 | K（负向） | 随时间自动积累消极卡（系统自动消耗玩家的安全空间） |
| 绝望/被抓捕 | T | 恐惧×3→绝望=游戏结束；证据×3→被抓=游戏结束 |

**角色特征**：C 极高 + 独特的"负向 K"——与大多数游戏不同，Cultist Simulator 的 K 角色主要由负向卡牌（恐惧、证据、伤病）的自动积累驱动，而非玩家主动选择消耗。这制造了独特的"多时钟并行压力"。

**可迁移洞察**：文明Roguelite可以设计"负向 K 自动积累"机制——每个文明阶段有特定的"负面状态"随时间自动增长（如符文污染、异端压力、梦境噪声），玩家必须主动消耗治理注意力去抑制它们，否则到达阈值触发时代危机。

## 6. Six Ages / King of Dragon Pass

**角色分布**（估算）：P:20 / C:20 / S:15 / K:35 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 牛群自然繁殖 | P | 无外部输入，牛群随时间增长（净产出正） |
| 劫掠（军事行动→牛群扩大） | K | 消耗战士+得罪邻族→换取牛群（有社会关系代价） |
| 祭祀（牛→魔法） | C | 物质资源转化为超自然能力 |
| 仪式（牛+货物+魔法→神灵态度） | K | 消耗多种资源换取神灵好感/丰收/安全（非资源性产出） |
| 外交/联姻（货物送出→联盟） | K | 消耗货物换取政治关系和军事支持 |
| 贸易 | C | 货物交换，形态改变 |
| 战争（人口+牛群损失→领土/安全） | K | 巨大消耗换取长期安全或失败 |
| 神殿建设 | S | 解锁新仪式能力（不直接产资源） |
| 季节消耗（牛/货物/神殿维护） | K | 周期性资源消耗，维持系统运转 |
| 部族存续/神话使命完成 | T | 长期目标，与"胜利感"直接关联 |

**角色特征**：K 极高且每条 K 链都绑定世界观解释 — KoDP 的独特性在于消耗行为不是抽象的数值减法，而是"我祭祀河神是因为神话逻辑告诉我应该这样做"。每一条 K 链都携带叙事重量。

**可迁移洞察**：文明Roguelite的消耗行为应该绑定"世界观解释框架"——消耗铁矿建神殿 vs 消耗铁矿锻剑，不仅是资源选择，更是"文明自我解释方式"的选择。不同文明路线应对同一消耗赋予不同叙事意义。

## 7. Against the Storm

**角色分布**（估算）：P:15 / C:30 / S:15 / K:30 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 采集营地（伐木/采集/石匠） | P | 从林地节点凭空产出原料（净产出正） |
| 粗制工坊（原料→木板/砖块/布料） | C | 1:1或1:N原料转化，经典C |
| 高级加工建筑（锯木厂/磨坊/面包房） | C | 效率更高的转化器（同样是C但乘数不同） |
| 农田/牧场 | P | 稳定的食物来源，净产出正 |
| 服务建筑（酒馆/茶馆/神殿） | K | 消耗加工品（酒/茶/香）→满足种族需求→声望（非资源性产出） |
| 蓝图选择 | S | 解锁新建筑类型（改变可用工具集但不产资源） |
| 基石（Cornerstones） | S | 永久被动加成（改效率/解锁特殊能力） |
| 贸易站 | C | 盈余换匮乏，形态改变 |
| 林间空地事件 | K | 消耗资源/人口→奖励/惩罚 |
| 声望条 | T | 填满→胜利（资源流动的最终目的地） |
| 女王急躁度 | T（压力） | 满值→失败（终端触发，与声望是互补的T） |

**角色特征**：C+K双高 + 随机蓝图S — Against the Storm 的核心是"在随机给定的工具箱（S）内，搭建 C 链满足 K 需求，推动 T 进度"。S（蓝图/基石）的随机性是每局体验差异的根源。

**可迁移洞察**：文明Roguelite的时代工具箱 = 随机蓝图系统——每个时代给玩家一组随机的制度/技术/事件选项（S），玩家用它们搭建 C（文明状态转化）和 K（应对危机消耗）链，目标是让 T（时代生存/飞升进度）在危机条满之前达标。

## 8. dotAGE

**角色分布**（估算）：P:25 / C:20 / S:20 / K:25 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 农田（农民分配→食物产出） | P | 从土地凭空产出食物（净产出正） |
| 采集站（工人分配→材料） | P | 从环境中产出建造材料 |
| 学院（学者分配→知识） | P | 产出科技点数（解锁能力的基础资源） |
| 青年→职业分配（农民/工人/学者/士兵） | C | 将一个"通用人口"转化为专业人力，形态改变且不可撤回 |
| 知识→科技解锁 | S | 消费科技点数解锁新建筑/能力 |
| 预言系统（揭示未来灾难） | S | 不产资源但提供信息优势——改变玩家准备策略 |
| 老年人食物消耗 | K | 消耗食物但不产出（结构性消耗，反馈延迟） |
| 灾难结算 | K | 消耗积累的物资/人口换取存活 |
| 胜利条件达成 | T | 完成所有预言周期或达成特定目标 |

**角色特征**：独特的"延迟 K"——dotAGE 的 K 不即时反馈，而是通过人口老龄化（老年人多吃不干）和预言预告的灾难来延迟兑现。这让 K 从"当前资源减法"变成"未来资源规划的约束"。

**可迁移洞察**：文明Roguelite可以采用"延迟 K"——制度选择可能不立即消耗资源，但会在 3-5 回合后开始产生结构性消耗（如工业化的污染→未来健康危机，教团化→未来思想僵化）。这让玩家的当前决策承载未来重量。

## 9. Northgard

**角色分布**（估算）：P:30 / C:10 / S:20 / K:30 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 猎人/农民/渔夫 | P | 从地块产出食物，净产出正 |
| 伐木工 | P | 从森林地块产出木材 |
| 矿工（石材/铁矿） | P | 从矿脉产出稀有资源（矿脉有限→P是临时的） |
| 村民转职（通用—>专业） | C | 形态改变：一个人从通用劳动力变为专业生产者 |
| 商人（贸易路线→克朗） | C | 货物→金币，形态改变 |
| 知识→科技树 | S | 解锁新建筑/能力/加成，不直接产资源 |
| 幸福度系统 | S | 影响人口增长速度（间接乘数） |
| 冬季（食物消耗×2-3，木材+50%） | K | 周期性消耗暴增（审判机制） |
| 殖民新地块（一次性大量食物消耗） | K | 消耗食物换取领土扩张 |
| 军事单位（征兵+维护） | K | 消耗食物/克朗换取战斗力 |
| 胜利条件（名望/贸易/智慧/统治） | T | 四种不同终端，每一种定义了资源流动的最终方向 |

**角色特征**：P+K双高 + 季节性K波动 — Northgard 的 P 和 K 都有强烈的季节节奏。夏天 P 全开攒资源，冬天 K 暴增消耗储备。这种 "P/K的季节性耦合" 是游戏的核心压力来源。

**可迁移洞察**：文明Roguelite可以采用"季节/时代周期"模型——每个时代分为建设期（P主导，治理注意力投入产出）和审判期（K主导，所有建设成果接受危机检验）。时代切换时 P/K 角色权重剧烈变化，制造"储备→消耗→评估→下一轮"的完整循环。

## Batch 1 批次总结

### 角色权重雷达图（文字描述）

```
            P(生产)
             /\
            /  \
           /    \
          /  B1  \
    T(终端)--+--C(转化)
          \      /
           \    /
            \  /
         K(消耗)--S(支持)
```

**Batch 1 平均分布**（估算）：
- P: 20%（从纯粹P接近0的Reigns到35%的Slipways/Northgard）
- C: 28%（主力角色，Stacklands/Cultist达到45%）
- S: 16%（偏低，大多数游戏的S仅提供解锁/效率）
- K: 28%（另一主力，Thronefall/Six Ages达到35-45%）
- T: 8%（明显弱，多数游戏的终端不是显式胜利条件）

**核心特征**：**C+K双主导**。Batch 1 的9款游戏共同展现了"转化+消耗"驱动短循环的模式，P和S相对弱化，T是隐性存在。

### 批次内共性模式

1. **"转化即游戏"**：Stacklands、Cultist Simulator、Slipways 的乐趣核心是发现和执行转化链，而非积累资源池。玩家追求的不是"让数字变大"，而是"看看A+B能变成什么"。

2. **K绑定了时间压力而非资源枯竭**：除Northgard（冬季）和dotAGE（老龄化）外，多数游戏的K不是"资源快用完了"的恐慌，而是"在下一次审判前我有没有做对选择"。Thronefall的夜晚、AtS的暴风雨、Reigns的条值归零——都是K作为节奏触发器。

3. **T的隐式化**：Batch 1的游戏中，仅Against the Storm有明确的、可视化的"声望条=胜利"终端。其余游戏的T要么是隐性终点（Stacklands的月之解锁、Slipways的分数排行），要么是失败条件（Reigns的条归零、Cultist的绝望），而非显式胜利。

4. **S的低占比 + 高杠杆**：S角色虽然占比低（15-20%），但往往是"改变游戏规则"的关键——AtS的蓝图选择、Northgard的科技、dotAGE的预言——S不大的数量却决定了整个C链和K策略的有效性边界。

### 2-3个最值得迁移的角色设计模式

#### 模式1：C-heavy 配方发现系统（来自 Stacklands + Cultist Simulator）

**核心机制**：将可用元素（文明节点、制度、技术、事件）做成可组合的卡牌/构件，玩家的主要操作不是采集资源而是"将A和B组合，看看会发生什么"。

**在文明Roguelite中的应用**：
- 工坊卡 + 符文矿卡 + 工匠卡 → "符文工坊"新卡（解锁符文科技线）
- 祭司团卡 + 符文工坊卡 → "符文教团"卡（宗教化转折点）
- 每局随机生成配方池（类似AtS的蓝图系统），玩家发现而非按固定树解锁

#### 模式2：K驱动的周期审判 + 延迟K（来自 Thronefall + dotAGE + Northgard）

**核心机制**：K不是均匀消耗，而是集中在周期性的"审判时刻"（夜晚/冬季/暴风雨/时代末）。审判前的 P/S 阶段是准备期，审判时刻是 K 的高密度兑现。

**在文明Roguelite中的应用**：
- 每个时代 = 3-5回合建设期（P/S主导）+ 1回合审判期（K暴增）
- 审判期的危机类型由建设期的选择决定（用了太多符文→符文潮汐审判；建了太多工坊→污染危机）
- 部分K延迟兑现（如人口老龄化的影响、制度选择的文化包袱）

#### 模式3：P=0 的纯状态平衡（来自 Reigns）

**核心机制**：取消所有资源生产，只保留少量状态维度和频繁的选择消耗。每一次抉择都是"将A状态值转移给B状态值"，生存=所有值保持在区间内。

**在文明Roguelite中的应用**：
- 只保留3-5个状态维度（稳定度/信仰凝聚力/技术扩散/阶层满意/梦境噪声）
- 每回合有2-4个治理选项，每个选项同时影响多个维度
- 引擎关注"哪个维度即将爆/归零"，而非"哪种资源不够"
- 不同文明路线改变的是：维度标签、正常区间、选择的可用选项池
