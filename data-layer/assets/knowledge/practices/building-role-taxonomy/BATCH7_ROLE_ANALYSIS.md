# Batch 7 功能角色分类分析：叙事策略 / 事件驱动治理

> 分析日期：2026-07-30
> 框架版本：五角色分类 (P/C/S/K/T)
> 游戏数量：10款
> 批次特征：叙事/事件驱动，资源主要表现为关系、承诺、信任、时间窗口、选项空间

---

## 批次概述

本批次10款游戏的共同特征：**资源 = 关系 + 承诺 + 解释权**。传统物理资源（金币、粮食、木材）退居次要，核心资源变为政治资本、派系信任、承诺债务、信息获取权和路线自主权。这使得角色分布与B1-B6批次的基建/生产类游戏有本质区别——**K (消耗) 和 S (支持) 占比显著提高**，因为事件选择本身即是消耗行为，而信息获取/选项解锁是主要的支持形态。

## 逐游戏分析

### 1. King of Dragon Pass

**角色分布（估算）**：P:15% / C:15% / S:30% / K:30% / T:10%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 季节行动槽位（每季4个） | S | 不产不转，但定义全年行动空间和节奏 |
| 劫掠邻族 | P+K | 获得牛/货物(P)，同时消耗邻族关系(K) |
| 祭祀神灵 | C+K | 消耗牛→改变神灵态度(C)，消耗行动槽(K) |
| 贸易 | C | 一种资源→另一种资源，附带关系变化 |
| 顾问系统（7人理事会） | S | 不直接产资源，提供信息/解释/选项解锁 |
| 神殿/神龛建设 | S | 解锁新的神灵行动选项 |
| 英雄探索/冒险 | P+K | 可能获得资源(P)，消耗角色安全(K) |
| 部族声誉 | S | 影响所有外交和贸易的效率/成功率 |
| 神灵态度值 | S+C | 作为支持层影响年景(C)，也可通过祭祀转化 |
| 成为龙王（终局条件） | T | 消耗多年积累的资源/关系，推进最终胜利 |

**角色特征**：S+K双高模式——顾问对同一事件的冲突解释提供了"选择空间"（S），而每个选择都消耗稀缺的行动槽位（K）。没有中立获取，每种资源收入都绑定社会关系变化。

**可迁移洞察**：文明Roguelite可以设计"顾问解释冲突"系统——同一危机事件中，不同派系/价值体系给出不同解读，玩家的选择不仅是资源最优解，更是"我相信哪种文明语法"的声明。

### 2. Six Ages 2: Lights Going Out

**角色分布（估算）**：P:15% / C:20% / S:30% / K:25% / T:10%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 季节行动槽位 | S | 同KoDP，定义治理节奏 |
| 神话仪式系统 | C+K | 消耗祭品→获得神灵恩赐(C)，消耗行动槽(K) |
| 魔法资源（仪式/附魔） | C | 将物理资源转化为超自然效果 |
| 氏族顾问（神话视角） | S | 提供基于神话逻辑的解释和选项 |
| 邻族外交 | C+K | 关系→资源/安全转化，消耗外交窗口 |
| 世界秩序理解（学习过程） | S | 玩家逐渐掌握神话规则→解锁更优策略 |
| 气候变化/年景 | P/T | 神话秩序的好坏直接影响基础产出 |
| 氏族身份塑造 | S+T | 长期选择累积为氏族"路线"，最终指向特定终局 |

**角色特征**：比KoDP多一层C（转化）——神话仪式不仅是消耗，更是"用世界观语法把资源转化为超自然效果"。S的核心在于"学习神话规则的过程本身就是玩法"。

**可迁移洞察**：文明路线不仅是策略选择，更可以是"世界观学习过程"——不同路线（符文/教团/心灵）应有不同的"规则语法"，玩家在一次次事件中学会这套语法。

### 3. Suzerain

**角色分布（估算）**：P:10% / C:20% / S:20% / K:35% / T:15%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 预算（税收收入） | P | 从经济体产出政府资金 |
| 政治资本（议员支持） | P+C | 支持本身可视为可生产/可转化的资源 |
| 承诺债务 | K | **核心消耗机制**——每个承诺都是未来必须支付的账单 |
| 预算↔政资↔支持三角兑换 | C | 三维资源转化网络 |
| 内阁成员/顾问 | S | 提供信息、特殊选项、政策建议 |
| 宪法框架 | S | 决定可用的政策空间和权力边界 |
| 情报报告 | S | 解锁隐藏信息和战略选项 |
| 外交条约/军事行动 | K+T | 消耗预算和政治资本，可能直接导致战争终局 |
| 个人财富（灰色操作） | C | 私财→政治结果的转化通道 |
| 弹劾/政变/连任/战争 | T | 多种终局条件，由累积的承诺债务决定 |

**角色特征**：K极高——承诺债务系统是核心引擎，每个决策都是"现在获得支持，未来支付成本"。C（三角兑换）也有显著占比，预算-政治资本-支持度的互相转化是日常博弈。P极低，几乎没有纯生产行为。

**可迁移洞察**：文明Roguelite中最值得迁移的是**承诺债务系统**——每项制度选择（灌溉/神权/商业）产生"未来的必然支出"，承诺过多→资源枯竭→被迫违约→制度解体。制度选择的本质是延期支付的资源成本。

### 4. The Life and Suffering of Sir Brante

**角色分布（估算）**：P:10% / C:15% / S:30% / K:30% / T:15%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 教育/学习 | P | 产出知识、技能、社会资质 |
| 家庭地位/出生阶层 | S | 决定初始可用的选项空间（解锁/锁定） |
| 人生阶段门槛（童年→青年→成年） | S+K | 早期选择定义后来的选项空间(S)，错过门槛→路线永久关闭(K) |
| 意志力/决心 | K | 每次做违背环境期望的选择都消耗意志力 |
| 家族关系网 | C+S | 关系可转化为机会(C)，也决定哪些选项可用(S) |
| 社会地位上升/下降 | C | 将个人努力→社会阶层转化的核心通路 |
| 信仰/理念选择 | S+K | 选择信仰解锁对应路线(S)，但消耗其他路线可能性(K) |
| 关键人生抉择（背叛/牺牲） | K+T | 消耗重要关系，直接影响最终命运走向 |
| 最终命运（多个结局） | T | 由所有累积选择决定的终局 |

**角色特征**：S+K双高但类型独特——S表现为"路线门槛"（够格才能走），不同于KoDP的"顾问解释多元"。K表现为"不可逆消耗"（错过永远关闭），而非有意识的资源交易。人生不能回头。

**可迁移洞察**：文明Roguelite中的**路线门槛机制**——不是"选A或选B"，而是"你的文明够不够格走A？不够格就只能走B或C"。早期选择（建神殿还是市场）应像童年塑形一样，打开某些未来、关闭另一些未来。

### 5. Yes, Your Grace

**角色分布（估算）**：P:10% / C:10% / S:15% / K:50% / T:15%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 每周请愿（接见系统） | K | **核心K**——每个请愿者都要求消耗金币/粮食/部队 |
| 税收征收 | P | 从领地定期获取金币和粮食 |
| 将军/猎人/女巫等代理人 | S | 解锁特殊行动选项和任务线 |
| 王国资源分配（金/粮/兵） | K | 在战争/家庭/请愿/盟友之间分配稀缺资源 |
| 家庭事件（女儿/王后） | K+T | 消耗情感资源和王国资源，影响终局家族命运 |
| 请愿者回访机制 | K+S | 被帮/被拒的人在后续带着后果回来——过去判断被验证 |
| 战争准备 | K+T | 大量消耗→直接关联终局战斗胜负 |
| 联盟/外交承诺 | C+K | 资源→盟友支持的转化，并产生未来义务 |
| 最终决战 | T | 所有资源分配和请愿判断的终极验证 |

**角色特征**：K极度主导（≈50%）——这款游戏的几乎一切机制都是消耗。每周请愿不是"做任务得奖励"，而是"在什么上花掉我的稀缺资源"。S不来自顾问多元解释，而来自代理人和请愿者回访带来的"判断被验证"。

**可迁移洞察**：文明Roguelite中**回访机制**的威力——被帮助/拒绝/背叛的派系和个人应在后续时代带着后果回来。不是简单的"好感度变化"，而是让玩家面临"你当年选错了，现在怎么办"的追讨时刻。

### 6. Frostpunk 2

**角色分布（估算）**：P:10% / C:15% / S:35% / K:30% / T:10%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 资源采集（热量/物资/劳动力/核心） | P | 物理资源的基础生产 |
| 派系支持 | S+K | 接受支持解锁特定路线(S)，但消耗路线自主权(K) |
| 立法系统 | S+K | 通过法律改变城市运行规则(S)，消耗政治资本和派系关系(K) |
| 派系谈判/承诺 | K | 为通过法案做出的承诺→未来必须兑现 |
| 城市规划/区划建设 | C+S | 资源→基础设施转化(C)，基础设施改变运行效率(S) |
| 派系争夺"未来解释权" | S+K | 不同派系争夺城市应该走向何方(S层面)，选择一边消耗另一边(K) |
| 科技研发 | S | 解锁新建筑、新能力、新选项 |
| 紧急措施/极端手段 | K+T | 消耗合法性换短期生存，可能导向特定终局 |
| 信任/紧张度系统 | S | 影响所有政治行动的效率和可用选项 |
| 城市终局（乌托邦/反乌托邦/灭亡） | T | 由所有路线和政治选择决定的终点 |

**角色特征**：S占比本批次最高（35%）——不是因为建筑多，而是**派系-法律-路线三角构成了极其厚重的支持层**。每个派系不是"好感度条"，而是"对城市未来的定义权竞争者"。接受派系支持 = 把他们的愿景写入法律 → 路线被绑定。

**可迁移洞察**：**派系 = 路线定义权竞争者**——文明Roguelite中，不同阶层/教派/阶级不应只是好感度。他们应争夺"文明未来应该走什么路线"。接受一个阶层的支持 = 部分放弃路线自主权。改变路线 = 背叛旧支持者 + 引发内乱。

### 7. The Pale Beyond

**角色分布（估算）**：P:10% / C:15% / S:20% / K:40% / T:15%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 狩猎/采集/补给搜索 | P | 从环境中获取食物和燃料 |
| 燃料→热量→生存链 | C | 物理资源的转化，维持生存底线 |
| 船员信任系统 | S+K | 信任影响行动效率和选项(S)，决策可能消耗信任(K) |
| 每周任务分配 | K | 有限劳动力→各项任务的消耗分配 |
| 船员专家/角色 | S | 不同船员解锁不同的应对选项 |
| 配给制决策 | K+T | 减少配给→消耗士气和健康(K)，但延长抵达时间(T) |
| 道德抉择（抛弃/牺牲） | K+T | 消耗船员信任/生命→换取整体生存，影响终局 |
| 船长领导力 | S | 影响所有船员相关的行动效果 |
| 救援/交易/外交 | C+K | 资源交换(C)，消耗时间窗口和关系(K) |
| 抵达终点（多重结局） | T | 船员存活数+道德记录决定终局品质 |

**角色特征**：K主导（40%）但不同于Yes Your Grace的"主动选择消耗"——The Pale Beyond的K更多来自**生存压力的被动消耗**。S的核心是"船员不是数字，而是有信任/怀疑/崩溃状态的个体"。

**可迁移洞察**：文明危机中**民众/派系需要信任和心理状态**，不能只是人口数字。信任 = f(决策兑现, 危机表现, 言行一致)，存在积累-崩溃曲线。当低信任时，同一指令的效率和可用选项会变化。

### 8. Roadwarden

**角色分布（估算）**：P:15% / C:10% / S:30% / K:35% / T:10%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 探索/发现 | P+S | 发现地点产出信息(P)，同时解锁新路径和选项(S) |
| 每日时间/体力 | K | **核心K**——每个行动消耗时间或体力 |
| 地区关系网 | S | 与不同聚落/人物的关系决定可用选项和信息 |
| 物品交易/礼物 | C | 物品→关系/信息的转化 |
| 笔记/线索记录 | S | 拼凑碎片信息→解锁完整理解和选项 |
| 装备系统 | S+K | 装备解锁能力(S)，消耗资源获得(K) |
| 委托/任务 | K+T | 消耗时间和资源推进，完成影响终局 |
| 危险探索 | K | 消耗健康/装备→信息/资源/关系推进 |
| 40天倒计时 | K+T | 全局时间压力，决定有多少任务可以完成 |
| 终局（多重结局） | T | 关系状态+任务完成+生存决定最终叙事 |

**角色特征**：S+K双高且S极为特殊——S在此不是顾问或派系，而是**信息获取和关系解锁**。Roadwarden的"支持层"本质是"你知道多少"和"你认识谁"。K来自时间的绝对有限性（40天倒计时）。

**可迁移洞察**：文明Roguelite可以将**信息不对称作为核心支持层**——不同文明路线不仅影响你能做什么，更影响你"知道什么"。越是封闭的路线（如教团路线），对内信息越多、对外信息越少。信息本身是资源（P），也是选项空间（S）。

### 9. Citizen Sleeper

**角色分布（估算）**：P:15% / C:25% / S:25% / K:25% / T:10%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 每日掷骰子（1-6点×N个） | P+K | 骰子产出行动点(P)，但数量/质量取决于身体状况(K的积累结果) |
| 骰子→时钟推进 | C | **核心C**——将骰子点数转化为任务/关系时钟的进度 |
| 工作/赚钱行动 | C | 骰子→金钱，最基础的转化 |
| 身体/状态维护 | K+S | 消耗金钱/物品维护身体(K)，好身体产出更多/更好的骰子(S) |
| 盟友系统 | S | 每个盟友解锁新的行动槽位和选项 |
| 升级/植入物 | S+K | 消耗资源获得→解锁新能力/提高骰子效率(S) |
| 多时钟并行（生存/任务/关系） | K | 每个时钟竞争骰子分配，放弃某时钟→它可能恶化 |
| 生存时钟（吃饭/治病） | K | 刚性消耗，不处理就死亡 |
| 关系时钟 | K+T | 消耗骰子推进关系(K)，关系线完成导向终局(T) |
| 离开空间站（多个结局） | T | 由所有时钟完成度和关系状态决定 |

**角色特征**：本批次最均衡——P/C/S/K各约20-25%。C突出（骰子→时钟进度转化是核心循环），S主要来自盟友解锁和升级系统。K的独特之处在于"放弃即消耗"（不投入骰子的时钟会恶化）。

**可迁移洞察**：文明治理可以用**有限行动点/骰子×多时钟**系统——日常治理（生存时钟、派系关系时钟、科技时钟、外交时钟）并行推进，每个时代有限行动点迫使玩家选择"优先推进哪个"，放弃的时钟可能恶化。让日常治理和长期路线互相挤压。

### 10. Wildermyth

**角色分布（估算）**：P:20% / C:15% / S:25% / K:25% / T:15%

**关键元素角色映射**：

| 机制/元素 | 角色 | 说明 |
|-----------|------|------|
| 英雄招募与成长 | P | 产出新英雄(P)，通过战斗和事件获得能力和特质(P) |
| 战斗系统 | K | 消耗HP/能力/时间→战术胜利 |
| 事件留痕（伤疤/变异/传承） | S+K | 永久改变角色外观和能力(S)，同时消耗"原来的身份"(K) |
| 角色关系系统 | S+C | 关系解锁协同能力(S)，关系→战术加成(C) |
| 魔法/变异感染 | C+S | 将"正常身体"转化为"变异身体"→新能力和外观(C+S) |
| 装备制作与升级 | C+S | 资源→装备(C)，装备改变效率(S) |
| 时间推进（日历） | K+T | 英雄会老去(K)，战役必须在有限时间内完成(T) |
| 地图巡逻/防守/建设 | S+K | 地区控制影响资源和安全(S)，消耗时间(K) |
| 英雄退休/传承 | S+T | 老英雄退休留下传承点→下一代英雄受益(S)，也是战役推进的标志(T) |
| 战役终局 | T | 击败最终Boss/完成主线故事 |

**角色特征**：最接近传统P/C/K平衡但S极为独特——S不是解锁选项或提高效率，而是**"身份改变"**。事件留痕（失去眼睛、感染变异、建立羁绊）改变的不是数值，是"这个角色是谁"。这使S层本身成为叙事内容。

**可迁移洞察**：文明事件应在文明主体/城市/制度上**永久留痕**——不只是资源变化，而是改变"这个文明长什么样"。一个城市经历瘟疫→建筑风格改变+获得医疗传统；一个制度被滥用→形态异化+产生新约束。10个事件后，文明已经不是原来的样子了。

### 角色权重雷达图描述

```
          P(生产)

        /      \
   T   /________\   C
 (10%) | BATCH 7 | (17%)
        \  平均  /

        (33%) (27%)
```

**B7平均分布**：K(33%) > S(27%) > C(17%) > P(15%) > T(10%)

与前面批次对比：
- B1（基建+轻叙事）: P+C双高
- B2（4X大战略）: P+C+S均匀
- B3（RTS+战术）: P+C双高
- B4（工厂+生存模拟）: P+C双高
- B5（卡牌+骰子Roguelike）: C+K双高
- B6（上帝视角+演化）: P+S均匀
- **B7（叙事策略/事件治理）: K+S双高** ← 独特模式

### 批次内共性模式

#### 模式1：事件即消耗（K主导）
本批次10款游戏的全部共性是**事件选择 = 消耗行为**，而非"读题得奖励"。在传统策略游戏中，随机事件通常是净正收益（奖励事件）或负面惩罚。在叙事治理游戏中，每个事件都是一道"资源分配题"——花什么、花在哪里、花在谁身上。这解释了K(33%)的显著占比。

#### 模式2：支持 = 信息 + 选项解锁（S的叙事化）
S在本批次不表现为"仓库/电线杆/研究站"类的基础设施，而是：
- **信息获取**：顾问解释（KoDP）、情报报告（Suzerain）、线索拼图（Roadwarden）
- **选项解锁**：路线门槛（Sir Brante）、盟友行动槽（Citizen Sleeper）、法律框架（Frostpunk 2）
- **判断辅助**：回访验证（Yes Your Grace）、信任状态（The Pale Beyond）

S层的"叙事化"是本批次最值得迁移的设计模式。

#### 模式3：资源形态的高度抽象
本批次游戏的"资源"概念需要大幅扩展：

| 物理资源 | 社会资源 | 认知资源 |
|----------|----------|----------|
| 金币/粮食/燃料 | 政治资本/派系支持 | 信息/世界观理解 |
| 劳动力/体力 | 承诺债务/路线自主权 | 选项空间/可能性 |
| 物资/装备 | 信任/关系网络 | 时间窗口/行动槽 |

传统策略游戏的P（生产）主要作用于物理资源，而叙事治理游戏的P/C/S/K作用于更抽象的社会和认知资源。

#### 模式4：延迟反馈 = K的独特表现
多款游戏共享"承诺→延迟追讨"模式：
- Suzerain: 承诺→兑现→违约→崩塌
- KoDP: 得罪神灵→几年后灾难
- Yes Your Grace: 帮/拒请愿者→后续带后果回来
- Frostpunk 2: 接受派系支持→路线被绑定
- The Pale Beyond: 决策→信任积累/崩溃

这种延迟反馈使K（消耗）不是一次性的，而是"现在消耗未来"的债务关系。

### 2-3个最值得迁移的角色设计模式

#### 迁移模式1：承诺债务 + 路线门槛（S+K复合）
**来源**：Suzerain + Sir Brante + Frostpunk 2

对于文明Roguelite的设计启示：
```
制度选择 → 产生"未来必须支付"的资源成本（承诺债务）
早期选择 → 设定后续路线的能力门槛（路线门槛）
接受派系支持 → 消耗路线自主权（解释权让渡）

实现示例：
  选择"灌溉文明"→ 承诺每时代维护水利（消耗治理注意力）
  → 早期没选"水利工程"科技 → 灌溉路线门槛不达标 → 路线关闭
  → 为了保证灌溉承诺，接受"农业派系"支持 → 城市发展方向被绑定
```

**角色分布影响**：使K从"一次性消耗"升级为"跨时代债务"，使S从"效率buff"升级为"路线资格"。

#### 迁移模式2：有限行动点 × 多时钟并行（C+K复合）
**来源**：Citizen Sleeper + Roadwarden + The Pale Beyond

对于文明Roguelite的设计启示：
```
每个时代有限行动点数（或骰子点数）
多个时钟并行推进：
  - 生存时钟（粮食/疾病/灾难）→ 不投入就恶化
  - 发展时钟（科技/基建/经济）→ 投入就推进
  - 派系时钟（各阶层关系）→ 不维护就疏远
  - 外交时钟（邻国/贸易）→ 有机会窗口

玩家选择 = 每个时代"优先推进哪个时钟"
放弃的时钟 → 恶化 → 产生危机事件 → 又消耗更多行动点
```

**角色分布影响**：将C（骰子/行动点→时钟进度）作为核心循环，使K（放弃的时钟）成为隐性消耗。

#### 迁移模式3：事件留痕 = 身份永久改变（S独特形态）
**来源**：Wildermyth + KoDP + Sir Brante

对于文明Roguelite的设计启示：
```
文明事件结果应改变"这个文明是谁"，而不只是资源数值：
  - 经历大瘟疫 → 城市建筑风格+卫生制度+人口结构永久改变
  - 与神灵立约 → 获得特殊能力+承受特定约束+文明外观变化
  - 文化融合 → 科技树分支改变+建筑外观混合+产生新传统

留痕的三个维度：
  1. 能力留痕：解锁/关闭特定科技或行动
  2. 外观留痕：城市、人物、地图永久视觉变化
  3. 叙事留痕：历史记录影响后续事件池和选项

10个事件后，文明已经不再是原来的文明。
```

**角色分布影响**：使S层从"功能性支持"升级为"身份性支持"——解锁的不是行动选项，而是"成为某种文明的可能性"。

## 批次总结

```text
叙事策略/事件驱动治理的P/C/S/K/T分布有别于所有其他批次：
- K(33%) 主导 → 因为"事件选择"本质上就是消耗行为
- S(27%) 次高 → 因为信息/关系/选项解锁是本批次的"支持层"
- P(15%) 最低 → 因为几乎没有"凭空产出"的纯生产行为
- 核心公式：事件 = 有立场的消耗 + 被记住的承诺 + 会追讨的代价

对文明Roguelite而言，本批次的核心启示是：
不要把事件设计成"选择题→奖励"，而要设计成
"消耗什么资源、对谁做出承诺、放弃什么选项、改变什么身份"。
```
