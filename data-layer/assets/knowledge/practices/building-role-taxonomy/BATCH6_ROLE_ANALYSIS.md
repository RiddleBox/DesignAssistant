# Batch 6 角色分类分析：文明演化 / 神话 / 抽象世界模拟

> 2026-07-30 | 基于资源经济深度拆解 + 好玩点分析 + Final Audit
> 本批次核心特征：低操作密度、形态变化驱动、阶段跃迁感

---

## 1. Spore

**角色分布（估算）**：P:30% / C:25% / S:20% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 进食获取DNA点数 | **P** | 从环境凭空产出进化能量 |
| 任务/目标奖励DNA | **P** | 达成里程碑凭空产出资源 |
| 部件购买（DNA→部件） | **C** | DNA→身体能力（资源→能力转化） |
| 部件组合（嘴+脚+武器） | **C** | 多个部件→复合行为签名（聚合转化） |
| 肉食嘴（限制食物类型） | **S** | 改变可吃什么的规则（S是因为它改变后续P的可能来源） |
| 社交部件（只能外交） | **S** | 改变互动规则（能力解锁而非资源转化） |
| 阶段跃迁（细胞→生物→部落→文明→太空） | **S** | 改变整个资源体系和玩法语法 |
| 食物消耗（维持生存） | **K** | 食物→生存状态（消耗换状态） |
| 攻击/社交行为 | **K** | DNA/食物→战斗/外交结果（消耗换进度） |
| 太空阶段银河目标 | **T** | 终局胜利条件 |

**角色特征**：P极高+C中高——Spore的乐趣在于"不断收集DNA(P)并转化为部件(C)来改变身体形态"。阶段跃迁是最独特的S层：每个阶段重构整个P/C/K体系。框架文档归类为P极高型。

**可迁移洞察**：文明路线跃迁时重构P/C/S/K/T比重——工业时代P层主导（采矿=生产率），符文时代C层主导（符文矿→能量=转化链），心灵时代S层主导（共识强度=规则修改）。不是数值升级，而是整个角色权重分布改变。

## 2. Terra Nil

**角色分布（估算）**：P:5% / C:15% / S:40% / K:30% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 树叶/能量（起始固定量） | **P** | 开局凭空获得，不可补充（一次性P层） |
| 风机/水泵（树叶→地形改造） | **K** | 消耗树叶→改变湿度/温度（消耗换生态状态） |
| 灌溉器（树叶→生态恢复） | **K** | 消耗树叶→绿色覆盖（消耗换环境健康度） |
| 生态建筑（树叶→生物群落） | **K** | 消耗树叶→多样生态（消耗换系统状态） |
| 建筑回收（返还树叶） | **S** | 不产新资源，但回收已有投入（逆向操作） |
| 生物量/湿度/温度 | **S** | 环境健康指标——不产不转，只是状态阈值 |
| 地形约束（可用格子） | **S** | 操作空间限制规则 |
| 相邻效应（建筑间协同） | **S** | 不产资源但改变建筑效率 |
| 撤退/离开（最终回收人造痕迹） | **S** | 清除自身存在 |
| 环境健康达标检测 | **T** | 终端——是否成功修复 |

**角色特征**：S极高+K高——Terra Nil是罕见的"逆向公式"游戏。P层只有开局一次，之后所有操作都是K层（消耗树叶换生态状态）和S层（回收/撤退/相邻优化）。传统的"扩张→更多P→更多扩张"循环被完全逆转。

**可迁移洞察**：文明衰退/净化可以是一条合法路线——不是所有文明都要"更大更强"。某些文明路线可以选择"消除工业痕迹→恢复自然→撤退"作为胜利条件。T层（终端）不一定只是扩张到银河。

## 3. Dorfromantik

**角色分布（估算）**：P:10% / C:30% / S:40% / K:5% / T:15%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 任务奖励（新地块） | **P** | 完成任务凭空产出新拼图片 |
| 地块放置 | **C** | 地块→地图形态（一片资源变成世界形态） |
| 边缘匹配（相邻地块种类相同） | **C** | 匹配=资源→任务进度转化 |
| 任务系统（如"连接50棵树"） | **T** | 完成得地块（终端出口→又回到P层） |
| 旋转地块 | **S** | 不产不转，但改变匹配可能性 |
| 空间预留（保留开放边） | **S** | 不产资源，但为未来增加操作空间 |
| 村庄/森林/铁路/河流延伸 | **S** | 视觉成形规则（美学的"完成"感） |
| 地块不可撤回 | **S** | 棘轮约束规则 |
| 匹配失败（破坏成形美感） | **S** | 负面S层——降低未来匹配可能性 |
| 地图终局判定 | **T** | 无法继续放置时结算 |

**角色特征**：C+S双高——Dorfromantik的核心是"地块→匹配→任务→新地块"的C层闭合循环。S层（旋转/预留/不可撤回）决定转化效率和质量。T层独特：任务完成本身就是终端+新P层入口，形成"T→P→C→T"自持循环。

**可迁移洞察**：文明地图的"渐进成形"——每个文明节点的放置是永久的、可见的。S层（空间预留、相邻规则）决定最终成形质量。任务系统提供"T→P"的续航动力（完成任务→获得更多节点）。

## 4. Islanders

**角色分布（估算）**：P:10% / C:30% / S:30% / K:10% / T:20%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 建筑包（随机分配） | **P** | 凭空获得一组建筑选项 |
| 建筑放置 | **C** | 建筑→分数（资源→进度转化） |
| 邻近加分/扣分逻辑 | **C** | 空间关系→分数变化（转化规则） |
| 分数阈值→新建筑包 | **C** | 分数→新机会（进度→资源转化） |
| 建筑包选择 | **S** | 选择决定城市风格方向（路线塑形） |
| 空间预留（高分位要不要现在用） | **S** | 不产资源但改变未来转化效率 |
| 开新区域 | **S** | 扩展操作空间（能力解锁） |
| 建筑密集/分散决策 | **S** | 空间策略（效率优化） |
| 分数不足断供 | **T** | 无法继续获得新建筑包的临界点 |
| 岛屿完成度 | **T** | 该岛是否完成的终端判定 |

**角色特征**：C+S主导——"建筑包→放置→分数→新包"是典型C层循环。S层（建筑包选择/空间预留/密集vs分散）塑造每局的城市风格。T层驱动（分数阈值为终端出口决定续航）。

**可迁移洞察**：制度/事件包的"路线分化"——每组制度包的邻近关系（工业制度靠近矿脉=高分，靠近神殿=冲突扣分）自然的塑造文明风格。不同包选择产生截然不同的城市（文明）。

## 5. Reus / Reus 2

**角色分布（估算）**：P:20% / C:30% / S:25% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 巨人能力创建资源 | **P** | 神力凭空产出地形/资源 |
| 地形改造（沙漠→森林→沼泽） | **C** | 一种地形→另一种地形（资源形态转化） |
| 资源→村庄成长 | **C** | 食物/财富/科技→人口/发展（资源→文明状态） |
| 巨人能力协同 | **S** | 多巨人组合改变产出效率（非资源转化） |
| 村庄需求系统 | **S** | 需求引导资源配置方向（方向规则） |
| 村庄野心/贪婪 | **S** | 村庄自反噬——成长后产生负面需求（规则反作用） |
| 项目需求（特定资源组合） | **C** | 多资源→完成项目（聚合转化） |
| 村庄冲突 | **K** | 支持A村庄消耗B村庄的资源（消耗换选择） |
| 生态失控 | **T** | 贪婪过度导致系统崩溃 |
| 项目完成 | **T** | 阶段胜利条件 |

**角色特征**：C层最高——"巨人→资源(P)→地形改造(C)→村庄成长(C)→项目完成(T)"是主要的资源流。独特的S层是"村庄的反作用"：给予的支持会转化为野心和贪婪，形成对玩家的反噬约束。

**可迁移洞察**：文明扶持的"反作用"——给文明提供制度/资源/技术(P)，会触发文明的野心/依赖/贪婪(S层反向约束)。强扶持=未来强反作用。这不只是资源转化，而是系统级别的"因果债务"。

## 6. The Universim

**角色分布（估算）**：P:15% / C:20% / S:35% / K:20% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 自然资源采集 | **P** | 从环境凭空产出食物/水/材料 |
| 建筑建造 | **C** | 资源→建筑→产能（资源→基础设施转化） |
| 神力干预（直接解决灾害） | **K** | 神力→问题消除（消耗神力换状态） |
| 科技/时代推进 | **S** | 解锁新能力（非资源产出） |
| 居民需求系统 | **S** | 需求引导资源配置（方向规则） |
| 灾害预报 | **S** | 信息层——不产资源但改变决策质量 |
| 文明自演（不干预时的自行发展） | **S** | 系统自驱动力（不依赖玩家P层输入） |
| 人口增长 | **P** | 居民自行繁衍（内生P层） |
| 资源短缺→文明衰退 | **T** | 资源耗尽导致阶段审判 |
| 时代跃迁门槛 | **T** | 科技条件达成则阶段推进 |

**角色特征**：S层为主——The Universim的核心不是"玩家操作流程"而是"文明自演+神力干预时机"。S层包括需求引导、灾害预报和最重要的"文明自演"——这是罕见的"系统自带P层"设计（文明自己成长，不需要玩家持续操作）。

**可迁移洞察**：文明自演的"内生P层"——文明不需要玩家每步都操作。玩家P层（治理干预）是稀缺的（如每回合3次干预），但文明自己有内生P层（人口增长/贸易/文化传播）。S层就是决定"什么时候干预、什么时候放手"。

## 7. WorldBox

**角色分布（估算）**：P:20% / C:10% / S:45% / K:10% / T:15%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 放置种族/动物/资源 | **P** | 投放初始变量→世界开始产出 |
| 地形笔刷（山脉/海洋等） | **P** | 凭空塑造地形（环境产出） |
| 灾害投放（陨石/瘟疫/战争） | **K** | 消耗世界稳定性→涌现新状态 |
| 神器投放 | **S** | 改变特定文明的竞争规则 |
| 文明间自发战争/贸易 | **S** | 系统自驱动力（不依赖玩家） |
| 边界变化/城市蔓延 | **S** | 涌现规则（非玩家手动操作） |
| 世界规则设置 | **S** | 底层参数决定涌现可能性 |
| 观察涌现故事 | **S** | 叙事层——玩家脑补因果链 |
| 文明毁灭 | **T** | 某个文明的终局 |
| 世界状态重置 | **T** | 整体是否"达成满意形态" |

**角色特征**：S极高（45%）——WorldBox的极端S层权重源于"玩家大部分时间在观察、而非操作"。P层只在开局投放变量时使用一次，之后系统自持运转。S层包括设置规则、观察涌现、脑补叙事。K层（灾害）和T层（毁灭/重置）是可选动作。

**可迁移洞察**：文明Roguelite中的"变量投放→观察涌现"——开局投放少数关键变量（地理奇观/初始制度/神话遗产），然后观察文明如何在这些约束下自行演化。玩家S层干预是稀缺点，大部分时间是观察涌现。

## 8. Cell to Singularity

**角色分布（估算）**：P:70% / C:10% / S:10% / K:5% / T:5%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 点击/自动产出资源 | **P** | 极高比例的纯凭空产出（idle核心） |
| 资源→解锁演化节点 | **C** | 资源→新节点（形态转化） |
| 升级加速产出 | **S** | 提升P层效率（极少量的S） |
| 演化树逐级展开 | **P** | 新节点=新P层来源（解锁更多产出） |
| 文明/科技阶段 | **S** | 阶段跃迁改变产出方式（轻微S） |
| 终局（演化树填满） | **T** | 完成所有节点 |

**角色特征**：P极高（70%）——Cell to Singularity是P层极端的典型idle游戏。几乎所有内容都是"更多产出→更多P层来源→更多产出"的正反馈循环。S/C/K/T层极为薄弱，这是其在Final Audit中被降为C级的核心原因（缺少有代价的抉择）。

**可迁移洞察**：纯P层主导的游戏缺少Roguelite所需的"失败压力"和"抉择深度"。文明Roguelite需要足够的C/S/K/T层来平衡P层，否则会变成"越做越大但没压力"的idle simulator。演化树可视化本身有参考价值（宏观阶段感），但单独的P层循环不可取。

## 9. Evolution Board Game

**角色分布（估算）**：P:15% / C:20% / S:30% / K:25% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 出性状牌（增加能力） | **S** | 赋予物种新规则（非资源产出，是能力解锁） |
| 增加种群（扩大数量） | **P** | 更多的生物体=更多进食口（扩大P层） |
| 增加体型 | **S** | 改变攻防规则（不产资源，改互动规则） |
| 取食阶段（从食物池进食） | **P** | 从公共食物池获取食物（环境产出） |
| 捕食（攻击其他物种） | **K** | 体型/性状→消灭其他物种→获得食物（消耗+转化） |
| 防御性状（壳/毒/合作） | **S** | 改变被攻击后的结果（规则修改） |
| 食物池减少（生态压力） | **T** | 资源不足→种群饿死（环境审判） |
| 性状组合（肉食+大体型+合作） | **C** | 多性状→复合生态位（聚合转化） |
| 生态位声明（我的物种适合什么） | **S** | 选择决定在生态中的位置 |
| 饿死/灭绝 | **T** | 物种终局 |

**角色特征**：S層最高——Evolution的性状不是"资源产出"而是"生态规则声明"。每种性状（肉食/毒/壳/合作）都是S层（改变互动规则），而非P层（产出资源）。K层（捕食）消耗己方性状换对方消亡。最终审判（T）是食物池枯竭时的取食阶段。

**可迁移洞察**：文明路线要素应是"生态位声明"而非"数值buff"——工业路线：声称"我能高效利用矿物"（S层新规则）；符文路线：声称"我能从仪式获得能量"（S层新规则）；心灵路线：声称"我能从共识获取力量"（S层新规则）。每种声明改变文明与环境的互动方式，不只是产出效率。

## 10. Niche

**角色分布（估算）**：P:15% / C:25% / S:30% / K:15% / T:15%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 采集食物 | **P** | 从环境产出生存资源 |
| 繁殖（选择基因组合） | **C** | 父母基因→后代基因（代际转化） |
| 移动/探索 | **S** | 不产资源但发现新食物来源/危险 |
| 基因性状（速度/嗅觉/抗病） | **S** | 赋予个体新能力规则（非资源产出） |
| 近亲繁殖 | **S** | 繁殖规则约束（改变后代基因质量） |
| 跨岛迁徙 | **S** | 改变环境约束（能力解锁新空间） |
| 食物短缺→饥饿 | **K** | 生物量→生存状态（消耗换生存） |
| 捕食者攻击 | **K** | 生物体→被消灭（外部消耗） |
| 疾病压力 | **K** | 基因劣势→种群损失（代际后果兑现） |
| 族群灭绝/延续 | **T** | 终端判定（是否存活过N代） |

**角色特征**：C+S双高——Niche的核心是"基因选择(C)×跨代后果(S)"。C层（繁殖=基因→后代基因）是跨代的转化链。S层（基因性状/探索/迁徙/近亲约束）决定代际转化的质量和方向。关键的T层不是"胜利"而是"是否活过N代"。

**可迁移洞察**：文明制度的"跨代后果"——今天的制度选择(C)，变成下一代文明的能力和缺陷(S层约束)。选工业标准化→后代获得高效率但失去灵活性(S)。选符文仪式→后代获得奇迹能力但积累污染债务(S)。当前选择约束未来的S层空间。

## 11. Sapiens

**角色分布（估算）**：P:20% / C:20% / S:35% / K:15% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 采集/狩猎 | **P** | 从环境产出食物/材料 |
| 制作工具 | **C** | 材料→工具（资源→能力转化） |
| 建造庇护所 | **C** | 材料→建筑（资源→基础设施转化） |
| 学习新技能（用火/种植/冶炼） | **S** | 解锁新生活方式（能力解锁，非资源产出） |
| 人类指派（分配人力） | **S** | 不产资源但改变资源流向 |
| 地形/资源分布 | **S** | 环境约束决定发展路径 |
| 生产链形成 | **C** | 采集→加工→产品（多步转化） |
| 食物消耗 | **K** | 食物→人口维持（消耗换生存） |
| 季节/天气压力 | **K** | 外部消耗（冬季需要更多食物） |
| 部落稳定/生存 | **T** | 终端判定 |

**角色特征**：S层为主——Sapiens的好玩来自"学会什么→改变生活方式"的质变感。S层（技能解锁/人力分配/环境约束）定义文明的"生活方式语法"。C层（制作链）是执行管道，P层（采集）提供原料。

**可迁移洞察**：文明早期阶段的"生活方式变化"比资源种类增加更关键——不是从5种资源到10种资源，而是"学会用火→改变食物消耗规则(S)"，"学会冶炼→改变工具制作规则(S)"，"学会种植→改变食物产出方式(P→从狩猎P变为农业P)"。

## 12. From Dust

**角色分布（估算）**：P:15% / C:30% / S:25% / K:20% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 抓取地形物质（沙/水/岩浆） | **P** | 从环境获取可塑形物质 |
| 放置物质→改变地形 | **C** | 物质→新地形（资源→空间转化） |
| 岩浆遇水→造陆 | **C** | 两种物质→新陆地（融合转化） |
| 水遇低洼→成湖 | **C** | 物质+地形→水体（条件转化） |
| 植物遇水→繁殖 | **C** | 植物+水→更多植物（增殖转化） |
| 引导水流/岩浆流 | **S** | 不产物质但改变流向（物理规则利用） |
| 自然灾害（洪水/海啸/火山） | **K** | 环境消耗已有的地形/生命 |
| 建造防护 | **S** | 不产资源但改变灾害影响 |
| 村民到达图腾 | **T** | 关卡终端判定 |
| 物理因果链（A导致B导致C） | **S** | 系统因果规则（非玩家直接操作） |

**角色特征**：C层最高——From Dust的核心是"物质物理操控=直接因果C链"。玩家不通过菜单操作，而是直接抓取物质→改变地形→影响生态→影响部落。C链的即时可见反馈是其最大特色："放岩浆→遇水→冒蒸汽→凝固成陆地"，全部在秒级内可见。

**可迁移洞察**：文明中的"超自然力量"必须对世界产生可见因果反馈——符文化→地形改变→可见。心灵力量→影响天气→可见。教团仪式→改变人口行为→可见。不是做菜单按钮，而是创造"放X→世界变Y→导致Z"的直接因果链。

## Batch 6 批量分析

### 角色权重雷达图描述

```
        P
       / \
      /   \
     /     \
    S ----- C
     \     /
      \   /
       \ /
        K
        |
        T
```

- **P（资源生产）**：跨度极大（5%-70%），从Terra Nil的几乎无P到Cell to Singularity的P主导
- **C（资源转化）**：中高（15%-30%），"物质→形态"的核心转化通道
- **S（运转支持）**：中高至极高（20%-45%），形态变化+阶段跃迁的主要驱动力
- **K（资源消耗）**：中等（5%-30%），不强调高频消耗，更注重"环境消耗+阶段审判"
- **T（资源终端）**：中等（5%-20%），形式多样（环境健康度/灭绝/阶段门槛/地图完成）

**集体特征**：S层权重在大多数游戏中最高（平均约31%），与Batch 5相似。但Batch 6的S层含义不同——不是"效率优化"而是"形态变化+阶段跃迁+世界规则设置"。P层存在极端分化（从几乎无到绝对主导），反映了批次内游戏的多样性。

### 批次内共性模式

1. **S层="形态变化驱动力"**：Batch 6的S层不是"删牌/升级/装备调整"（Batch 5式），而是"阶段跃迁/地形改变/规则设置/生态位声明/生活方式解锁"。S层定义"文明能成为什么"，而非"做得多好"。

2. **C层=物质/基因→形态的可见转化**：Spore的DNA→部件→身体、From Dust的物质→地形、Evolution的性状→生态位、Niche的基因→后代。C层的结果是"可见的形态变化"，不只是数值变化。

3. **P层=自驱还是外驱？**：关键分化——Spore/Cell to Singularity的P层是玩家驱动的；WorldBox/The Universim的P层有部分系统自驱（文明自行成长）。自驱P层减少操作密度需求。

4. **T层=不是"胜利"而是"形态达成"**：不像Batch 5的"击败Boss"，Batch 6的T层更松散——环境健康达标(Terra Nil)、地图完成(Dorfromantik)、物种存活N代(Niche)、文明风格成形(Islanders)。T层是"一种满意状态"而非"击败敌人"。

5. **K层=环境/生态压力**：不是主动消耗（主动攻击），而是被动消耗——食物短缺/灾害/灭绝压力/生态失控。K层是"世界对文明的压力测试"。

6. **阶段跃迁=C/S/T复合现象**：Spore的阶段跃迁同时涉及：C层（资源体系完全变化）、S层（规则改变）、T层（旧阶段终点=新阶段起点）。

### 最值得迁移的角色设计模式

#### 模式1：S层"生态位声明"（Evolution + Niche）

**核心**：文明路线组件不是"产出+10%"的P层buff，而是改变文明在系统中位置的S层声明。

```
工业路线 = 声明"我能高效利用矿物"（改变资源→产能的C层效率）
         + 约束"我不擅长仪式性解决方案"（限制S层选项）
符文路线 = 声明"我能从仪式获取力量"（开辟新的P层来源）
         + 约束"我会积累污染"（引入新的K层压力）
```

每种路线是完整的P/C/S/K/T小循环，而非单一角色的属性修改。

#### 模式2："修复型T层"（Terra Nil）

**核心**：终端不只是"扩张到最大"，还可以是"回复到最佳状态"。

```
传统文明Roguelite T层：征服所有区域 / 科技达到顶点 / 信仰统一世界
Terra Nil式T层：恢复所有荒地 / 撤除所有人造物 / 让自然自持运转
```

在文明Roguelite中，可以设计"净化路线"：不是消除对手，而是消除自己留下的痕迹。这是传统4X中几乎不存在但极具戏剧张力的T层设计。

#### 模式3：P层"自驱系统"（The Universim + WorldBox）

**核心**：文明不需要玩家每回合都操作。设计"内生P层"——文明自己会成长、贸易、冲突、演化。玩家P层（治理干预）是稀缺资源。

```
玩家治理注意力(P层)：每阶段3次干预
文明内生P层：人口增长/贸易/文化传播/技术扩散
S层：决定干预时机和方向（不看则自演，干预则引导）
T层：文明是否达到"满意状态"（不是"击败所有对手"）
```
