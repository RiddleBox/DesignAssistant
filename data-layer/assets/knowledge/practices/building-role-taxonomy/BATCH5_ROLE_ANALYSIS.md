# Batch 5 角色分类分析：卡牌 / 骰子 / 构筑 Roguelite

> 2026-07-30 | 基于资源经济深度拆解 + 好玩点分析 + Final Audit
> 注意：本批次"资源"概念抽象——能量/法力/骰面/手牌槽位/重投次数/金币/血量/回合数均视为资源

## 1. Slay the Spire

**角色分布（估算）**：P:10% / C:35% / S:25% / K:20% / T:10%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 能量（每回合获得） | **P** | 凭空产出行动点，净产出为正 |
| 攻击牌（如 Strike） | **K** | 能量→伤害（消耗资源换进度） |
| 技能牌（如 Defend） | **K** | 能量→格挡（消耗资源换状态） |
| 能力牌（如 Barricade） | **S** | 改变规则但不直接转化/产出资源 |
| 遗物（如 Snecko Eye） | **S** | 改变抽牌/能量规则，非直接资源产出 |
| 药水 | **K** | 消耗（使用后消失）换战术效果 |
| 商店删牌 | **S** | 压缩牌组提高效率（不产不转，优化系统） |
| 篝火升级 | **S** | 提高单卡效率（不产新资源） |
| Boss遗物（如+1能量） | **P** | 每回合凭空多产1能量 |
| Boss战 | **T** | 决定能否进入下一层（与通关直接关联） |

**角色特征**：C+K为主导——"能量→卡牌效果→伤害/格挡"的转化+消耗闭环。S层（遗物+删牌+升级）决定构筑质量。框架文档归类为C+K双高。

**可迁移洞察**：文明Roguelite需要"获得+删除+升级"三层构筑——不只是加制度（P/C），也要削制度（S）和升级制度（S）。路线选择本身就是S层（改变未来资源流向）。

## 2. Balatro

**角色分布（估算）**：P:5% / C:40% / S:35% / K:15% / T:5%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 手牌（每回合抽取） | **P** | 从牌组凭空产出可用牌 |
| 弃牌 | **S** | 不产资源但改变手牌质量（概率塑形） |
| 出牌 | **K** | 消耗手牌+出牌次数→筹码/倍率 |
| Joker卡（如 +4 Mult） | **C** | 输入筹码/倍率→输出更高筹码/倍率（乘法转化） |
| Joker卡（如 x3 Mult） | **C** | 同上，更强的转化乘数 |
| 塔罗牌（改造牌面） | **C** | 改变牌面值（资源形态转化） |
| 星球牌（提升牌型等级） | **S** | 提升基础倍率/筹码（效率增益） |
| 金币 | **P** | 每回合凭空产出，可用于购买 |
| 商店购买Joker | **C** | 金币→引擎组件（资源投资转化） |
| Boss盲注 | **T** | 分数不够则失败（终端判定） |

**角色特征**：C+S为主导——"Joker触发链=乘法引擎"是典型的C层组合，S层（弃牌+星球牌+Joker排列顺序）决定转化效率。C+S权重和框架文档归类完全一致。

**可迁移洞察**：文明制度的"触发顺序"就是C层排列——工业法令先于劳工法 vs 劳工法先于工业法令，产出结果完全不同。S层（制度排列、废除旧法）决定C层引擎强度。

## 3. Slice & Dice

**角色分布（估算）**：P:25% / C:25% / S:30% / K:15% / T:5%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 骰子掷出（每回合） | **P** | 凭空产出6个骰面（概率资源产出） |
| 重掷 | **S** | 不产新资源但改善骰面质量（概率塑形） |
| 攻击骰面 | **K** | 骰面→伤害（消耗资源换进度） |
| 护盾骰面 | **K** | 骰面→防御（消耗资源换状态） |
| 治疗骰面 | **K** | 骰面→生命恢复（消耗资源换生存） |
| 法力骰面 | **C** | 骰面→法力（一类资源变为第二类） |
| 升级替换骰面 | **C** | 旧骰面→新骰面（行为签名重塑） |
| 道具/装备 | **S** | 改变骰面效果或规则 |
| 敌人回合 | **T** | 生存/死亡判定 |
| 角色升级选择 | **S** | 不可逆路线锁定（不产不转，改变方向） |

**角色特征**：P-C-S三足鼎立——骰子掷出是P（每回合凭空产出），骰面替换是C（旧→新行为），重掷和升级是S（效率+方向）。这是"概率塑形"角色的典型案例。

**可迁移洞察**：文明节点的"骰面化"——边疆要塞的6个可能行为（征兵/抗税/保境/私战/投诚/叛乱），升级就是替换骰面。P（每回合随机产出事件）、C（制度替换旧规则）、S（治理注意力改善概率分布）三者的互动是其核心深度来源。

## 4. Dicey Dungeons

**角色分布（估算）**：P:30% / C:20% / S:20% / K:25% / T:5%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 每回合掷骰 | **P** | 凭空产出N个骰子（通用行动货币） |
| 装备槽放入骰子 | **C** | 骰子→伤害/护盾/状态（通用货币→具体效果） |
| 攻击装备 | **K** | 骰点→伤害（消耗资源换进度） |
| 防御装备 | **K** | 骰点→护盾（消耗资源换状态） |
| 状态装备（如冰冻） | **S** | 改变后续规则（非资源转化） |
| 装备选择/替换 | **S** | 改变槽位配置（不产不转，效率优化） |
| 多骰组合装备 | **C** | 多个骰子→更强效果（聚合转化） |
| 升级新装备 | **S** | 扩展可用槽位/能力 |
| 生命值（EP） | **T** | 归零则失败 |
| 职业特殊规则 | **S** | 底层规则塑形（如战士vs巫师） |

**角色特征**：P+K为主导——"掷骰(P)→槽位分配(C)→伤害/护盾(K)"是一条完整的P→C→K流水线。槽位冲突（同一骰子不能同时放A和B）是其核心S层决策。

**可迁移洞察**：治理注意力的"槽位分配"模型——每回合6点注意力(P)，投入不同文明节点产生不同价值。槽位限制迫使用途冲突："镇压叛乱"和"推行改革"争夺同一个注意力点。S层就是槽位配置策略。

## 5. Luck be a Landlord

**角色分布（估算）**：P:30% / C:30% / S:25% / K:10% / T:5%

**关键元素角色映射**：

| 元素 | 角色 | 说明 |
|------|------|------|
| 每回合从符号池抽符号 | **P** | 凭空产出符号资源 |
| 符号→金币（基础产出） | **C** | 符号→金币（资源形态转化） |
| 动物符号（消耗植物） | **C** | 植物符号→动物符号→更多金币（转化链） |
| 阳光/雨水符号（buff相邻） | **S** | 不产不转，但提升相邻符号效率 |
| 黄金符号（基础高产） | **P** | 高净产出但无协同 |
| 删除低效符号 | **S** | 净化池子提升抽中高价值符号概率 |
| 道具（改变规则） | **S** | 底层规则修改器 |
| 租金（每回合消耗） | **T** | 金币不够付租金则失败 |
| 选择新符号加入池子 | **C** | 金币/机会→新符号（投资改变未来池子） |
| 特殊符号（改变相邻规则） | **S** | 规则修改而非资源转化 |

**角色特征**：P-C-S三足鼎立——符号生态=P产出+C转化链+S相邻增益。核心公式是"池子质量=好符号/总符号数"，S层（删除+道具）决定池子净化程度。框架文档归类为C+S双高。

**可迁移洞察**：文明事件池的"生态搭配"——发展型(P)、转化型(C)、增益型(S)事件需要合理比例。每次选择新制度都在"污染或净化未来的文明事件池"。S层的删减（废除旧制度）比P层的叠加（颁布新法）更关键。

**关键元素角色映射**：

| 元素 | 角色 | 说明 |

| 移动（调整站位） | **S** | 不产不转，但改变谁先被攻击 |

| 皇冠（开场buff） | **S** | 改变初始规则/状态 |

**可迁移洞察**：文明危机的"可干预倒计时"——5回合后符文潮汐(P产出压力)，玩家用S层（治理注意力分配、制度调试）提前干预。倒计时让"做了准备"vs"没做准备"的差异可视化。

## Batch 5 批量分析

### 角色权重雷达图描述

```
        P
       / \
      /   \
     /     \
    S ----- C
     \     /
      \   /
       \ /
        K
        |
        T
```

- **P（资源生产）**：偏低（5%-30%），卡牌游戏的"资源"本身就是稀缺设计
- **C（资源转化）**：中高（15%-40%），卡牌游戏核心是"资源→效果"的转化链
- **S（运转支持）**：中高至极高（20%-40%），卡牌游戏深度的主要来源
- **K（资源消耗）**：中高（15%-35%），攻击/防御/效果消耗资源
- **T（资源终端）**：低（5%-10%），Boss战/盲注/生命归零形式单一

**集体特征**：S层在所有10款游戏中占比最高（平均约31%），远超其他角色。这说明卡牌Roguelite的核心深度不在"产出更多资源"或"更多转化链"，而在"如何高效运转已有系统"。

### 批次内共性模式

1. **S层驱动深度**：所有游戏的S层（遗物/删牌/弃牌/站位/倒计时干预/槽位配置/规则破坏）是区分"新手"和"高手"的关键。P/C/K/T层定义"能做什么"，S层定义"做得多好"。

2. **P层=稀缺设计**：能量/法力/骰子每回合自动恢复是P，但产量固定且稀缺，过度依赖P层是新手陷阱。

3. **C层=乘法引擎**：转化链不是线性加法（A→B→C），而是乘法共振（触发器A×触发器B×触发器C）。Balatro的Joker触发链是最极致的案例。

4. **K层=资源→状态/进度的桥梁**：所有攻击/防御/效果都是K，区别在于状态可逆（护盾）还是进度不可逆（伤害）。

5. **T层形式单一但意义重大**：Boss战/盲注/生命归零是统一的终端形式，但它们的存在使P/C/S/K层有了意义锚点。

6. **"删/净化"也是核心动作**：所有游戏中，删除低效组件（删牌/删符号/删Joker）和获得新组件同等重要。这在传统P/C/S/K/T框架中归属S层（优化效率），但在设计中应被视为独立维度。

### 最值得迁移的角色设计模式

#### 模式1：S层作为"治理语法"（Dicey Dungeons + Wildfrost）

**核心**：给文明Roguelite设计一个S层不是buff列表，而是"槽位分配+延迟预判"的治理语法。

```
文明治理注意力（P层）：每回合6点
槽位（S层）：镇压/改革/仪式/工程/外交
槽位冲突：同一点投给镇压就投不了改革
延迟结算：3回合后符文化潮汐 → 提前投资S层
```

#### 模式2：C层"触发链排列"（Balatro + Monster Train）

**核心**：制度/法令/事件的排列顺序决定最终效果，不只是"有什么"，更是"怎么排"。

```
工业化法令 × 铁路网络 × 矿工工会 = 生产触发链
但：
铁路网络 × 工业化法令 × 矿工工会 → 完全不同
排列顺序 = 触发顺序 = 设计逻辑
```

#### 模式3：P层"事件池塑形"（Luck be a Landlord + Slay the Spire）

**核心**：每一次选择新制度/法令不只是增加能力（P/C），更是在"污染或净化未来的文明事件池"。

```
颁布临时征税法令 → 解决当前危机
但 → "税怨"加入未来事件池 → 降低后续抽取好事件的概率
文明强度 = 好制度数 / 总制度数（需持续删减旧制度）
```

|------|---------|--------------------------|
| Slay the Spire | C+K主导，S层决定构筑质量 | 获得+删除+升级三层构筑 |
