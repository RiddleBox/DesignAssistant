# Batch 2 五角色分类分析

> 文明身份与路线大转向 — 10款游戏的建筑/科技/政策按 P/C/S/K/T 角色分类

---

## 1. Civilization VI

**角色分布**（估算）：P:35 / C:10 / S:25 / K:20 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 区域+建筑（学院/剧院/圣地/工业区） | P | 每回合产出科技/文化/信仰/生产力（从地块+人口凭空产出，净产出正） |
| 奇观 | K | 一次性大量生产力投入→独特全局效果（非持续资源产出） |
| 政策卡 | S | 改变产出乘数/解锁加成（不直接产资源但改变整个P系统的效率） |
| 尤里卡/灵感触发 | S | 加速特定科技/市政 40%（改效率而非产资源） |
| 科技树/市政树解锁 | S | 解锁新区域/建筑/单位/政策（扩展工具集） |
| 砍树加速 | C（一次性） | 将地图上的森林转化为一次性生产力，形态改变且不可逆 |
| 军事单位（建造+维护） | K | 消耗生产力和金币/战略资源→换取战斗力（非资源产出） |
| 伟人点数积累→伟人 | K | 消耗长期积累的点数→换取一次性或持续性独特效果 |
| 太空竞赛项目 | T | 生产力→航天部件→科技胜利（资源流动的终点） |
| 时代系统（黄金/黑暗时代） | S | 改变忠诚度和产出修正（全局效率调节器） |

**角色特征**：P+S双高 — Civ6 的核心是"建更多P建筑→产出更多→解锁更多S（科技/政策）→让P更高效"的正向飞轮。K（军事/奇观/伟人）是路线分化的消耗渠道，T是延迟满足的远端终点。

**可迁移洞察**：文明Roguelite的"基础时代"可以用 P+S 双高模型——大量生产建筑产出通用资源，科技/政策（S）改变效率，但路线分化点不在P而在K（选择把资源消耗在工坊升级还是符文实验上）。尤里卡系统尤其可迁移："行为→认知加速"让玩家的持续行为自然塑形科技方向。

## 2. Old World

**角色分布**（估算）：P:25 / C:5 / S:35 / K:25 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 城市建筑（粮仓/铸造厂/市场/学院） | P | 每回合产出食物/产能/金币/科研 |
| Orders（命令点）系统 | S（元机制） | 所有行动竞争同一个全局行动池——Orders 不产生资源但定义了"每回合能做什么"。本质是一个跨所有角色的限制器 |
| 科技卡牌（随机抽取+家族交易） | S | 解锁新建筑/能力（但获取方式是随机的，非固定树） |
| 角色/家族系统 | S | 家族性格影响城市产出乘数、角色持有科技（人物=移动的S乘数器） |
| 继承危机（国王死亡→Orders骤降） | K | 突然消耗大量Orders处理内斗（资源池被紧急任务吃空） |
| 家族好感波动 | S（动态） | 好感影响产出乘数（从正面到负面），等于一个会漂移的全局效率系数 |
| 奇观建造 | K | 消耗产能换取唯一全局加成 |
| 军事单位 | K | 消耗产能+Orders维持 |
| 胜利条件 | T | 多种隐性终端 |

**角色特征**：S 极高（35%）— Old World 的独特性在于 Orders 系统让"行动权"成为元级 S 资源，所有 P/C/K 行为都在竞争同一个 S 池。此外，角色/家族系统是"人物化的 S"——科技不存储在文明面板里，而是存储在会死亡的角色大脑里。

**可迁移洞察**："治理注意力"作为元级 S 约束——所有文明操作（工业化改革/符文实验/安抚教团/镇压异端）竞争同一个全局行动池，S（制度/科技/人物关系）决定池子大小和分配效率。科技/知识应该和角色绑定，角色死亡可能导致知识丢失。

## 3. Stellaris

**角色分布**（估算）：P:25 / C:20 / S:30 / K:15 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 星球区划（发电/采矿/农业） | P | 从星球凭空产出能源/矿物/食物 |
| 高级建筑（合金铸造厂/消费品工厂） | C | 矿物→合金/消费品（形态改变，多层级转化链） |
| 科研建筑（物理/社会/工程实验室） | P | 产出三维科研值 |
| 传统树（Unity驱动） | S | 解锁全局被动和飞升特权槽位（改变系统规则） |
| 飞升特权 | S | 解锁巨型结构/种族改造等改变游戏规则的能力 |
| 星基地模块（船坞/贸易中心/锚地） | S | 提供造船能力/贸易收集/海军容量（扩展系统边界） |
| 舰队建造+维护 | K | 消耗合金+能量币→战斗力（巨型消耗器） |
| 种族飞升（基因/灵能/合成/机械） | S（元级） | 彻底改变资源系统的运作方式——改变了哪些建筑/岗位/资源存在，是一个"语法级"的S变更 |
| 终局危机 | T（外部） | 审判所有文明的银河级事件（外部T，不由玩家触发） |
| 巨型结构（戴森球/环世界） | K→P | 边界情况——建造期是K（巨大消耗），建成后变为超大规模P |

**角色特征**：S 高 + 独特的"语法级 S"——Stellaris 区别于其他4X之处在于飞升特权不仅仅是效率加成，而是改变了资源系统的底层规则（合成飞升=不需要食物、灵能飞升=进入虚境新资源维度）。这种"S改变了P和C的定义"是最高级的支持角色。

**可迁移洞察**：文明Roguelite的路线大转向应该是"语法级 S 变更"而非数值变化。工业→符文路线不只是"科技+10%符文产出"，而是"能源的定义从煤炭变为符文矿"——改变了哪些P建筑存在、哪些C链失效、哪些K消耗被触发。

## 4. Humankind

**角色分布**（估算）：P:30 / C:5 / S:30 / K:20 / T:15

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 区域+基础设施（农场/矿场/市场/研究所） | P | 标准四维产出（食物/工业/金币/科技） |
| 文化特色区域（每时代新文化专属） | P/S | 边界情况——多数是强化版P，但解锁的行为本身是S带来的 |
| 时代文化切换 | S（元级） | 改变文明身份——获得新特殊能力、新特色区域、新单位类型。改变了P的效率分配和K的可用选项 |
| 文化被抢（先到新时代先选文化） | K（负向S） | 被抢走心仪文化→不得不选次优→路线被迫改变 |
| 科技树（单线+时代门控） | S | 每个时代内线性解锁新建筑/基础设施/单位 |
| 奇观建造 | K | 消耗工业→唯一全局效果 |
| 军事单位 | K | 消耗工业+金币维护→战斗力 |
| Fame（名望）| T | 唯一的、显式的胜利进度条——所有行为最终都转化为Fame |
| 时代之星系统 | S（目标生成器） | 引导玩家在当前时代完成特定类型成就才能推进，本质是S框架下的目标生成 |

**角色特征**：S 极高 + 唯一显式 T——Humankind 有全批次最清晰的单T（Fame=一切行为的终点分数），同时 S（文化切换）是核心好玩点。争议在于文化切换可能造成"身份断裂"——从设计角度看，这反映了"频繁的 S 变更可能破坏 P→T 的连续性"。

**可迁移洞察**：文明Roguelite的时代切换应该像 Humankind 的文化选择一样有"抢占"机制和路线成本，但不能让玩家感觉身份断裂。关键改进：旧文明形态不消失，而是以"病根/遗留问题"的形式保留在新文明中（工业时代的污染在符文时代变成"符文污染"，在教团时代变成"异端遗址"）。

## 5. Endless Legend

**角色分布**（估算）：P:25 / C:15 / S:35 / K:15 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 城市建筑（磨坊/铸造厂/市场/图书馆） | P | 标准产出 |
| 派系专属建筑 | P/C/S（差异极大） | 根据派系不同：裂隙领主用金币买人口=将金币 C 为人口；菌菇族用人当建材=将人口 C 为建筑；遗忘者用金币买科技=绕过S树直接获取 |
| 时代科技（9×6格矩阵） | S | 每时代9个科技可选，不强制顺序但需完成足够数量才能进下一时代 |
| 帝国计划 | S | 每20回合选一个全局buff（效率/能力改变） |
| 冬日机制 | K（负向） | 周期性所有产出-30%~50%（系统级消耗） |
| 派系任务线 | K→T | 消耗行动资源推进专属叙事→特定胜利条件 |
| 奢侈品激活 | S | 消耗奢侈品→激活全局加成 |

**角色特征**：S 极高 + 派系间角色重分配——Endless Legend 的极端非对称性使得同一个角色（如"C转化"）在不同派系中有截然不同的比重。遗忘者完全不需要S（科技树被金币购买取代，S→C）；裂隙领主将食物角色替换为金币（连P的定义都改变了）。

**可迁移洞察**：文明Roguelite的路线差异应该体现为"角色权重的重分配"而非"效率数值差"——工业文明 P-heavy、符文文明 C-heavy、教团文明 K-heavy、心灵文明 S-heavy。让不同路线不仅玩得好坏不同，而是玩的根本不是一个角色组合。

## 6. Age of Wonders 4

**角色分布**（估算）：P:25 / C:20 / S:30 / K:15 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 城市基础建筑（工坊/市场/图书馆） | P | 标准产出 |
| 魔法建筑（魔典解锁） | P/C（混合） | 召唤圈=将法力C为单位；附魔工坊=将法力C为装备加成；远古圣坛=P产出法力 |
| 魔典研究（Tier I→V） | S | 解锁法术和建筑（核心S系统） |
| 帝国发展树 | S | 解锁城市专业化行会和全局加成 |
| 法术施放 | C/K | 战斗法术=K（消耗法力→伤害/效果）；附魔法术=C（法力→单位能力增强）；召唤法术=C（法力→新单位） |
| 种族转化 | S（语法级） | 将所有单位变为天使/恶魔/亡灵——改变了单位的本质属性，等于改变了K消费的"终端产品"是什么 |
| 单位训练 | K | 消耗金币+产能→军事单位 |
| 魔典/Tier V法术完成 | T | 魔典胜利条件 |

**角色特征**：独特的"双树S"——帝国发展树+魔典研究两个独立S系统并行，且可以产生交叉效果（帝国树决定城市职能，魔典决定魔法风味，二者叠加在同一个城市上）。种族转化是"S改变了K消费品的本质"的又一例证。

**可迁移洞察**：文明Roguelite可以采用"双路线S并行"模型——文明建设线（城市/军队/外交，P+S主导）+ 超自然线（符文/信仰/心灵，C+S主导），两线独立推进但产生交叉节点（符文技术+军事工业=符文坦克；祭司团+工业工坊=宗教工厂）。T在两条路线的交汇处出现。

## 7. Crusader Kings III

**角色分布**（估算）：P:20 / C:5 / S:30 / K:40 / T:5

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 领地收入（城堡/城市/神殿） | P | 从领地凭空产出金币/税收 |
| 封臣税 | P | 从封臣关系网中抽取资源 |
| 建筑升级（领地内） | S | 提升领地P效率或增加防御（改变系统参数） |
| 科技/文化革新 | S | 解锁新继承法/新单位/新建筑（长期S投资） |
| 生活方式/技能树 | S | 改变角色能力（个人化的S） |
| 婚姻/继承 | C/S | 边界——将家族声望/关系C为领土/联盟；同时也是S（改变未来资源获取结构） |
| 常备军（维护费） | K | 消耗金币→维持军事实力 |
| 战争 | K | 消耗金币+人力→可能获得领土（高风险K，可能净损失） |
| 计谋/阴谋 | K | 消耗时间和关系→暗杀/绑架/制造宣称 |
| 压力系统 | K（负向） | 行为偏离角色特质→压力积累→精神崩溃（人格化的负向K） |
| 人物死亡 | T（软性） | 不是硬终端但是重大的"结算点"——遗产分割、好感重置、收入骤降 |

**角色特征**：K 极高（40%）— CK3 的独特之处在于它不是"资源不足"驱动的K，而是"人物欲望和关系冲突"驱动的K。战争、阴谋、压力管理——几乎所有K行为都有"人格化动机"。而且T极弱（没有硬性胜利条件，玩家自己定义何时算"成功"）。

**可迁移洞察**：文明Roguelite应该给资源消耗赋予"人格化动机"——不是"我需要50铁矿所以消耗它"，而是"工坊联盟要求自治权，我消耗治理注意力去谈判/镇压/妥协"。K的驱动力应该来自文明内部主体（工坊联盟、祭司团、心灵学派、边疆部族）的欲望和冲突，而非来自外部资源稀缺。

## 8. Europa Universalis IV

**角色分布**（估算）：P:30 / C:10 / S:30 / K:25 / T:5

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 省份发展度（税收/生产/人力） | P | 每个省份自动产出金币/商品/人力 |
| 建筑（教堂/工坊/兵营） | S | 提升省份P效率（不改产出类型，改产出乘数） |
| 君主点数（行政/外交/军事） | C | 将时间和统治能力C为科技/发展度/和平条约（核心转化资源） |
| 科技树 | S | 解锁新单位/新建筑/新能力 |
| 国家理念 | S | 全局被动加成（定义国家的S profile） |
| 贸易（商品→金币） | C | 通过贸易节点链路将省份商品转化为金币收入 |
| 军队（建造+维护） | K | 消耗人力+金币→战斗力 |
| 战争 | K | 消耗人力+金币+君主点数→可能获得领土/赔款 |
| 外交（联姻/同盟/附庸） | S | 改变国际关系结构（影响未来的P和K可用性） |
| 时代能力 | S | 每个时代可选的全局特殊能力 |
| 明确终端 | T≈0 | EU4 几乎没有硬终端（除了游戏结束年份），T极弱 |

**角色特征**：P+S均衡 + T≈0 — EU4 是最纯粹的"开放式沙盒"，没有硬性胜利条件。君主点数是独特的C资源（将"统治时间"转化为一切），也是核心瓶颈。S（理念/时代能力/外交）决定了一个国家"适合走什么路线"。

**可迁移洞察**：文明Roguelite的路线选择应该产生"路径惯性"——EU4 的地缘/国家理念一旦产生就很难逆转，创造了"身不由己"的历史感。在文明Roguelite中，工业文明积累的制度/污染不会因为切换到符文路线就消失，它们变成新路线的"历史债务"。

## 9. Total War: Three Kingdoms

**角色分布**（估算）：P:30 / C:5 / S:20 / K:35 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 郡县建筑（农田/工坊/市场/学校） | P | 产出食物/工业/商业/文化收入 |
| 改革树（科技） | S | 解锁新建筑/新单位/新能力 |
| 人物（将领/官员） | S | 人物属性影响城市产出乘数和军队战力（可移动的S乘数器） |
| 人物俸禄/满意度 | K | 消耗金币维持人物忠诚（不维持→叛变，K的负向风险） |
| 军队招募+维护 | K | 消耗金币+食物→战斗力 |
| 战役层战斗 | K | 消耗兵力+资源→领土控制 |
| 外交（联姻/同盟/附庸/交易） | S/C | 既有S（改变关系结构）也有C（用资源换关系/用关系换安全） |
| 称帝/统一胜利 | T | 占领三个皇位或统一天下 |

**角色特征**：K 极高 + 双层级结构 — Total War 的 K 分布在两个层级：战役层的宏观K（募兵/建筑/外交）和战斗层的微观K（消耗单位换取战术优势）。人物系统是核心S（可移动的乘数器），但人物的俸禄/满意度又是K（持续消耗）。

**可迁移洞察**：文明Roguelite可以采用"双层级K"——宏观层K（消耗治理注意力投到不同文明节点）和微观层K（节点内部事件消耗具体资源/人口）。但不必照搬战斗系统——将"战斗"替换为"文明内部主体间的冲突"（工坊联盟vs祭司团、符文派vs心灵学派）。

## 10. Terra Invicta

**角色分布**（估算）：P:25 / C:15 / S:30 / K:20 / T:10

**核心建筑/科技/卡片的角色映射**：

| 元素 | 角色 | 判断依据 |
|------|------|----------|
| 国家控制→资源产出 | P | 通过控制地球国家获取资金/科研/影响力 |
| 太空采矿/轨道站 | P | 从小行星/行星产出太空资源 |
| 高级材料生产 | C | 矿物→合金/稀有材料（多级转化链） |
| 科技树（全球+工程） | S | 解锁新组件/新舰船/新武器 |
| 派系能力 | S | 7大派系各有独特行动和能力集 |
| 任务控制（MC） | S（瓶颈） | 严格限制可部署的太空资产数量（核心S约束） |
| 舰船建造+燃料消耗 | K | 消耗合金+稀有资源→太空舰队 |
| 外星威胁（隐藏的环境压力） | K（外部） | 外星人行动→破坏地球基建/太空资产（外部K，不由玩家控制） |
| 核武器 | K | 消耗极高资源→一次性毁灭效果 |
| 击败外星人/达成派系目标 | T | 两种终端（共同或对立，取决于派系） |

**角色特征**：独特的"外部K"——Terra Invicta 的 K 角色不仅来自玩家自己的消耗决策，更来自隐藏的外星威胁：一个外部实体在不断消耗你的资源和安全空间。这种"不是我想花资源，而是我被迫花资源去应对"的K模式产生了独特的战略紧张。

**可迁移洞察**：文明Roguelite可以引入"外部K"——不仅是文明内部主体消耗资源，而是一个环境级的外部威胁（气候变化/符文污染/灵能入侵）在不可预测地消耗文明资源。玩家必须在"主动消耗（发展文明）"和"被动消耗（应对外部威胁）"之间分配治理注意力。不同路线对外部威胁的"解释"和"应对方式"完全不同。

## Batch 2 批次总结

### 角色权重雷达图（文字描述）

```
            P(生产)
             /\
            /  \
           /    \
          /  B2  \
    T(终端)--+--C(转化)
          \      /
           \    /
            \  /
         K(消耗)--S(支持)
```

**Batch 2 平均分布**（估算）：
- P: 28%（中高，所有游戏都有标准P产出层）
- C: 12%（偏低，传统4X和P社游戏的C都不是核心）
- S: 31%（最高角色——科技树/政策/理念/飞升/魔典等本质上都是S）
- K: 22%（中等，军事/外交/奇观/事件消耗）
- T: 8%（仍然弱，大部分没有硬终端或终端极远程）

**核心特征**：**S主导 + P支撑**。Batch 2 的10款大型策略游戏共同展现了以S（科技/政策/制度/理念）为核心驱动的模式——S决定P的效率、C的可用性、K的选项。T在大多数游戏中是隐性的、远程的、玩家自定的。

### 全批次共性模式

1. **S 是路线分化的载体**：在Batch 2的游戏中，"文明身份"的形成几乎100%由S角色决定——Civ6的政策卡+科技树、Stellaris的飞升特权、Humankind的文化切换、AoW4的魔典、Endless Legend的派系科技、CK3的生活方式。S不是辅助角色，而是"定义你是什么文明"的核心。

2. **P 是S的基础但被S定义**：所有游戏都有大量P建筑产出基础资源，但"什么算资源"由S定义——Stellaris的合成飞升后不需要食物P、Endless Legend的遗忘者不需要科技P、Humankind的时代文化改变哪些P建筑最有效。P的绝对量虽高但角色重要性低于S。

3. **T 的普遍弱化**：10款游戏中仅Humankind（Fame）、Civ6（太空竞赛）、AoW4（魔典胜利）有明确的T。EU4和CK3几乎没有T，Stellaris的T（危机）是200年后才触发。这反映了"文明策略游戏"的核心乐趣在过程而非终点——玩家享受的是"我做了什么"而非"我赢了"。

4. **C 的非核心化**：Batch 2的C普遍低（5-20%），因为转化机制不是这些游戏的核心——它们关注的是"解锁什么能力"（S）和"消耗什么去扩张/战争/外交"（K），而非"A怎么变成B"。

5. **K 的多元化**：K在Batch 2中不是单一的资源消耗，而是多个独立渠道——军事K（军队维护）、外交K（贡品/联姻）、内部K（CK3的压力、EU4的叛乱镇压）、建设K（奇观/巨型结构）。这种多元K创造了"玩家必须在多种消耗之间平衡"的决策空间。

### 与 Batch 1 的关键差异

| 维度 | Batch 1 | Batch 2 |
|------|---------|---------|
| 主导角色 | C+K（28%+28%） | S+P（31%+28%） |
| S 角色 | 功能解锁（低杠杆） | 路线定义（高杠杆） |
| C 角色 | 核心（转化即游戏） | 辅助（转化非重点） |
| K 角色 | 时间压力驱动 | 多目标竞争驱动 |
| T 角色 | 隐性/缺失 | 远程/多元/自定 |
| 核心循环 | 转化→消耗→存活 | 生产→科技解锁→扩张→消耗→新解锁 |

### 2-3个最值得迁移的角色设计模式

#### 模式1：语法级 S 变更作为"路线大转向"（来自 Stellaris + AoW4 + Humankind）

**核心机制**：路线转向不仅仅是数值加成变化，而是重新定义"什么算资源、什么算消耗、什么算终端"。飞升特权（Stellaris）、种族转化（AoW4）、文化切换（Humankind）都是"改变游戏底层语法"的S操作。

**在文明Roguelite中的应用**：
- 工业→符文：能源的定义从"煤炭/石油"变为"符文矿"，所有依赖能源的P建筑变成"符文P"，旧的煤炭P失效
- 符文→教团：合法性从"符文技术效能"变为"神谕解释权"，C链从"符文→工业品"变为"神谕→信仰力"
- 教团→心灵：K的定义从"物质消耗"变为"意识消耗"——以前消耗铁矿建庙，现在消耗共识度建心灵连接
- 每次转向不是加减10%效率，而是"旧资源体系部分崩溃+新资源体系建立"

#### 模式2：Orders/治理注意力作为元级 S 约束 + 人格化 K（来自 Old World + CK3）

**核心机制**：所有文明操作竞争同一个稀缺行动池（Orders/治理注意力），而K的驱动力来自文明内部主体的人格化诉求（家族要权力、祭司要解释权、工坊要自治）。

**在文明Roguelite中的应用**：
- 唯一的全局稀缺资源 = 治理注意力（每回合/每分钟有限）
- 每次消耗治理注意力 = 投入特定文明节点处理其诉求
- 文明节点的诉求是人格化的："工坊联盟要求自治权，并在秘密储备符文技术"（不是抽象数值，是有名有姓的主体在索要）
- K的本质从"资源不足"变为"主体冲突"——不是"我缺铁矿"，而是"两个文明主体在争夺我的注意力"

#### 模式3：身份拼接 + 历史债务保留（来自 Humankind + EU4 + CK3）

**核心机制**：文明身份由一系列不可逆的历史选择拼接而成（Humankind的文化切换），每次新选择都带着旧选择的"病根"（EU4的路径惯性），关键载体不是抽象数值而是活着的主体（CK3的人物/家族）。

**在文明Roguelite中的应用**：
- 文明不是"开局选一个路线走到底"，而是每次时代切换时选择新方向
- 每次切换保留旧路线的问题作为"历史债务"：
  - 工业化遗留→环境污染（在符文时代变成"符文污染"）
  - 符文化遗留→符文矿脉枯竭（在教团时代变成"圣地争夺战争"）
  - 教团化遗留→宗教专制惯性（在心灵时代变成"集体意识烙印"）
- "文明主体"是跨时代的记忆载体——祭司团记得工业时代的压迫、工坊联盟记得符文时代的合并、心灵学派记得教团时代的清洗
- 路线设计的目标不是"走最优解"，而是"每个遗留问题都在下个时代找到新的表达形式"
