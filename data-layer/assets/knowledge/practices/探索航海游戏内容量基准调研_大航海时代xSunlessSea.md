> 数据来源：Steam 商店页面 / IGN / RPS 评测（已验证） + 游戏 Wiki 与社区数据（未逐条验证）

## 一、Sunless Sea（2015，Failbetter Games）

### 1.1 基本信息

| 维度 | 数据 |
|------|------|
| 类型 | Gothic Horror RPG / 航海 Roguelike |
| 平台 | PC (Steam/GOG/Humble) |
| 文本总量 | **350,000+ 词**（Steam 验证）；首发时约 250,000 词（RPS 评测） |
| Steam 成就 | 54 个 |
| 获奖 | RPS Best Words 2014 / 金摇杆 Best Storytelling 提名 / WGGB Best Writing 提名 |

### 1.2 地点与港口

| 维度 | 估算值 | 说明 |
|------|--------|------|
| 可探索港口/岛屿 | **~50-70 个** | 包括伦敦（母港）及 Unterzee 各海域的定居点、遗迹、灯塔、浮冰等 |
| 海域分区 | ~5-6 个 | 伦敦周边近海 / 北方冰海 / 东方盐狮海域 / 南方铁与尘海域 / 中腹无人区 |
| 随船长的地图变化 | 每次新船长（死亡后）地图重新随机 | 岛屿位置在小范围内漂移，保持新鲜感但不会面目全非 |
| 地标记忆性 | 极高 | RPS 评测："看到 Low Barnet 就像看到老朋友"——每个港口都有鲜明叙事特征 |

### 1.3 NPC 与军官

| 维度 | 数据 | 说明 |
|------|------|------|
| 可招募军官 | **~10-12 名** | Haunted Doctor / Irrepressible Cannoneer / 等，每位有自己的完整支线故事 |
| 主线 NPC（关键角色） | ~15-20 个 | 伦敦海军总部、学者、走私者、各港口的邂逅角色 |
| 复现港口 NPC | 每个港口 1-3 个交互角色 | 大部分为文本交互（无头像），少数关键角色有专属立绘 |
| 军官故事深度 | 每位军官 5-10 个事件节点 | 需多次出海触发、满足条件才能推进 |

### 1.4 故事线

| 维度 | 数据 |
|------|------|
| 核心野心（Ambitions） | **~5-7 条主要胜利条件**：找到父亲遗骨 / 决定伦敦命运 / 积累巨额财富 / 击败深海之神等 |
| 港口支线故事 | **每个港口至少 1 条**，部分港口 2-3 条交错叙事 |
| 军官个人任务线 | **10-12 条**（每位军官一条） |
| 全局事件线 | 多个——伦敦海军总部、深海神祇、革命者网络等跨区域叙事线 |

### 1.5 游玩时长

| 模式 | 时长 | 说明 |
|------|------|------|
| 单次通关（一条野心线） | **20-35 小时** | 取决于熟悉程度和选哪条野心 |
| 全成就 / 全故事 | **60-100 小时** | 需要多周目、不同野心、不同选择分支 |
| 新手到掌握 | 前 5-10 小时死亡率高 | 继承系统降低挫败感，每次死亡重新开始但有资源继承 |

### 1.6 核心循环

```
出海 → 管理燃料/食物/恐惧 → 航行发现新港口 → 读故事/做选择 →
→ 战斗或逃跑 → 赚取资源/情报 → 回港升级船只/招募军官 → 再次出海
死亡 → 下一代船长继承地图+金钱+物品 → 重新出海（世界重新洗牌）
```

### 1.7 内容生产核心特征

- **文本驱动**：几乎全部叙事通过文本 + 选项实现，无需 3D 场景或动画
- **模块化叙事**：每个港口是独立的故事模块，通过品质（quality）系统联动
- **选择编织**：同一港口在不同品质条件下呈现不同叙事——"你有 50 灵魂，可以……" vs "你没有灵魂，只能……"
- **继承性世界**：船长死亡 ≠ 完全重启，地图记忆和传承系统降低重复劳动感

## 二、大航海时代 IV（Uncharted Waters IV: Porto Estado，1999/2000，KOEI）

> ⚠️ 以下数据基于游戏 Wiki 和社区统计，未经 Steam 等平台直接验证。大航海时代 IV 在 Steam 上的 HD 版页面被重定向。

### 2.1 基本信息

| 维度 | 数据 |
|------|------|
| 类型 | 历史模拟 RPG / 航海 + 贸易 + 探索 + 海战 |
| 平台 | PC（原版）/ PSP / Steam HD 版 |
| 主角数量 | **7 名主角**（Rafael、Hodram、Lilu、Abraham、Tial、Maria、杏太郎） |
| 背景设定 | 16 世纪大航海时代、全球地理、真实历史港口 |

### 2.2 地图与港口

| 维度 | 数据 |
|------|------|
| 城市/港口总数 | **~120-140 个** | 覆盖欧洲、非洲、亚洲、美洲的全球港口网络 |
| 可占领/投资城市 | 大部分城市可投资发展商业/军事 |
| 补给港（小港口） | ~20-30 个 | 仅提供补给的简易港口 |
| 世界海域分区 | 7 个海域 | 地中海、北海、西非、东非/印度洋、东南亚、东亚、美洲 |
| 独占港 | 每个海域有 1-2 个可独占的贸易港口 | 需完成特定任务后解锁 |

### 2.3 NPC 与角色

| 维度 | 数据 |
|------|------|
| 可操作主角 | **7 名** | 每位有独立故事线和动机 |
| 初始船员/伙伴 | 每主角 **5-8 名固定伙伴** | 约 40-50 名全游戏伙伴 |
| 可招募酒吧船员 | **~30-40 名** | 分布在各地酒吧，按主角不同有差异 |
| 敌对势力/海贼 | **~15-20 个势力** | 每个海域 2-3 个敌对/中立势力 |
| 剧情 NPC | 每条故事线 ~15-20 个关键角色 | 合计 ~80-100 个有名字的剧情 NPC |
| 酒吧女郎 | 各地酒吧女郎 ~10-15 名 | 提供情报和支线任务 |

### 2.4 故事线

| 维度 | 数据 |
|------|------|
| 主线故事 | **7 条**（每条主角线 ~15-25 小时） | 每条线有独立主题：Rafael（商业帝国）、Lilu（贸易路线开辟）、Hodram（国家荣耀）等 |
| 霸者之证任务链 | 每条主线需收集 7 个霸者之证 | 每个霸者之证对应一个海域的深度探索 + 战斗 + 剧情 |
| 支线任务 | 每条线 ~10-15 个支线 | 涉及寻宝、特定货物贸易、击败海贼等 |
| 剧情文本总量 | 每条线预估 **50,000-80,000 字**（日语原文） | 中文版 7 条线合计约 50-80 万字 |

### 2.5 游玩时长

| 模式 | 时长 |
|------|------|
| 单主角通关 | **20-30 小时** |
| 全部 7 位主角通关 | **120-180 小时** |
| 100% 全收集（宝物/霸者之证/全港口投资） | **200+ 小时** |

### 2.6 核心系统与循环

```
港口出发 → 贸易（买入→航向→卖出赚差价）→ 探索未知海域 →
→ 投资港口（发展商业/军事）→ 招募船员 → 海战（敌对势力/海盗） →
→ 收集霸者之证线索 → 剧情推进 → 解锁新海域/新港口 → 最终达成霸者之证
```

### 2.7 内容生产核心特征

- **7×N 结构**：7 条主角线 × 各海域的共同内容（港口、势力、贸易品）+ 差异化剧情
- **共享世界**：所有主角线共享同一世界地图和港口网络，差异在剧情线和初始条件
- **重复利用**：大量内容（港口、贸易、海战系统）在各主角线间复用，最大化内容利用率
- **贸易模拟层**：真实的供需波动和价格差，为叙事提供"理由"去探索新港口

## 四、对探索游戏的内容量预估启发

### 4.1 如果要做一个类大航海+Sunless Sea 的探索游戏

#### 内容量分档建议

| 档位 | 港口数 | 故事文本 | NPC | 预期时长 | 对标 |
|------|--------|----------|-----|----------|------|
| **MVP**（最小可行） | 15-25 | 30,000-50,000 词 | 5-10 个有深度的角色 + 每港 1-2 个 | 5-10 小时 | Sunless Sea 近海 1-2 个海域 |
| **Alpha** | 30-50 | 80,000-150,000 词 | 15-25 个关键 NPC + 5-8 军官 | 15-25 小时 | Sunless Sea 完整一局 |
| **Beta/完整版** | 60-100 | 200,000-350,000 词 | 40-60 个 NPC | 40-80 小时 | Sunless Sea 全内容 |
| **商业级** | 100-150 | 500,000+ 词 | 100+ 个 NPC + 多主角 | 100-200 小时 | 大航海时代 IV 规模 |

#### 4.2 Sunless Sea 模式的效率优势（推荐借鉴）

1. **文本驱动 > 过场动画**：350K 词 = 约 30-50 小时的叙事内容，只需文字+静态图+选项，零动画成本
2. **模块化港口**：每个港口是一个独立故事单元，可以独立编写、测试、插入，不依赖前后顺序
3. **品质系统（Qualities）**：同一港口根据玩家拥有的品质值（金钱、灵魂、恐惧、技能）呈现不同叙事分支——用少量文本创造大量变体
4. **继承 + 洗牌**：死亡后世界重新洗牌 + 部分继承，既保持了新鲜感又避免了完全重开
5. **渐进门控**：资源消耗（燃料/食物/恐惧）自然地将内容分为初/中/后期，不需要硬性等级门

#### 4.3 大航海时代模式的复用优势（可结合）

1. **多主角 × 共享世界**：7 个主角用同一套港口和系统，但剧情不同——最大化内容利用率
2. **贸易系统驱动探索**：经济动力（赚差价）让玩家"自愿"去探索，减少推着玩家走的剧本感
3. **势力网络**：每个海域的势力关系创造动态冲突，降低手动设计每个事件的需求
4. **渐进解锁**：收集霸者之证/特定物品解锁新海域，提供明晰的长线目标

#### 4.4 关键风险

- **内容量低估**：Sunless Sea 首发 250K 词，最终 350K+ 词，耗时约 2-3 年（15 人团队含 Early Access 期间追加）。单人/小团队的文本产能需要理性评估。
- **重复性问题**：Sunless Sea 的 IGN 评测明确提到 permadeath 可能导致"重复做同样的事"。大航海 IV 通过 7 个完全不同的故事线规避了这个问题。
- **中间海域瓶颈**：RPS 评测指出 Sunless Sea 存在"mid-game hump"——中间海域缺少足够港口导致玩家卡在赚不到钱的循环里。这是内容密度分布的经典陷阱。
