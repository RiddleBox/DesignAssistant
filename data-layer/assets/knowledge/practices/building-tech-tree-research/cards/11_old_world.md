## A. 建筑类型谱系

Old World 的建筑系统较传统4X更简洁，聚焦于**城市专业化 + 家族加成**。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **城市基础** | 食物 | 粮仓、农场 | 人口增长基础 |
| | 产能 | 石匠坊、铸造厂 | 建造速度 |
| | 金币 | 市场、大市场 | 经济产出 |
| | 科研 | 学院、图书馆 | 科技值，关联可研发科技 |
| | 市政 | 法院、大法院 | 市政值（类似 Civ 的文化值，解锁法律） |
| | 训练 | 兵营、靶场 | 军事单位经验 |
| **城市专业化** | 家族城市 | 每个家族城市可建其特殊建筑 | 如「执政官家族」有特殊政府建筑 |
| **奇观** | 历史 | 金字塔、大图书馆等 | 一个文明只能建一座的全局唯一建筑 |
| **要塞** | 防御 | 要塞、城堡 | 地图上的防御节点 |
| **宗教** | 神殿 | 圣祠、大神殿 | 牧师生产+宗教传播 |
| **基础设施** | 道路 | 道路网 | 加速移动+贸易 |

### 家族系统与建筑的关联

每个城市由特定家族控制。家族的性格影响建筑产出：
- 尚武家族 → 城市军事建筑产出加成
- 学者家族 → 科研建筑产出加成
- 商人家族 → 金币建筑产出加成
- 宗教家族 → 宗教建筑产出加成

且**不同家族间可以互相交易科技卡牌**！

## B. 解锁条件链

### 卡牌抽取 + 家族交易

与 Stellaris 类似，Old World 用**随机科技卡池**替代固定科技树：

```
每完成一项研究 → 抽取3-4张科技卡 → 选1张 → 研究
```

但有**关键差异**：
1. **家族科技交易**：如果某个家族拥有你没有的科技，你可以用资源/好感换取
2. **科技死亡**：角色死亡时如果某些科技只被那个角色掌握，科技会丢失！
3. **科技卡片可见前驱关系**：不是完全随机，有前置依赖

### 前置条件类型

| 条件类型 | 说明 |
|----------|------|
| 基础科技值产出 | 足够快的科研速度 |
| 随机卡池 | 从满足前置条件的已解锁科技中随机抽取 |
| 家族交易 | 用资源向家族购买科技卡 |
| 角色持有 | 科技由角色掌握（角色死亡=科技可能丢失） |
| 前置科技 | 某些科技需要特定前提 |

### 链条长度

- **最短**：0层（初始科技直接可选）
- **最长**：约6层（从石器到铁器到古典到...）

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| **铁器加工** | 早期科技 | 解锁剑士→军事优势 |
| **法典/书写** | 早期 | 解锁法律系统 |
| **与家族交易到关键科技** | 家族好感+资源 | 绕过随机池的卡片缺失 |
| **王朝更替** | 角色死亡 | **科技可能丢失！** 建立知识传承系统的紧迫性 |
| **奇观完成** | 足够产能+资源 | 全局唯一建筑的占领 |

## C. 节奏波形

### Orders 系统驱动的节奏

Old World 最独特的节奏来自 **Orders（命令数）** 系统：

```
每回合有有限 Orders（如 10-15 个）
每个行动消耗 1 Order：
  - 移动单位
  - 建造/改进
  - 外交行动
  - 内部政治行动

Orders 用完后 = 结束回合
```

这使得游戏节奏不是"产量竞赛"而是**"注意力分配"**：

```
决策密度
 ▲
 │  ╱─╲  ╱─╲  ╱─╲  ╱─╲
 │ ╱  ╲╱  ╲╱  ╲╱  ╲──── Orders 用尽 = 回合结束
 │╱
 └──────────────────────────────► 回合

每回合：Orders 分配 → 少数核心行动 → 回合结束
```

### 节奏设计意图

1. **Orders = 注意力经济**：不让你同时做所有事，逼你决定这回合最该做什么
2. **角色生命周期**：科技/建筑与角色绑定，角色有寿命→知识需要传承→创造跨代节奏
3. **家族好感变化**：家族好感随事件波动→城市产出高低→科技速度起伏
4. **王朝更替**：国王死亡→继承→政局动荡→科技可能倒退→重建周期

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| Orders 不够用 | **瓶颈** | 想建城市也想打仗也想外交也想...必须选择 |
| 关键学者角色死亡 | **瓶颈** | 科技持有者死了→未传承的知识丢失 |
| 家族好感暴跌 | 瓶颈 | 城市产出腰斩 |
| 交易到核心科技 | **突破** | 绕过随机池的运气成分 |
| 完成全局唯一奇观 | **突破** | 独占一座金字塔的成就感 |
| 稳定继承 | **突破** | 经过危机，知识体系成功传承到下一代 |
