# Age of Wonders 4 — 建筑类型谱系 + 科技树 + 节奏波形

> 标签：4X 策略/奇幻 | 双树协同（帝国树+魔典） | 双路线构筑
> 参考：Batch 2 分析

---

## A. 建筑类型谱系

AoW4 的建筑分为**帝国发展树解锁**和**魔典解锁**两个独立来源。

| 大类 | 解锁来源 | 代表建筑 | 核心机制 |
|------|----------|----------|----------|
| **城市基础** | 帝国树 | 工坊、市场、图书馆 | 标准4X产出（产能/金币/知识/食物） |
| **军事/招募** | 帝国树+魔典 | 兵营、射箭场、法师塔 | 训练单位的地点 |
| **城防** | 帝国树 | 石墙、守望塔 | 城市防御 |
| **城市专业化** | 帝国树 | 三种行会（如法师行会/商人行会/战士行会）| 每个城市选一种行会路线，影响产出和可招募单位 |
| **魔法建筑** | 魔典书 | 召唤圈、附魔工坊、远古圣坛 | 魔典专属建筑，每本魔典提供独特建筑 |
| **奇观/独特建筑** | 魔典书 | 黄金古树、地下墓穴、暗影之门 | 终局等级魔法建筑，提供巨大加成 |
| **行省改良** | 帝国树+种族特质 | 农田、矿场、研究站、圣所 | 在地块上的改良设施 |
| **种族转化** | 魔典书 | （不是建筑，但改变所有单位类型） | 如"天使化""恶魔化""亡灵化" |

### 类间关系

```
城市基础建筑（帝国树解锁）
    ↓
城市专业化：行会选择（帝国树分支）
    ↓
魔典解锁建筑（叠加在专业化之上）
    ↓
种族转化（终极改造，魔典终局）
```

**关键设计**：帝国树+魔典是**双轴叠加**，不是替代。同一座城市既有帝国树决定的「职能」，又有魔典决定的「魔法风味」。

## B. 解锁条件链

### 双树架构对比

| 维度 | 帝国发展树 | 魔典研究 |
|------|-----------|----------|
| 驱动资源 | 帝权（Imperium）+ 人口 | 知识（Knowledge） |
| 解锁节奏 | 人口里程碑解锁节点 | 知识累积→选择魔典→研究其中法术 |
| 选择性质 | 永久不可逆 | 每本魔典内5个法术，选序研究。换魔典后可回头 |
| 终局 | 帝国树终点 = 最终国家形态 | 最高阶魔典（Tier V） = 终极魔法/种族转化 |
| 对称性 | 所有文明共享一个帝国树 | 魔典选择高度个性化 |

### 魔典系统

**分层+顺序选择**（本质是「魔典卡牌构筑」）：

```
Tier I 魔典（选2本）
  ├── 灰烬魔典（火系）
  ├── 岩石魔典（地系）
  ├── 信仰魔典（秩序系）
  ├── 兽性魔典（自然系）
  └── ...（共12本 Tier I）

    ↓ 研究完2本Tier I 后解锁

Tier II 魔典（选2本）
  ├── 同系升级或跨系搭配
  └── ...

    ↓ 研究完2本Tier II + 3本任意魔典 后解锁

Tier III 魔典（选1本）
  └── ...

    ↓

Tier IV 魔典（选1本）
  └── ...

    ↓

Tier V 魔典（选1本，终局）
  └── 如「大天使魔典」「神格魔典」「混沌魔典」
```

### 前置条件类型

| 条件类型 | 说明 |
|----------|------|
| 魔典Tier门控 | 必须研究足够数量的低阶魔典 |
| 亲和力要求 | 有些魔典需要特定亲和力点数（如秩序3+） |
| 帝权+人口 | 帝国树节点需要帝国人口推动 |
| 每本魔典内线性 | 必须先研究法术A才能研究法术B |

### 链条长度

- **帝国树**：约25-30个节点，最深约8层
- **魔典链**：5 Tier × 每本5法术 = 25个法术（但跨魔典可自由选择顺序）
- **综合最长**：Tier I→II→III→IV→V 约20个选择节点

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| 选择第一本Tier I魔典 | 游戏开始 | 定调初期战略（火/自然/秩序/暗影/物质/星界6系选1） |
| 帝国树第一个行会 | 城市人口4 | 城市专业化分叉→决定城市未来角色 |
| Tier III魔典 | 研究完3本低阶 | 开始获得强力法术和可量产高级单位 |
| Tier V魔典 | 研究完7本+ | **终局大魔法/种族转化**，游戏最绚丽的时刻 |
| 种族转化 | Tier III-V魔典 | 将整个种族转化为天使/恶魔/亡灵等，**文明身份的终极重塑** |

## C. 节奏波形

### 研究节奏

```
解锁频率
 ▲
 │ ╱╲  ╱╲    ╱╲    ╱╲      ╱── Tier V（终极爆发）
 │╱  ╲╱  ╲  ╱  ╲  ╱  ╲   ╱
 │        ╲╱    ╲╱    ╲─╱
 └──────────────────────────────► 回合
  Tier I    Tier II   Tier III   Tier IV   V
  (快)      (快)      (中)       (慢)      (爆发)
```

### 节奏设计意图

1. **Tier I-II 快速推进**：让玩家迅速体验不同魔法体系，建立"我的文明"的初始形象
2. **Tier III-IV 放缓**：让玩家巩固路线，开始感受种族转化/高级魔法的强大
3. **Tier V 终局爆发**：一两个法术就完全改变文明形态（如"神格化"），极具仪式感
4. **帝国树与魔典的交替节奏**：人口增长→帝国树节点→城市扩张→知识产出增加→魔典研究加速→交替
5. **战争/扩张作为变速器**：攻占城市→人口增加→帝权+知识同时加速→双树同时突进

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 选择第一本魔典 | 决策点 | 决定初期方向，但后续可调整 |
| 第一次亲和力不足 | 瓶颈 | 跨系混合需要计划亲和力积累 |
| 种族转化完成 | **突破** | 全种族视觉+玩法变化，文明"蜕变" |
| Tier V魔典解锁 | **突破** | 终局爆发，最强法术/单位 |
| 征服/魔法胜利 | **结尾** | 魔典胜利（多个Tier V法术完成） |
