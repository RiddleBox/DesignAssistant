## A. 建筑类型谱系

Civ VI 的建筑体系以**区域（District）分区**为组织核心，不同区域承载不同类型的建筑。

| 大类 | 区域 | Tier 1 建筑 | Tier 2 建筑 | Tier 3 建筑 | 核心机制 |
|------|------|-----------|-----------|-----------|----------|
| **科研** | 学院区 | 图书馆 | 大学 | 研究实验室 | 每人口产出科技值（相邻加成：山脉/雨林） |
| **文化** | 剧院广场 | 露天剧场 | 美术馆/考古博物馆 | 广播中心 | 产出文化值+伟人点数（相邻加成：奇观/娱乐区） |
| **宗教** | 圣地 | 神社 | 寺庙 | （多宗教建筑三选一） | 每人口产出信仰值（相邻加成：山脉/森林/自然奇观） |
| **军事** | 军营/马厩 | 兵营/马厩 | 军械库 | 军事学院 | 训练单位经验+住房+生产力 |
| **经济** | 商业中心/港口 | 市场/灯塔 | 银行/造船厂 | 证券交易所/港口 | 每人口产出金币+商路容量（相邻加成：河流/海岸） |
| **工业** | 工业区 | 作坊 | 工厂 | 发电厂（煤/油/核三选一） | 生产力产出+区域辐射效应（相邻加成：矿场/采石场/区域） |
| **民生** | 娱乐区/水上乐园 | 竞技场 | 动物园 | 体育场 | 宜居度+区域辐射效应 |
| **治理** | 政府区 | 三种建筑选一 | （对应升级） | - | 传承卡槽+总督加成 |
| **防御** | 城墙 | 中世纪城墙 | 文艺复兴城墙 | - | 城市防御值和远程攻击 |
| **外交** | 外交区 | 领事馆 | 大法官庭 | - | 外交点数+减少间谍 |
| **奇观** | （独立地块）| 金字塔、兵马俑等 | - | - | 占用一个地块，提供独特全局加成 |

### 区域系统规则

1. **每3人口解锁新区域槽位**
2. **区域占用一个地块**（不能重叠）
3. **相邻加成**：不同区域有不同相邻加成对象（例如学院区靠山脉+1科技/每格）
4. **区域限制**：市中心+特色区域受人口限制

### 类间关系

```
学院区 → 科技值 → 科技树解锁 → 新建筑/单位
   ↓ 相邻加成
山脉/雨林 ─→ 学院区 + 剧院广场（文化）
               ↓
           市政值 → 市政树解锁 → 政策卡/政府/外交
               ↓
         文化胜利路线
                              ↗ 军事路线
工业区 → 生产力 → 建造速度 → → 科技/文化路线
                              ↘ 宗教路线

商业中心/港口 → 金币 → 购买建筑/单位
娱乐区 → 宜居度 → 城市产出加成/惩罚
```

**多条独立路线平行推进**：玩家选择专注哪几条，决定了胜利方向。

## B. 解锁条件链

### 双树架构

| 维度 | 科技树 | 市政树 |
|------|--------|--------|
| 驱动资源 | 科技值（瓶中烧瓶） | 文化值（紫色音符） |
| 解锁内容 | 单位、建筑、奇观、区域 | 政策卡、政府、外交、奇观 |
| 获取方式 | 学院区、人口、奇观 | 剧院广场、人口、奇观、伟人 |
| 独特机制 | **尤里卡（Eureka）** | **灵感（Inspiration）** |
| 胜利路线 | 科技胜利（太空竞赛） | 文化胜利（旅游业绩） |

### 尤里卡/灵感系统

每个科技/市政都有触发条件，完成条件→完成度瞬间+40%（标准速度）
- "建造一个采石场"→ 触发石工术尤里卡
- "击杀一个单位"→ 触发青铜器尤里卡

**设计意图**：生成「小目标」——让玩家不是被动等研究，而是主动去触发条件。

### 前置条件类型

| 条件类型 | 说明 |
|----------|------|
| 前置科技/市政 | 标准树结构，需满足所有前置 |
| 时代门控 | 某些科技/市政必须到特定时代才能研究 |
| 区域建筑层级 | 先建图书馆才能建大学才能建实验室 |
| 人口门槛 | 每3人口解锁一个新区域槽 |
| 尤里卡 | 非强制但强烈鼓励的加速手段 |

### 链条长度

- **最短链**：1层（远古时代初始科技）
- **最长链**：**约12层**（从远古→古典→中世纪→文艺复兴→工业→现代→原子→信息→未来）
- **典型深度**：每个时代2-3个科技/市政

### 分支结构

**宽树状 + 时代门控**

```
远古时代
├── 畜牧 ─→ 箭术
├── 采矿 ─→ 青铜器 ─→ 炼铁
├── 制陶 ─→ 灌溉 ─→ 文字
└── 航海 ─→ 天体导航
    │
    古典时代 ← ─ ─ ─ 时代门控
    │
    链继续延伸...
    │
    未来时代 ─→ 无限重复科技（未来市政+未来科技）
```

**结构特征**：
1. **宽入口**：远古有8条独立起点
2. **时代门控**：不会跳过时代，必须每代至少完成一定数量
3. **后期收敛**：到未来时代合并为无限重复科技
4. **非对称树的对称化**：初始不同路径，但到终局殊途同归

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| **青铜器** | 采矿 | 解锁矛兵+砍伐雨林（地图改造开始） |
| **炼铁** | 青铜器 | 解锁剑士→第一个强力军事单位 |
| **学徒** | 中世纪 | 解锁工业区→城市生产力质变 |
| **工业化** | 工业时代 | 解锁工厂→生产力再质变 |
| **火箭学** | 原子时代 | 开启太空竞赛（科技胜利路线起点） |
| **政治哲学** | 古典市政 | 解锁第一个高级政府→政策插槽质变 |

## C. 节奏波形

### 时代节奏

```
建设密度
 ▲
 │  ╱╲  ╱╲  ╱╲  ╱╲  ╱╲  ╱╲  ╱╲  ╱╲
 │ ╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲
 │╱
 └────────────────────────────────────► 时代 → 信息时代
  远古  古典  中世纪  文艺复兴  工业  现代  原子
```

每个时代的节奏模式相似：
1. 时代初：快速点几个新科技/市政（解锁兴奋）
2. 时代中：建造新建筑/单位（消化期）
3. 时代末：为下个时代做准备（等待期）

### "错峰承诺队列"

这是 Civ VI 最核心的分钟级节奏机制（引自 Batch 2 分析）：

不是让玩家等一个大目标，而是让玩家随时看见 3-5 个"快要完成"的承诺：
- "科技 2 回合完成"
- "制造者 1 回合到达"
- "奇观 8 回合但敌人可能抢"

**每个承诺都是一个小 hook**，让玩家自然说出「再过一回合」。

### 节奏设计意图

1. **时代打分系统**：每个时代结束时有"平凡/黄金/黑暗时代"打分，金色加速，黑色有挑战。让每次时代切换变成「审判时刻」
2. **尤里卡=分散节奏**：让玩家在每个时代都保持活跃（不止等研究），而是主动完成小目标
3. **奇观竞赛**：奇观是有限的（全球每座只能一个文明建造），创造「被抢」的焦虑感
4. **胜利路线的终局加速**：太空竞赛需要多个部件连续发射，最后30回合急剧加速

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 铺城选址纠结 | 瓶颈 | 区域限制导致早期选址有"机会成本"压力 |
| 进入黑暗时代 | **瓶颈** | 忠诚度压力+周边城市可能叛变 |
| 进入英雄/黄金时代 | **突破** | 忠诚度加成+可购买平民单位 |
| 完成第一个区域 | 突破 | 搞懂区域系统后的第一次正确放置 |
| 工业化完成 | **突破** | 工厂解锁，生产力爆炸 |
| 火星殖民组件完成 | 突破 | 科技胜利触手可及 |
