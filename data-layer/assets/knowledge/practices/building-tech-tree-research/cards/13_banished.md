# Banished — 建筑类型谱系 + 科技树 + 节奏波形

> 标签：中世纪殖民地/纯粹生存 | 无科技树 | 人口驱动解锁
> 参考：Batch 4 分析

---

## A. 建筑类型谱系

Banished 的「科技树」就是**人口数量**。人口增长→解锁新建筑选项。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **采集/食物** | 采集 | 采集小屋、狩猎小屋、捕鱼码头、牧场、农田 | 基础食物来源 |
| | 加工 | 酿酒厂 | 水果→酒（贸易/幸福） |
| **资源/建材** | 木材 | 伐木小屋 | 砍树→原木 |
| | 石材 | 采石场（无限但慢）| 地表石（快但有限）vs 采石场 |
| | 铁矿 | 矿场（无限但慢）| 地表铁（快但有限）vs 矿场 |
| | 加工 | 伐木场、铁匠铺、裁缝店 | 原木→柴火，铁→工具，皮革/羊毛→衣服 |
| **居住** | 住房 | 木屋→石屋 | 石屋更暖（柴火需求低） |
| **健康/幸福** | 医疗 | 草药屋→医院 | 草药→健康维持，医院→疫病应对 |
| | 宗教 | 教堂、墓地 | 幸福度+防止快乐度过低 |
| | 教育 | 学校 | 儿童→受教育成人（工作效率+50%） |
| **贸易** | 贸易 | 贸易站 | 用盈余换稀缺品（种子、牲畜） |
| **市政** | 行政 | 市政厅 | 统计数据+接受移民 |
| | 道路/桥 | 土路→石路、木桥→石桥 | 加速行走 |
| **防御/灾难** | 灾难 | 水井、医院 | 应对火灾/疫病 |

### 类间关系

```
食物（采集/农业/畜牧）→ 防止饥饿
    ↓
工具/衣服/柴火 → 工作效率/保暖/生存
    ↓
住房 → 保暖+生育
    ↓
健康/教育 → 长期效率
    ↓
贸易 → 获取地图上不存在的资源
```

**纯线性依赖**：每个系统都是更高级系统的基础，没有交叉飞轮。

## B. 解锁条件链

### 没有科技树！

Banished 是本次调研中**唯一没有科技/研究系统的样本**。所有建筑从一开始概念上可用，但解锁门槛是：

| 门槛类型 | 说明 |
|----------|------|
| **人口** | 城镇中心升级→新建筑选项（如市政厅需要一定人口） |
| **资源** | 需要足够材料才能建造 |
| **种子/牲畜** | 只能通过贸易站获得（地图上没有） |
| **教育** | 学校→培养教育工人→所有生产效率+50% |

### 「人口驱动解锁」

```
初始人口：采集小屋、狩猎小屋、伐木小屋、木屋
    ↓
人口 20+：铁匠铺、裁缝店、学校
    ↓
人口 50+：采石场、矿场、贸易站
    ↓
人口 100+：市政厅、石屋、医院
    ↓
人口 200+：教堂、酿酒厂
```

### 链条长度

Banished 的建筑链本质是**资源循环**而非科技解锁：
- 工具链：原木+铁→工具→加速所有工作
- 衣服链：皮革/羊毛→衣服→过冬生存
- 食物链：采集→农业→畜牧（更多样化）
- 教育链：学校→受教育工人→效率爆发

### 关键门控（人口里程碑）

| 门控 | 条件 | 为什么是转折点 |
|------|------|---------------|
| **铁匠铺** | 资源+人口 | 工具→效率飞升 |
| **学校** | 资源+人口 | 教育→所有效率+50%，长期质变 |
| **贸易站** | 人口50+ | 获取新种子/牲畜的唯一途径 |
| **市政厅** | 人口100+ | 可见统计数据→接受移民 |
| **医院** | 人口+资源 | 防止疫病毁灭全城 |

## C. 节奏波形

### 人口周期节奏（最核心的节奏机制）

```
人口
 ▲
 │  ╱╲          ╱╲  ╱╲
 │ ╱  ╲        ╱  ╲╱  ╲
 │╱    ╲──────╱        ╲────
 │  老龄化死亡   新成人爆发  老龄化死亡
 └────────────────────────────────► 时间（年）
```

Banished 没有周期性危机（不像 Frostpunk 的暴风雪或 Timberborn 的旱季），它的节奏完全由**人口波**驱动：
1. 造新房→年轻夫妇搬入→生育→儿童+10年→成年
2. 如果有教育→教育儿童→教育成人产出150%
3. 老年人死亡→人口骤降→劳动力不足→食物减产→饥荒

**年龄结构的延迟反馈**是最精妙也最残酷的设计。

### 节奏设计意图

1. **反馈延迟**：今天的婴儿=10年后的成人。今天不造学校=10年后全是效率低下的劳动力
2. **增长陷阱**：快速扩张→食物/柴火不够→饥荒/冻死→人口崩溃→劳动力不足→更多饥荒→负飞轮
3. **没有紧急救援**：不像 Frostpunk 有法典可以临时变通，Banished 犯错的后果是不可逆的
4. **贸易打破瓶颈**：所有新种子/新牲畜必须通过贸易站→河流位置决定了可贸易范围→选址直接影响发展上限

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第一个冬天 | **瓶颈** | 柴火不够→全城冻死 |
| 工具耗尽 | **瓶颈** | 没造铁匠铺→一切效率减半→食物/柴火同时崩溃 |
| 人口老龄潮 | **瓶颈** | 太多老人→太多死亡→劳动力断崖 |
| 建成学校 | **突破** | 教育成人→效率长期质变 |
| 贸易船带来新种子 | **突破** | 解锁之前无法生产的食物/资源 |
| 稳定的人口循环 | **终局** | 可以自我维持的城镇 |
