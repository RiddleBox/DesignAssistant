## A. 建筑类型谱系

RimWorld 的建筑以**殖民者需求层次**为组织原则，从生存到舒适逐层解锁。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **基础设施** | 结构 | 墙壁、门、地板 | 温度隔离、美观度、防御 |
| | 电力 | 发电机（木柴/太阳能/地热/核能）、电线、电池 | 电网管理，短路风险 |
| | 温控 | 空调、加热器、通风口 | 温度直接影响殖民者健康和心情 |
| **居住** | 睡眠 | 睡眠点→床→双人床→皇家床 | 休息效率+心情 |
| | 娱乐 | 马蹄铁→象棋桌→电视→望远镜 | 娱乐多样化需求 |
| **食物** | 种植 | 种植区→水培盆 | 土壤肥力+光照需求 |
| | 加工 | 屠宰台→炉灶→营养膏合成机 | 生食→熟食/营养膏 |
| | 存储 | 冷藏库（空调降温）+货架 | 食物保鲜=冬季生存关键 |
| **生产** | 工作台 | 裁缝台、锻造台、机械加工台、装配台 | 原料→装备/武器/零件 |
| | 研究 | 研究台→高科技研究台→多功能分析仪 | 三级递进 |
| | 药物 | 药物实验室 | 草药→药物→高级义肢和强化 |
| | 艺术 | 雕塑台 | 美观度对殖民者心情的巨大影响 |
| **防御** | 墙/陷阱 | 沙袋、路障、陷阱、自动炮塔 | 袭击压力递增→防御升级 |
| | 迫击炮 | 迫击炮 | 远程打击围攻 |
| **医疗** | 医疗 | 医疗床→生命体征监测仪 | 治疗质量影响生存率 |
| | 义肢 | （需要研究解锁后由工作台制作）| 替换受损肢体 |
| **社交/宗教** | DLC | 王座厅（Royalty）、仪式点（Ideology） | IDEOLOGY DLC 大幅扩展 |
| **基因/异种** | DLC | 基因装配台、基因提取器（Biotech） | BIOTECH DLC 大幅扩展 |

### 类间关系

```
食物 → 殖民者生存（基础）
  ↓
心情（居住/娱乐/美观）→ 精神崩溃风险
  ↓
工作台 → 装备/武器（应对袭击）
  ↓
防御 → 保护殖民地
  ↓
研究（三级研究台）→ 解锁以上所有的高级版
  ↓
电力/温控 — 贯穿始终的基础设施层
```

**DLC 扩展**：
- Royalty：增加王座系统和灵能
- Ideology：给建筑添加仪式/角色/文化含义
- Biotech：基因改造解锁全新的建筑链（基因提取→装配→培育）

## B. 解锁条件链（科技树拓扑）

### 前置条件类型

| 条件类型 | 示例 | 说明 |
|----------|------|------|
| 研究解锁 | 所有建筑通过研究台解锁 | 100% 研究驱动 |
| 研究台等级 | 高科技研究台需要微电子基础 | 三级门控 |
| 资源门槛 | 精密装配需要高级零部件（只能买或拆解） | 地图资源稀缺性 |
| 技能要求 | 建筑建成后的工作效率由殖民者技能决定 | 非解锁条件但影响实际可用性 |

### 研究台分级

| 研究台 | 解锁条件 | 能研究什么 |
|--------|----------|-----------|
| 简易研究台 | 初始 | 石器/中世纪科技 |
| 高科技研究台 | 微电子基础+高级零部件 | 工业/太空时代科技 |
| 多功能分析仪（附件）| 更后期科技 | 加速高级研究（不独立使用） |

### 链条长度

- **最短链**：1层（但大多数科技需要前置）
- **最长链**：**6层**（石器→中世纪→工业→太空→超科技→超凡）
- **典型深度**：3-4层

### 分支结构

**树状（宽而浅的分支）**

```
研究台
├── 农业线：种植→水培→（无深度，就2-3层）
├── 电力线：木柴→太阳能→地热→核能（4层）
├── 武器线：弓→枪→突击步枪→电荷枪（4层）
├── 装备线：部落装→防弹衣→动力装甲（3层）
├── 医疗线：草药→药品→仿生部件（3层）
├── 建造线：石材切割→精密建筑（2层）
├── 飞船终局线：飞船结构→反应堆引擎→传感器（6层）
└── (DLC) 灵能/基因/机械线
```

**结构特征**：
1. **宽分支**：10+条并行研发线，线性为主，交叉少
2. **时代门控**：石器→中世纪→工业→太空→超凡五阶段
3. **每条线内部浅**：通常3-4层即到顶
4. **飞船线最深**：6层为最长研发链，毕竟是逃离星球的终局目标

### 关键门控节点

| 门控节点 | 解锁条件 | 为什么是转折点 |
|----------|----------|---------------|
| **微电子基础** | 简易研究台 | 解锁高科技研究台，开启全后50%科技 |
| **地热能** | 微电子 | 从燃料经济→无限电力 |
| **精密装配** | 高科技研究台 | 解锁高级零部件自制 |
| **飞船结构基础** | 高科技研究台+多前置 | 开启终局逃离路线 |
| **（DLC）机械师** | 简易研究台+找到机械部件 | Biotech：开启机械体自动化 |

## C. 节奏波形

### 节奏模式（由 AI Storyteller 驱动）

RimWorld 的科技解锁节奏与 Factorio 不同——**科技本身匀速可研，但外部事件决定你是否有空研究**。

三个 Storyteller 提供不同节奏：
- **Cassandra Classic**：平衡的上升曲线，袭击间隔逐渐缩短
- **Phoebe Chillax**：长时间和平→突然爆发
- **Randy Random**：完全随机，可能开局空投 50 只松鼠

```
解锁密度（不受事件影响时）
开局(1-2年)：极高，每季度3-5科技（基础生存科技天女散花）
中期(3-5年)：中，每季度1-2科技（开始专精某条线）
后期(6-10年)：低，每半年1个科技（只剩飞船或DLC终局线）
```

### 节奏波形图

```
压力（事件驱动）
 ▲
 │     ╱╲  ╱╲  ╱╲───── 越来越强的袭击
 │    ╱  ╲╱  ╲╱
 │   ╱               ╲──── 和平期攀科技
 │  ╱
 │ ╱  开局建设
 └──────────────────────────────► 时间
```

### 节奏设计意图

1. **科技树不是瓶颈，事件才是**：你有空研究吗？还是殖民者正在流血？
2. **随机性的节奏美**：每次袭击后获得喘息→快速补科技→下一次袭击更难→循环
3. **研究是"希望"的载体**：看到科技条在前进，让玩家在灾难中有盼头
4. **飞船终局是动机终点**：不强迫你走，但给你一个"离开这个地狱"的承诺

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第一波袭击 | 瓶颈 | 毫无准备→学会防御建筑 |
| 冬天食物不够 | 瓶颈 | 学会食物储存/温控 |
| 高级零部件不够 | 瓶颈 | 必须贸易或袭击商队 |
| 第一次造出自动炮塔 | **突破** | 从人力防御→自动防御 |
| 飞船引擎研究完成 | **突破** | 看见逃离的希望 |
