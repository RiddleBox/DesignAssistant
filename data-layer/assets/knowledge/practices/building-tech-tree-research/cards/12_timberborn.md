## A. 建筑类型谱系

Timberborn 的建筑以**水资源工程**为核心，垂直分层是其最大特色。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **水工程** | 拦截 | 水坝、防洪闸 | 拦截水流形成水库，防涝排洪 |
| | 输送 | 水泵、灌溉塔 | 水→土地湿润=植物生长 |
| | 存储 | 水箱（小型/中型/大型） | 旱季用水储备 |
| | 水力 | 水车 | 水流→电力 |
| **食物** | 耕种 | 农田、水生农场 | 需要湿润土地或水 |
| | 林业 | 林场（不同树种） | 橡木/枫木/松木各有用处 |
| | 加工 | 磨坊、面包房 | 原料→高级食物 |
| **居住/人口** | 住房 | 小屋→双层排屋→高层公寓 | 垂直堆积，节省地面空间 |
| | 人口控制 | （无直接建筑，通过住房+食物调节） | 住房数=人口上限 |
| **电力/工业** | 发电 | 水车、风车、引擎（需燃料） | 从水力到燃料 |
| | 生产 | 锯木厂、齿轮工坊、造纸厂 | 木材→板材→齿轮→高级产品 |
| **科技/研究** | 研究 | 发明家小屋→瞭望塔（观测站） | 发明点数驱动科技解锁 |
| **仓储** | 存储 | 仓库、地下仓库 | 大容量存储 |
| **装饰/幸福** | 幸福 | 屋顶花园、神殿、泥浴 | 提升海狸幸福感（影响工作效率） |
| **平台/基建** | 平台 | 平台、楼梯、桥梁 | **垂直建筑的核心**——可层层堆叠建筑 |

### 垂直建筑系统

Timberborn 最独特的建筑机制：

```
地面层：农田 仓库 水坝
    ↓
平台层1：小屋 工坊（乘在平台上！）
    ↓
平台层2：屋顶花园 太阳能（乘在平台上！）
    ↓
平台层N...
```

不是每款城市建造游戏都有 Z 轴——但 Timberborn 的 Z 轴是生存关键（防洪+节省空间）。

### 类间关系

```
水 → 水坝 ← 防洪闸
  ↓
水泵 → 水箱 → 旱季用水
  ↓
灌溉塔 → 农田湿润 → 食物
  ↓
水车 → 电力 → 工业生产 → 高级产品
  ↓
住房 → 海狸 → 劳动力 → 所有建筑
  ↓
幸福建筑 → 幸福感 → 工作效率 buff
```

## B. 解锁条件链

### 科技树（发明系统）

Timberborn 的科技树是**单线解锁 + 可选分支**：

```
发明家小屋（初始）→ 发明点数
    ↓
核心科技线（线性推进）：
  林业 → 板材生产 → 齿轮 → 高级工程 → 引擎
    ↓
分支：
  水工程线：水坝 → 防洪闸 → 灌溉 → 水泵
  食物线：农田 → 磨坊 → 面包房
  幸福线：屋顶花园 → 神殿 → 泥浴
  电力线：水车 → 风车 → 引擎
```

### 前置条件类型

| 条件类型 | 说明 |
|----------|------|
| 发明点数 | 由发明家产出，是唯一解锁科技的资源 |
| 前置科技（单线） | 线性链条，每个科技需前置 |
| 资源门槛（隐含） | 有些科技需要高级材料（齿轮、金属）才能建造对应建筑 |

### 链条长度

- **最短链**：1层（初始科技直接可用）
- **最长链**：约6-7层（从基础林业→板材→齿轮→金属→引擎→高级住宅）
- **典型深度**：3-4层

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| **林业** | 初始发明 | 从砍野生树→种植林业（可持续发展） |
| **水坝** | 水工程线初段 | 从被动承受旱季→主动蓄水 |
| **防洪闸** | 水工程线中段 | 调控水流方向，真正的水利工程 |
| **平台** | 建设工程线 | 开启垂直建造，生存空间质变 |
| **引擎** | 工业线终段 | 从水力→燃料驱动，摆脱水车依赖 |

## C. 节奏波形

### 旱涝周期节奏

```
水资源压力
 ▲
 │  ╱╲        ╱╲        ╱╲
 │ ╱  ╲      ╱  ╲      ╱  ╲          ← 旱季：水资源紧张
 │╱    ╲────╱    ╲────╱    ╲─────── ← 雨季：补充储备
 │      旱季    旱季    旱季
 └────────────────────────────────────► 时间

旱季长度随时间逐渐增加！
```

### 节奏设计意图

1. **可预判的周期审判**：旱季是定期的，预告给了玩家准备时间。设计意图不是"吓你一跳"而是"让你为可预见的挑战做准备"
2. **旱季逐渐变长**：初期旱季2-3天→后期旱季10-20天→必须有大规模水库
3. **从被动到主动的水管理**：开局靠河流→水坝→防洪闸→水库→最终完全调控水流
4. **垂直建造解锁前的平面挣扎**：在平台科技解锁前，空间焦虑始终存在。解锁后空间焦虑转化为更复杂的布局谜题

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第一个旱季 | **瓶颈** | 新手最常团灭的时刻——没存够水 |
| 水坝建成 | **突破** | 从被动等水→主动蓄水 |
| 防洪闸解锁 | **突破** | 可调控水位，不怕涝 |
| 平台科技解锁 | **突破** | 垂直建造解放空间 |
| 旱季 10+ 天仍够水 | **突破** | 水库体系成熟 |
| 幸福度全部满足 | **终局** | 海狸天堂达成 |
