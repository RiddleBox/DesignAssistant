# Dwarf Fortress — 建筑类型谱系 + 科技树 + 节奏波形

> 标签：殖民地模拟/深度涌现 | 无科技树 | 产业工作室网络
> 参考：Batch 4 分析

## A. 建筑类型谱系

Dwarf Fortress 的「建筑」本质上是**工作室（Workshop）+ 家具（Furniture）**的网络。没有"科技树"，所有建筑从开局理论可用，但被资源链约束。

| 大类 | 子类 | 代表工作室/建筑 | 核心机制 |
|------|------|---------------|----------|
| **采矿/木工** | 采矿 | 地下矿道 | 开采石材/矿石/宝石 |
| | 木工 | 木工坊 | 木头→家具/工具/容器 |
| **石工** | 基础 | 石工坊 | 石材→石块→家具/工艺品 |
| | 高级 | 机械工坊 | 制作机械零件（水车/风车/机关等） |
| **冶金** | 冶炼 | 熔炼炉 | 矿石→金属条 |
| | 锻造 | 锻炉（武器/盔甲/金属工艺） | 金属条→武器/盔甲/工具/零件 |
| **食品** | 屠宰 | 屠宰场 | 动物→肉/骨/皮/脂肪 |
| | 加工 | 厨房、蒸馏室 | 生食→熟食、植物→酒 |
| | 种植 | 地下农场 | 地下种植（不需要阳光！） |
| **纺织** | 纺纱/织布 | 纺纱机、织布机 | 植物纤维/毛→线→布 |
| | 制衣 | 裁缝店 | 布→衣服 |
| | 制皮 | 皮革坊 | 皮→皮衣/皮甲 |
| **玻璃/陶瓷** | 玻璃 | 玻璃窑 | 沙子→玻璃制品 |
| | 陶瓷 | 窑炉 | 黏土→陶瓷制品 |
| **家具/贸易** | 家具 | （多种）| 床、桌椅、容器、门 |
| | 贸易 | 贸易仓库 | 与商队交易（获取地图没有的资源） |
| **军事/防御** | 训练 | 兵营、靶场 | 矮人训练武术 |
| | 防御 | 陷阱、吊桥、笼子 | 物理防御机制 |
| **居住/生活** | 房间 | 卧室、餐厅、办公室 | 矮人的私人空间 |
| | 幸福 | 酒馆、神殿、图书馆 | 满足矮人的多元需求 |
| **液体工程** | 水利 | 水泵、水闸、排水管 | 复杂的流体力学系统 |
| | 岩浆 | 岩浆泵、岩浆锻炉 | 终局级工业（需要岩浆） |

### 产业网络

Banished 有 4-5 层的资源链，但 Dwarf Fortress 的资源链**深度和复杂度远超前者的任何建筑游戏**：

```
采矿 → 矿石 → 熔炼 → 金属条 → 锻造 → 武器/盔甲
    ↘ 石材 → 石工 → 石块 → 机械零件 → 水车/闸门
                                  ↓
木头 → 木工 → 床/桶/笼子 ──→ 所有产业的基础容器
                             ↓
植物 → 蒸馏室 → 酒 ──→ 矮人动力燃料
动物 → 屠宰 → 肉+皮+骨 → 厨房+皮革坊+工艺坊
```

不是单一链条，而是**全连接网络**——每个工作室依赖其他工作室的产品。

## B. 解锁条件链

### 没有科技树！

Dwarf Fortress 是最极端的「0 科技树」设计：

| 解锁方式 | 说明 |
|----------|------|
| **资源获取** | 挖到矿石→解锁冶金→解锁武器。没挖到？永远不会 |
| **移民技能** | 新移民带着技能来。来了个玻璃匠→玻璃产业解锁 |
| **商队交易** | 某些资源（如钢的助熔剂）可从商队处购买 |
| **灵感/奇想** | 矮人可能被灵感激发出神器和物品 |
| **地图特性** | 不同地图的矿物/植被/气候完全不同 |
| **工程知识（玩家）** | "解锁"取决于玩家是否知道如何建造某些工程 |

### 链条长度

不存在「科技链条」。但存在**资源链条**：
- 最短资源链：木头→木桶（1步）
- 最长资源链：挖矿→炼焦炭→炼铁→炼钢→钢武器（5步）+ 皮革柄缠（更多步）
- 复杂链可以交叉到 8-10 步（如：挖矿石+烧焦炭+收集助熔剂+泵水+建厂房+备容器...）

### 关键解锁事件

| 事件 | 条件 | 为什么是转折点 |
|------|------|---------------|
| **挖到铁矿** | 随机/选址 | 从木制时代→铁器时代 |
| **移民铁匠** | 移民波 | 解锁锻造能力（即使你挖到了矿也不会锻） |
| **碰到岩浆** | 深挖 | 燃料从焦炭→岩浆（无限热源） |
| **建好水闸系统** | 玩家工程能力 | 水淹地城/水淹敌人的终极武器 |
| **神器锻造** | 矮人灵感 | 一件神器 = 房间质量暴增 = 矮人幸福感质变 |

## C. 节奏波形

### 事件驱动节奏（纯涌现，无预设）

Dwarf Fortress 的节奏不由设计者编排，而由**随机事件 + 资源发现 + 玩家野心**共同涌现：

```
事件频率
 ▲
 │╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲
 │ 随机移民 怪兽 商人 灵感 围攻 怪兽 怪兽 怪兽
 └────────────────────────────────► 时间

（完全随机，没有固定的节奏波形）
```

### 节奏设计意图

1. **所有节奏来自系统交互**：没有编排→从系统碰撞中自然涌现
2. **财富驱动难度**：要塞越富有→怪物袭击越强→"越成功越危险"的自调控难度曲线
3. **无终止条件**：要塞可以运行数百年。游戏何时结束完全由玩家决定
4. **建造成就感替代科技成就感**：不是"我解锁了这个新建筑"而是"我终于让这个复杂的工程跑起来了"

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 找不到某种矿石 | **瓶颈** | 地图生成随机→可能永远不能造钢 |
| 第一个冬天没食物 | 瓶颈 | 忘了种地→全员饿死 |
| 液体工程失败 | **瓶颈** | 水淹要塞→矮人溺死 |
| 移民带来稀有技能 | **突破** | 随机出现你缺的铁匠/玻璃匠 |
| 挖到岩浆 | **突破** | 开启岩浆锻炉→无限热源 |
| 要塞运行超过10年 | **突破** | 自维持系统证明可行 |
