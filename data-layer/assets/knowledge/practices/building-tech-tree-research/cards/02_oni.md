## A. 建筑类型谱系

ONI 的建筑按**生存必需功能系统**分层，每个系统解决复制人的一种生存需求。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **氧气** | 初级产氧 | 藻类制氧机→氧气扩散器 | 消耗藻类→O₂，复制人平均消耗 100g/s |
| | 中级产氧 | 电解器 | H₂O→O₂+H₂，副产品H₂可用于发电 |
| | 高级 | SPOM（自供氧模块）| 电解+氢气发电机自循环 |
| **电力** | 初级 | 人力发电机、煤炭发电机 | 复制人跑步/燃煤 |
| | 中级 | 天然气发电机、氢气发电机 | 副产品利用 |
| | 高级 | 石油发电机、蒸汽涡轮机 | 高温→电力 |
| | 终极 | 太阳能板 | 零燃料但受光照限制 |
| **食物** | 耕种 | 种植箱→水培砖 | 土/水→作物 |
| | 畜牧 | 畜舍 | 动物→肉/蛋 |
| | 加工 | 电烤架、燃气灶 | 生食→熟食，士气加成 |
| **水/液体** | 采集/净化 | 水泵、净水器 | 污染水→净水+污染土 |
| | 循环 | 筛水器、脱盐器 | 封闭水循环的关键 |
| **温度** | 冷却 | 冷风扇、液冷器、空调 | 应对系统热累积 |
| | 加热 | 空间加热器 | 低温区保暖 |
| **管道/气体** | 气体 | 气泵、气体管道、气阀 | 气体分流+压力管理 |
| | 液体 | 液泵、液体管道、液阀 | 液体分流+循环 |
| **排污/卫生** | 厕所 | 茅厕→抽水马桶 | 污染水/食物中毒管理 |
| | 排污 | 堆肥 | 污染土→肥料 |
| **复制人生活** | 士气 | 按摩床、淋浴、娱乐 | 抵消压力，维持效率 |
| | 医疗 | 医疗床、疾病诊所 | 应对受伤/疾病 |
| **自动化** | 逻辑 | 自动化线、传感器、开关 | 条件触发，减少手工操作 |
| **运输** | 轨道 | 运输轨道、装载器 | 固体物资自动输送 |
| | 管道运输 | 运输管 | 复制人快速移动网络 |
| **研究** | 研究站 | 研究台→超级计算机→虚拟天象仪 | 三级递进，依次解锁 |

### 类间关系

**核心依赖网**（双向依赖强于单向）：

```
氧气 ←→ 电力（电解需要电，氢气发电机需要电解副产品）
电力 ←→ 温度（发电机产热→需要冷却→冷却需要电）
水 ←→ 食物（种植需水，厕所→污染水→净化→闭环）
温度 ←→ 农业（作物有温度区间）
复制人 ←→ 全部（每个系统故障都影响复制人）
```

**系统性迭代**：没有哪个系统独立存在。解决氧气会产热→热会杀作物→作物死导致食物危机→复制人压力爆→呕吐污染物→污染水扩散→氧气设备停转...

## B. 解锁条件链（科技树拓扑）

### 前置条件类型

| 条件类型 | 示例 | 说明 |
|----------|------|------|
| 前置科技 | 超级计算机需基础研究 | 标准树 |
| 研究站等级 | 科技分属初级/中级/高级/材料/终局五层 | 每层需对应研究站 |
| 前置建筑（隐含）| 太空探索需望远镜（定位小行星）| 非显式UI但有隐性依赖 |
| 资源门槛 | 塑料需石油→需找到油田 | 地图资源决定能否攀科技 |

### 研究站分级

| 研究站 | 解锁 | 对应科技层 |
|--------|------|-----------|
| 研究台 | 初始 | 初级研究 |
| 超级计算机 | 初级研究+水 | 中级研究 |
| 虚拟天象仪 | 塑料+中级研究 | 高级/材料研究 |
| 望远镜 | 玻璃 | 太空研究（DLC） |
| 材料研究终端 | 辐射 | DLC 终局 |

### 链条长度

- **最短链**：1层（初级科技直接可点）
- **最长链**：**5-6层**（从研究台→超级计算机→高级研究→材料研究→辐射研究）
- **典型深度**：3-4层

### 分支结构

**树状（5大分支）+ 横向依赖**

```
        基础研究（研究台）
        /    |    \
    氧气线  食物线  电力线
      |      |      |
      |      |      ├─────────────────┐
      |      |      │                  │
    中级研究（超算）─→ 自动化 ← → 管道 ← →
      |              │         │
    高级研究（天象仪）→ 精炼 → 太空 ← → 辐射（DLC）
```

**结构特征**：
1. 5条主要分支高度独立（可专注一线）
2. 中级研究站作为统一门控（所有分支到中级都需超算）
3. 系统间物理交互形成「隐性依赖」（研究树上不显示，但物理上必然：点了解电解但没降温方案=自杀）
4. DLC 新增终局辐射线

### 关键门控节点

| 门控节点 | 怎么触发 | 为什么是转折点 |
|----------|----------|---------------|
| **电解器** | 初级研究 | 从消耗藻类到用水产氧，开启水循环时代 |
| **超级计算机** | 需水管+初级研究 | 研究能力分水岭，解锁中级科技 |
| **蒸汽涡轮机** | 高级研究+塑料 | 从被动承受热量→主动利用热量 |
| **塑料/石油** | 中级研究+找到油田 | **最大门控**：从生物质经济→工业经济 |
| **永续循环达成** | 电解+氢电+冷却+净水 | 从消耗式生存→自维持文明（质变时刻） |
| **太空** | 望远镜+高级研究 | DLC终局，跨小行星殖民 |

## C. 节奏波形

### 阶段节奏

```
阶段               时间       解锁密度    玩家状态
────────────────────────────────────────────────
开局求生(0-30周期)   极高密      每3-5周期新解锁  学习狂飙，每个科技都救命
氧气稳定(30-60)      高         每5-10周期       学会管理气体/水，基础生存达标
热量危机(60-120)     中         每10-20周期      温度→食物→电力连锁崩溃（最痛苦）
工业化(120-200)      中→低      每15-30周期     石油/塑料/太空
终局(DLC)            低         每30+周期        跨星球，无限循环优化
```

### 节奏波形图

```
压力 ▲
     │    ╱╲        ╱╲─────── 热量+食物连锁崩溃
     │   ╱  ╲      ╱
     │  ╱    ╲    ╱  ╲───── 氧/水电稳定了但热量在累积
     │ ╱ 氧气  ╲  ╱    ╲─── 塑料/太空
     │╱  危机   ╲╱
     └──────────────────────────────► 时间（周期数）
        30     60   100   150   200
```

### 节奏设计意图

1. **前60周期高密解锁**：让玩家感觉自己在快速进步，每个科技都解决一个紧急问题
2. **60-120周期的热量峭壁**：ONI 最精妙的设计——玩家前60周期的"成功"（大量机器运转）正在埋下热量炸弹。等玩家发现时已经太晚
3. **系统滞后性是核心设计工具**：污染水积累、温度上升、CO₂下沉都需要数周期才显现，创造「事后诸葛亮」式的学习曲线
4. **永续循环是心理终点**：达成「水电氧食闭环」后的成就感超越任何数值奖励

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第一次缺氧 | 瓶颈 | 藻类耗尽，学会电解 |
| 食物不够 | 瓶颈 | 种植/畜牧首开 |
| 水用完了 | 瓶颈 | 学会净水循环（筛水器） |
| 植物热死了 | **瓶颈** | 学会主动降温——最痛苦的教训 |
| 达成永续循环 | **突破** | 水电氧食全部闭环，核心质变 |
| 第一次太空发射 | 突破 | DLC 终局入口 |
