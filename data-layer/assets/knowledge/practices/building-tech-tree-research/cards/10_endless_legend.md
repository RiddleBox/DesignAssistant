# Endless Legend — 建筑类型谱系 + 科技树 + 节奏波形

> 标签：奇幻4X | 强非对称派系 | 时代门控+派系专属科技
> 参考：Batch 2 分析

---

## A. 建筑类型谱系

Endless Legend 的建筑分为**通用建筑 + 派系专属建筑**两层。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **城市基础** | 食物 | 磨坊、公共粮仓 | 人口增长基础 |
| | 工业 | 铸造厂、帝国工坊 | 产能=建造速度 |
| | 金币 | 市场、铸币厂 | 经济产出+军队维护 |
| | 科研 | 图书馆、帝国研究所 | 科技值产出 |
| | 影响力 | 使馆、帝国参议院 | 外交/帝国计划/边界扩张 |
| **军事** | 防御 | 民兵设施 | 城市守军 |
| | 特殊 | 各派系专属军事建筑 | - |
| **人口增长** | 住房 | 各时代的自治街区 | 人口容量上限 |
| **派系专属** | （差异极大） | 见下方 | 每个派系有独特的建筑树和玩法语法 |

### 派系非对称性（关键差异）

| 派系 | 专属建筑/机制 | 建筑玩法变化 |
|------|-------------|------------|
| **野行者** | 不需要城市区域（可移动城市） | 完全不同的城市系统 |
| **死灵法师** | 只建一座巨型城市 | 单城挑战→最大化一座城 |
| **裂隙领主** | 城市消耗金币而非食物增长 | 经济驱动而非农业 |
| **菌菇族** | 建筑消耗人口而非工业 | 人口作为建造成本 |
| **遗忘者** | 不能使用科技值（用金币买科技） | **绕过科技树** |
| **龙族** | 城市必须有神庙，只能由龙族单位建新城市 | 宗教军事混合 |
| **秘术师** | 城市可传送（移动到不同地块） | 完全可移动城市！ |

### 非对称性的极端程度

在上面的例子中可以看到，不同派系甚至**改变了建筑系统的底层规则**：
- 不需要城市区域
- 不需要科技值
- 用人口当建材
- 城市能移动

这是「不同文明 = 不同游戏」而非「不同文明 = 不同数字加成」的范例。

## B. 解锁条件链

### 时代门控+派系覆盖

Endless Legend 的科技树是**按时代分层的网格**：

```
时代 I（9个科技）
├── 通用科技 × 6
└── 帝国改善 × 3

时代 II（9个科技，需研究完时代I任意9个）
├── 通用科技 × 6
└── ...

时代 III → VI（同理，每层9个科技）
```

### 前置条件类型

| 条件类型 | 说明 |
|----------|------|
| 时代门控 | 每时代必须研究够9个才能进入下一时代 |
| 资源门槛 | 某些科技需要拥有特定战略资源（如钛、玻璃钢）才出现 |
| 派系专属科技 | 替换部分通用科技位置 |
| 奇观竞争 | 每座奇观全图唯一，先完成先得 |

### 链条长度

- **最短链**：0层（时代I科技直接可选）
- **最长链**：**6层时代门控** × 每层9个科技（但层内非线性和非强制顺序）
- 核心是**横向9×6矩阵**，深度6但每层宽度9

### 派系科技覆盖

带派系科技的游戏有一个通用树+派系分支。但 Endless Legend 更进一步：**派系专属科技替换了通用科技的位置**，且在时代内排序不同。

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| **时代 II** | 完成9个时代I科技 | 解锁新资源+新单位 |
| **战略资源发现** | 各时代 | 钛/玻璃钢等资源解锁对应的科技和建筑系列 |
| **派系专属时代 III-IV 科技** | 时代门控 | 一些派系在中期解开其核心机制 |
| **时代 VI** | 完成9个时代V科技 | 终局科技=胜利冲刺（科技/扩张/外交/霸权） |

## C. 节奏波形

### 节奏特点

```
决策密度
 ▲
 │ ╱╲          ╱╲          ╱╲
 │╱  ╲        ╱  ╲        ╱  ╲──── 终局竞赛
 │    ╲──────╱    ╲──────╱
 │     时代I      时代II-III    时代IV-VI
 └────────────────────────────────► 回合
```

**节奏核心模式**：研究和建造是并行的，你同时有 3-5 个城市的建造队列 + 科技研究 + 帝国计划 + 探索多线并行。这种多线节奏创造持续的目标感。

### 节奏设计意图

1. **时代门控的"聚光灯"效应**：每个时代开始时，玩家同时看到9个新科技→决策爆发
2. **非对称节奏**：不同派系的节奏完全不同——
   - 死灵法师：慢→专注→一座超级城（渐强型节奏）
   - 裂隙领主：快→有钱就扩张（金币爆发型节奏）
   - 遗忘者：没有科技等待→想买什么直接买（无等待型节奏）
3. **帝国计划的节奏接入**：每20回合可选择一个帝国计划（全局buff），与科技节奏交替
4. **冬日机制**：每 N 年一次寒冬（减产），类似 Frostpunk 的温度审判但更温和

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 派系弱项被暴露 | 瓶颈 | 裂隙领主没食物/死灵法师没军队等 |
| 战略资源不足 | 瓶颈 | 玻璃钢/秘银不出在地盘→科技锁死 |
| 冬日来临准备不足 | 瓶颈 | 食物储备不够→人口暴跌 |
| 拿到关键派系科技 | **突破** | 解开派系核心玩法链 |
| 进入时代IV | **突破** | 军事/经济/科研中的一个达到统治级别 |
| 时代VI终局 | **终局** | 所有 9 个终局科技中选冲刺方向 |
