## A. 建筑类型谱系

Factorio 的建筑分类以**物流系统**为核心组织原则，所有建筑围绕「输入→处理→输出」的流水线逻辑展开。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **采集** | 矿物 | 电力采矿机、抽油机 | 从地图节点提取原料，无限或有限储量 |
| | 流体 | 水泵 | 水资源无限但有管道流速上限 |
| **转化/生产** | 冶炼 | 石炉→钢炉→电炉 | 矿物→板材，升级提升速度/效率/模块槽 |
| | 组装 | 组装机 I/II/III | 多原料→成品，等级提升=原料种类上限+速度 |
| | 化工 | 化工厂、炼油厂 | 流体输入输出，多产出分流管理 |
| | 核能 | 离心机、核反应堆 | 铀浓缩→燃料棒→热量→蒸汽→电力 |
| **物流/传输** | 传送带 | 黄→红→蓝→绿传送带 | 带宽升级，吞吐量 15/30/45/60 items/sec |
| | 机械臂 | 黄→蓝→绿→白机械臂 | 抓取速度+堆叠数，决定节点吞吐 |
| | 管道 | 管道、地下管、储液罐 | 流体传输，流速受距离和泵影响 |
| | 物流机器人 | 建造/物流机器人 | 后期替代传送带的灵活方案 |
| | 铁路 | 火车、车站、信号灯 | 长距离大宗运输 |
| **存储** | 固体 | 木箱→铁箱→钢箱→物流箱 | 缓冲库存，物流箱与机器人网络联动 |
| | 流体 | 储液罐 | 流体缓冲，多输入输出可混 |
| **能源** | 蒸汽 | 锅炉+蒸汽机 | 初级，燃煤 |
| | 太阳能 | 太阳能板+蓄电器 | 零污染但不稳定 |
| | 核能 | 核反应堆 | 高产但需要完整燃料链 |
| **防御** | 墙/炮塔 | 石墙、机枪/激光/火焰炮塔 | 虫族压力→防御需求 |
| **研究** | 实验室 | 实验室 | 消耗科学包→解锁科技，可链式传递 |
| **火箭/终局** | 发射 | 火箭发射井 | 发射卫星→获取太空科学包（基础版终局） |
| | | | Space Age：太空平台、跨星球物流 |

### 类间关系

```
采集（矿/油/水）
  ↓
转化（炉/组装机/化工厂）—— 依赖能源
  ↓
物流（传送带/机械臂/管道/火车）—— 连接所有节点
  ↓
研究（实验室）—— 消耗多级科学包
  ↓
科技解锁 → 新建筑/升级 → 新采集/转化/物流需求
```

**关键依赖链**：
- 铁板 → 铜线 → 电路板 → 高级电路 → 处理器（四级深度）
- 科学包 I（红）→ II（绿）→ III（蓝）→ IV（紫）→ V（黄）→ VI（白）= 7级科学包门控

## B. 解锁条件链（科技树拓扑）

### 前置条件类型

| 条件类型 | 示例 | 占比 |
|----------|------|------|
| 前置科技（AND） | 自动化2 需 自动化1 + 电子学 | ~90% |
| 前置科技（OR） | 部分可选路径 | ~5% |
| 科学包门槛 | 蓝瓶需要石油化工链前置 | ~100%（隐含） |
| 资源门槛 | 蓝瓶需原油=必须找到油田 | ~50% |

### 链条长度

- **最短链**：1层（基础科技，如自动化1，0前置）
- **最长链**：**7层**（从红瓶到白瓶完整链：自动化→物流→化工→生产→高科技→太空）
- **典型深度**：4-5层

### 分支结构

**树状 + 收敛**（非纯树，有交叉依赖）

```
        自动化1
        /     \
   物流1      电子学
    /  \        /  \
 物流2 铁路  自动化2 电路网络
  /      \    /   \
物流3   铁路信号  处理器
  \       |      /
   物流网络 → 终局科技
```

结构特征：
1. **根节点收敛**：所有线路从 自动化1 开始
2. **中期交叉**：不同分支在 3-4 层开始交叉依赖（如物流需要电子学，军事需要化工）
3. **终局再收敛**：白瓶（太空科学）作为终极门控
4. **无限延伸**：采矿产能/机器人速度等可无限重复研究

### 关键门控节点

| 门控节点 | 解锁条件 | 为什么是转折点 |
|----------|----------|---------------|
| **自动化2** | 红+绿瓶，自动化1+电子学 | 解锁组装机II，手工→半自动 |
| **石油化工** | 蓝瓶门槛 | **最大瓶颈**：强制玩家从简单矿产转向流体系统 |
| **建筑机器人** | 蓝瓶+绿瓶 | 解锁蓝图铺建，从手工铺设→自动化建造 |
| **物流网络** | 黄瓶+紫瓶 | 解锁请求箱/供应箱，物流质变 |
| **火箭发射井** | 全色瓶 | 进入终局/太空时代 |

## C. 节奏波形

### 解锁间隔模式

```
阶段          科学包需求      解锁密度      玩家感受
─────────────────────────────────────────────────
开局(0-30min)  红瓶            极高          每小时5-10个新科技，快速扩张可能
早期(30min-2h) 红+绿瓶         高            攀科技树很顺畅
中期(2-10h)    红+绿+蓝瓶      低→中         石油化工爆炸（瓶颈！）
中后期(10-30h) 红+绿+蓝+紫+黄  中             多个瓶颈并行
终局(30-60h)   全色+白瓶       低（无限科技）  重复优化，产能竞赛
```

### 节奏波形图（玩家心理能量曲线）

```
能量 ▲
     │  ╱╲
     │ ╱  ╲___  ← 石油化工瓶颈（最痛苦的 2-4 小时）
     │╱       ╲___  ← 紫瓶/黄瓶扩展
     │          ╲_______  ← 火箭发射后的终局
     └──────────────────────────────► 时间
```

### 节奏设计意图

1. **开局密集爆发**：0-30分钟解锁大量基础建筑，给玩家「我能建一切」的错觉
2. **石油化工作为成人礼**：故意设计为最大瓶颈（需要全新思维：流体+多产出管理+化工链），淘汰不会用流体的玩家
3. **中后期交错瓶颈**：紫瓶（生产规模）和黄瓶（高科技）要求玩家同时优化两条线
4. **火箭作为心理终点**：发射火箭标记「通关」，之后无限科技给持续型玩家

### 瓶颈 & 突破时刻

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第一次缺铁 | 瓶颈 | 刚学会采矿就耗尽，学会扩矿 |
| 石油化工 | **瓶颈** | 2-4小时的痛苦转型，学会流体管理 |
| 油不够了 | 瓶颈 | 需要开拓新油田+铁路运输 |
| 第一次造出建筑机器人 | **突破** | 蓝图自动铺建，从此建造不再用手 |
| 物流网络完成 | **突破** | 请求/供应自动化，产能管理质变 |
| 火箭发射 | **突破** | 完成主线，已掌握全部系统 |
