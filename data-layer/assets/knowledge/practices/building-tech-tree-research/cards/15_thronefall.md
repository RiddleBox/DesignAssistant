# Thronefall — 建筑类型谱系 + 科技树 + 节奏波形

> 标签：极简塔防/策略 | 无科技树 | 日/夜周期建筑选择
> 参考：Batch 1 分析

## A. 建筑类型谱系

Thronefall 的建筑列表极度精简（每局约 10-15 个可选建筑），分类清晰。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **经济** | 金币产出 | 农场、磨坊、港口、市场 | 每轮产出金币 |
| | 特殊经济 | 酿酒厂、渔港 | 产金币+特定加成 |
| **军事/防御** | 城墙 | 栅栏→石墙→城门 | 阻挡/引导敌人路径 |
| | 塔楼 | 箭塔、炮塔 | 自动攻击经过的敌人 |
| | 军营 | 兵营、靶场 | 训练单位防守 |
| **人口** | 住房 | 小屋→房屋→豪宅 | 提供人口（更多人=更多金币=可建更多建筑） |
| **英雄** | 英雄升级 | 不同武器/装备选择 | 每局可选不同装备组合 |
| **特殊** | 祝福 | 不同地图的独特建筑 | 给予独特能力 |

### 极简选择压力

每回合只能在**已解锁的有限选项中**建造 N 个建筑。你的金币有限、地块有限、且白天时间有限。这使得每个建筑选择都是**权重极高的战略决定**。

## B. 解锁条件链

### 无局内科技树

Thronefall 的局内**完全没有科技树**。

但存在**跨局解锁的永久升级**：

| 解锁系统 | 说明 |
|----------|------|
| **关卡解锁** | 完成一关→解锁下一关（新地图+新建筑选项） |
| **特权升级** | 局后金币购买永久被动（如"所有农场+10%产出"） |
| **武器/装备解锁** | 完成挑战解锁新英雄装备 |
| **突变器** | 自行添加难度修饰符（如"敌人+50%伤害"）→更高分数 |

### 局内建筑决策

局内解锁顺序**完全由玩家自由选择**，但受制于：

```
白天：选择建什么（经济/防御/住房）
    ↓
夜间：敌人进攻！你建的东西够不够？
    ↓
战后：获得金币（经济建筑多=金币多）
    ↓
新白天：更多金币=能建更多/更好建筑
    ↓
循环N波→最终波→胜利/失败
```

### 前置条件（隐含）

- 金币：所有建筑的建造都需要金币
- 人口：住房先建造→提供人口→才能造更多
- 地块：地图上有限的可建地块
- 战略选择：你是先造防御还是先造经济？先造左边还是右边？

## C. 节奏波形

### 日/夜极简节奏

```
活动强度
 ▲
 │ ████          ████          ████
 │ ████  建造     ████  建造     ████
 │ ████          ████          ████  ← 夜间：战斗！
 │ ████          ████          ████
 │                ████          ████
 │                ████          ████
 │  战斗！         战斗！         战斗！
 └──────────────────────────────────► 波次
   波1   波2    波3  ...   最终波
```

### 极简但高效的设计

每局在 10-20 分钟内经历：
1. **建造成长期**（白天 30-60 秒）→ 紧张选择
2. **防守战斗**（夜间 60-120 秒）→ 验证建造决策
3. **结算**（几秒）→ 获得金币
4. **重复** 5-10 波次

这种 **1-2 分钟的微循环**在建筑策略游戏中是极其短促的，创造了独特的"快速→验证→再快速→再验证"的节奏。

### 节奏设计意图

1. **日/夜分割 = 呼吸节奏**：白天是「计划呼吸」，夜晚是「执行验证」
2. **每次夜间战斗都是一次 mini-boss 审判**：检验你白天的全部决策
3. **有限波次 = 有限决策次数**：你知道第 10 波是终局，所以在第 5-6 波就必须开始为终局规划
4. **经济 vs 防御的永恒张力**：每多建一个经济建筑→夜间少一座塔→更多金币→下一轮更强。这是 Thronefall 的核心节奏循环

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第一夜守不住 | 瓶颈 | 低估敌人→建太少防御 |
| 金币滚雪球开始 | **突破** | 经济建筑多→金币多→可买更多→正飞轮 |
| 关键塔位置选对 | 突破 | 一座箭塔在正确位置 = 三座的效率 |
| 最终波 | **终局审判** | 全关的最强敌人波→所有前期决策的最终验证 |
