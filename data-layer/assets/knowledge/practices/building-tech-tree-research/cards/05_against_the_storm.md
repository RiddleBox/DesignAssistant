## A. 建筑类型谱系

Against the Storm 的建筑体系极其精简：**核心建筑预制 + 随机蓝图池选择**。

| 大类 | 子类 | 代表蓝图/建筑 | 核心机制 |
|------|------|-------------|----------|
| **采集** | 基础采集 | 伐木工营地、采集者营地、石匠营地 | 初始可用，不限蓝图 |
| | 高级采集 | 捕猎者小屋、草药师小屋 | 需要蓝图选择解锁 |
| **食物生产** | 初级加工 | 田地点、牧场 | 从采集→种植/养殖 |
| | 高级加工 | 磨坊、面包房、屠宰场 | 原料→高级食物（复杂食物满足更多需求） |
| **工业/建材** | 基础 | 粗制工坊 | 初始可用，生产木板/砖块/布料 |
| | 高级 | 锯木厂、窑、织布机 | 蓝图解锁，效率3倍于基础版 |
| **服务/需求满足** | 娱乐 | 酒馆、茶馆、论坛 | 满足种族偏好，获得声望 |
| | 教育 | 学校、公会大厅 | 种族教育需求 |
| | 宗教 | 神殿、修道院 | 满足宗教需求（特定种族） |
| **住房** | 庇护所 | 临时居所→种族专属住房 | 每种族的专属住房满足不同需求 |
| **装饰/效率** | 增益 | 仓库、道路、装饰物 | 减少行走时间、增加满意度 |
| **贸易** | 贸易站 | 贸易站 | 用多余资源换缺失资源 |
| **事件/探索** | 林间空地 | 林间空地事件 | 地图上的可探索点，用资源/人口换取奖励 |

### 类间关系

```
基础采集（初始可用）
    ↓
粗制工坊（初始可用）→ 基础建材
    ↓
蓝图选择（随机3-4选1）← 声望获取
    │
    ├── 高级食物链：农田→磨坊→面包房（满足复杂食物需求）
    ├── 高级建材链：锯木厂/窑/织布机（三倍效率）
    ├── 服务链：酒馆/茶馆/神殿（满足服务需求→声望）
    └── 贸易链：贸易站（用盈余换匮乏）
```

**独特之处**：
- **无完整建筑树**：你不会（也不能）建所有建筑
- **蓝图的随机性 = 每局不同的建筑组合**：这局有面包房但没磨坊？那你这局不做面包
- **需求链作为目标**：每个种族有偏好的复杂食物/服务/住房。满足→声望→新蓝图→更多满足→正向循环

## B. 解锁条件链

### 前置条件类型

| 条件类型 | 说明 | 独特性 |
|----------|------|--------|
| **蓝图随机选择** | 每次声望达到阈值，从随机池中3-4选1 | **核心机制**，替代传统科技树 |
| 声望门槛 | 获得足够声望解锁下一个蓝图选择 | 驱动玩家去满足种族需求 |
| 命令（Orders） | 完成任务获得额外蓝图或加成 | 类似可选支线 |
| 基石（Cornerstones） | 每级声望选一个永久被动加成 | 影响战略方向 |

### "科技树"本质：声望驱动随机选择

```
                  声望等级1 → 随机3选1蓝图
                 /           \
        声望等级2 → 3选1     基石选择 → 全局被动
       /
声望等级3 → 3选1
       \
        声望等级4 → 3选1
                   \
                    声望等级N（终极）→ 胜利条件
```

**这不是树！** 这是**线性随机池选择**：
- 不存在固定前置依赖链（你不需要有磨坊才能解锁面包房，可能同时出现）
- 不存在跨局继承（每局独立）
- 但存在「软依赖」：选了磨坊没选面包房=磨坊作用下降，需要贸易或其他用途

### 元游戏解锁（跨局）

| 系统 | 说明 |
|------|------|
| 城堡升级 | 用局后资源解锁新种族、新蓝图、初始加成 |
| 天赋树 | Smoldering City 中的永久升级 |
| 蓝图池扩展 | 随城堡升级，可选蓝图池子变大 |

### 链条长度

- **每局内**：N层声望→N次蓝图选择（无前置深度，只有顺序）
- **跨局**：城堡升级树约20-30个节点

### 关键选择节点

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第一个蓝图 | **开局决定** | 决定本局核心产业链 |
| 基石选择 | **战略定型** | 每3个声望级的基石决定长期策略 |
| 第5-6个蓝图 | **中期抉择** | 开始有余力补服务/解决种族需求 |
| 最终蓝图 | 冲刺 | 最后一个蓝图用于满族需求冲刺胜利 |

## C. 节奏波形

### 局内节奏

```
压力/注意力
 ▲
 │  ╱╲   ╱╲   ╱╲
 │ ╱  ╲ ╱  ╲ ╱  ╲──── 暴风雨季（每3年=每局约3个周期）
 │╱    ╲╱    ╲╱
 │
 └────────────────────────────────► 时间（年份）

开局：人口少+基础采集
第1年末：第一次蓝图+看种族需求
第2-3年：建立核心产业链
暴风雨季：森林敌意飙升，减产，必须撑住
暴风雨后：恢复+扩建
满足种族→声望→更多蓝图→更多满足→正飞轮
女王急躁度 14 = 失败
```

### 节奏波形（玩家心理）

```
满足感 ▲
       │                ╱── 胜利满足感飙升
       │     ╱──╲─────╱
       │    ╱    ╲   ╱
       │ ╱─╱      ╲─╱──── 暴风雨低谷（焦虑）
       │╱
       └────────────────────────► 时间
```

### 节奏设计意图

1. **暴风雨作为节奏器**：每3年一次审判→必须准备→准备期间加速基建→暴风雨后奖励
2. **声望=解锁=希望**：不是科技研究，而是你的子民认可你→给你选择权
3. **女王急躁度作为倒计时**：红色进度条不断增长（因不满、时间流逝等），创造"必须加速"的压力
4. **每局独特的建筑组合** = Roguelite 的核心节奏：这局没面包房？那就走肉类路线。每局重新「学习」最优路径

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 蓝图没给好 | **瓶颈** | 随机性惩罚——抽不到产业链核心建筑 |
| 忽视种族偏好 | 瓶颈 | 忘了满足特定种族的复杂食物→不满飙升 |
| 暴风雨准备不足 | **瓶颈** | 木材/食物耗尽→人口死亡→负飞轮 |
| 第一个复杂食物链达成 | **突破** | 声望加速器开启 |
| 服务建筑集齐 | **突破** | 种族全面满足，声望快速冲刺 |
| 胜利 | **突破** | 女王急躁度打满前完成声望目标 |
