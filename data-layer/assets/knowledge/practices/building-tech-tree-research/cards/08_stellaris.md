## A. 建筑类型谱系

Stellaris 的建筑分为三大类：**星球建筑、太空站模块、巨型结构**。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **星球建筑** | 资源区划 | 发电区、矿区、农业区 | 按星球特征分配区划数量（如矿产丰富的星球矿区多） |
| （占用建筑槽） | 城市区划 | 城市区 | 提供住房+建筑槽位 |
| | 生产建筑 | 合金铸造厂、消费品工厂 | 转化基础资源为高级资源 |
| | 科研建筑 | 研究实验室 | 产出物理/社会/工程研究值 |
| | 文化/统一 | 纪念碑、寺庙 | 产出统一值（Unity，驱动传统树） |
| | 人口增长 | 基因诊所、机器人组装厂 | 加速人口增长或组装机械人口 |
| | 军事 | 要塞、护盾发生器 | 星球防御 |
| | 稀有资源 | 燃气精炼厂、水晶矿场 | 生产/转化战略资源（科技/军事必需品） |
| **太空站** | 船坞 | 造船厂 | 建造军事舰船 |
| （星基地模块） | 贸易 | 贸易中心 | 收集星系贸易值 |
| | 锚地 | 锚地 | 增加海军容量 |
| | 防御 | 炮台、机库 | 星基地武装 |
| | 特殊 | 黑市、策展人智库 | 事件/飞地解锁 |
| **巨型结构** | 初级 | 栖息地（Orbital Habitat） | 人工可居空间站 |
| | 终极 | 戴森球、物质解压器、环世界 | **每座都是终局级成就**，建造需数十年 |

### 建筑槽位系统

每个星球有有限的建筑槽位（受城市区划和科技解锁），创建了**空间稀缺性**的决策压力。

### 类间关系

```
区划（District）→ 基础资源生产（能源/矿物/食物）
    ↓
城市区 → 建筑槽位（Unlock Slots）
    ↓
建筑（Building）→ 转化基础资源为高级资源 + 科研/统一/稀有
    ↓
科技三线 + 传统树 → 解锁新建筑/新槽位/巨型结构
    ↓
星基地模块 → 军事/贸易/防御
    ↓
巨型结构 → 终局无限产出
```

## B. 解锁条件链

### 三线并行 + 卡牌抽取

Stellaris 的科技系统是**最独特的**之一：

| 维度 | 物理研究 | 社会研究 | 工程研究 |
|------|----------|----------|----------|
| 研究值来源 | 物理实验室 | 生物实验室 | 工程实验室 |
| 解锁内容 | 武器/护盾/能源/计算 | 行政/人口/殖民/基因 | 舰船/空间站/建筑/巨型结构 |
| 代表科技 | 聚变反应堆、超光速、AI | 殖民、基因改造、灵能 | 战列舰、戴森球、环世界 |

### 卡牌抽取机制（非树！）

```
每完成一项研究 → 从当前可用科技池中随机抽取3-5张卡 → 玩家选1张研究
```

- **没有固定的科技树**！可用科技由权重+随机决定
- 稀有科技（紫色边框）需要特定前置条件才会进入卡池
- 科学家的专长领域影响卡池权重（如"计算"专长→更多物理计算卡）

### 传统树（独立于科技）

| 传统树 | 核心主题 | 终局 |
|--------|----------|------|
| 扩张 | 更快殖民 | - |
| 探索 | 更快勘测 | 科学船自带隐形 |
| 支配 | 军事征服 | - |
| 繁荣 | 经济效率 | - |
| 和谐 | 人口幸福度 | - |
| 霸权 | 附庸管理 | - |
| 外交 | 星系共同体 | - |
| 机敏 | 间谍活动 | - |

每棵传统树 5 个节点 + 1 终局解锁。完全传统树后解锁**飞升特权**（Ascension Perk），飞升特权又解锁巨型结构和特殊路线。

### 前置条件类型

| 条件类型 | 说明 |
|----------|------|
| 随机卡池 | 取决于已研究科技+科学家专长+帝国伦理 |
| 前置科技（隐式）| 某些科技必须有前置才出现（但不对玩家显式标注） |
| 稀有科技 | 需要特定触发条件进入池子 |
| 科技Tier | Tier 1→5，需足够Tier 1才能看到Tier 2 |
| 传统树解锁 | 完全完成一棵传统树解锁飞升特权 |
| 飞升特权 | 是解锁巨型结构的关键（如"银河奇迹"→戴森球/环世界） |
| 人口门槛 | 飞升理论需要足够人口 |
| 伦理限制 | 某些科技/传统与帝国伦理冲突（如和平主义不能研究部分军事科技） |

### 链条长度

- **最短研究链**：0层（初始科技直接可选）
- **最长链（巨型结构）**：**约8层**（基础工程→空间站升级→巡洋舰→战列舰→泰坦→巨型结构工程→特定巨型结构）
- **传统树深度**：每棵5层+1终局

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| **殖民船科技** | 社会研究Tier 1 | 从单星球→多星球 |
| **巡洋舰/战列舰** | 工程推进 | 军事能力质变跳点 |
| **飞升理论** | 稀有科技 | 解锁飞升特权槽位 |
| **巨型结构工程** | 飞升特权+战列舰 | 开启终局建筑可能 |
| **戴森球/环世界** | 银河奇迹飞升特权 | 每座建造数十年，终局成就 |
| **三大危机路线** | 特定飞升特权 | 灵能/基因/合成三大终局飞升 |

## C. 节奏波形

### 三阶段节奏

```
阶段        时间         科技密度     事件密度
──────────────────────────────────────────────
探索期      0-50年       极高          高（首次接触+异常点）
扩张期      50-100年     中            中（边界接触+外交）
巩固期      100-150年    较低          低→高（银河共同体+危机前兆）
终局危机    150-200年+   低→有目标     极高（危机爆发）
```

### 节奏波形

```
事件/紧张度
 ▲
 │ ╱╲                        ╱───── 终局危机爆发
 │╱  ╲ ╱╲                   ╱
 │    ╲╱  ╲ ╱╲   ╱╲       ╱
 │         ╲╱  ╲╱  ╲ ╱───╱──── 危机平息/帝国覆灭
 │                   ╲
 └────────────────────────────────► 时间（年）
  探索  扩张  巩固  无聊期  危机
```

### 节奏设计意图

1. **探索期的科技密集**：利用"第一次接触"的新奇感，快速解锁大量科技
2. **中期的无聊期是设计的**：Stellaris 故意留出50-80年相对安静的窗口，让玩家建设内部帝国
3. **危机作为终局唤醒**：Unbidden/Prethoryn/Contingency 三大危机之一在终局爆发，打破无聊→全银河动员
4. **随机抽取维持新鲜感**：没有固定科技树→每局科技顺序不同→每局不同的「建筑组合」

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 核心科技一直抽不到 | **瓶颈** | 随机卡池的代价——可能很久拿不到战列舰 |
| 第一次殖民 | 突破 | 多星球管理开启 |
| 飞升特权首解锁 | **突破** | 帝国开始有独特"超能力" |
| 巨型结构开始建造 | **突破** | 数十年的等待，终局成就 |
| 终局危机爆发 | **终局审判** | 全银河动员，前200年的军事建设见分晓 |
