# Frostpunk — 建筑类型谱系 + 科技树 + 节奏波形

> 标签：末日生存/道德抉择 | 双树结构（科技+法典）| 绝望节奏
> 参考：Batch 4 分析

---

## A. 建筑类型谱系

Frostpunk 的建筑围绕**热量管理**这个绝对核心组织，所有次级系统都是为热量服务或消耗热量。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **热量** | 核心 | 发电机 | 城市唯一热源，需消耗煤炭，升级4级功率/范围 |
| | 扩展 | 蒸汽枢纽 | 从发电机延伸热量覆盖范围 |
| **资源采集** | 煤炭 | 煤矿→采煤机→蒸汽采煤机→高级采煤机 | 煤炭是生命线，耗尽=死亡 |
| | 木材 | 锯木厂→蒸汽锯木厂 | 基础建材 |
| | 钢铁 | 钢厂→蒸汽钢厂 | 高级建材和科技必需品 |
| | 食物 | 猎人小屋→温室→工业温室 | 满足饥饿需求 |
| **人口/居住** | 住房 | 帐篷→工棚→房屋 | 从简陋到保暖，直接影响生病率 |
| | 医疗 | 医疗站→医务所 | 治疗伤病，影响希望 |
| | 儿童 | 儿童庇护所（法典选择）| 选择让儿童上学还是工作 |
| **探索/外勤** | 侦察 | 侦察队→前哨站 | 获取地图外部资源 |
| **法律/秩序** | 法典解锁 | 警卫站、监狱、宣传中心 | 由法典树（非科技树）解锁 |
| | 秩序线 | 宣传中心→监狱→新秩序 | 高压统治路线 |
| | 信仰线 | 祈祷室→神殿→新信仰 | 宗教慰藉路线 |
| **科技/效率** | 研究 | 工坊 | 唯一的研究建筑，工程师越多越快 |
| **基础设施** | 道路 | 街道 | 影响通行效率和取暖范围 |

### 类间关系

**单核心辐射模型**（与 Factorio 的流水线模型截然不同）：

```
                发电机（唯一热源）
               /  |  |  |  \
             热   热  热  热  热
            /      |   |   |    \
        煤炭采集  居住  医疗  食物  研究
          │        │    │    │     │
        法典 ← → 科技树 ← → 希望/不满 ← → 人口
```

所有建筑必须建在发电机热量范围内（或蒸汽枢纽延伸）。
**没有热量 = 一切归零**。这是最独特的设计约束。

### 双树架构

Frostpunk 有两个独立的解锁系统：

| 维度 | 科技树 | 法典树 |
|------|--------|--------|
| 驱动资源 | 工程师（研究速度）+ 资源 | 冷却时间（每次签署有冷却）+ 希望/不满 |
| 解锁物 | 建筑升级、效率提升 | 新法律、新建筑类型、新治理手段 |
| 选择性质 | 通常单向（解锁即可） | 二择一（选了一条锁另一条） |
| 节奏 | 资源驱动，可加速 | 固定冷却时间，不可加速 |
| 后果 | 效率高低 | 道德+游戏机制双后果 |

## B. 解锁条件链

### 科技树拓扑

**4层深度×5大分支 = 蛛网结构**

```
Tier 0（初始解锁）  Tier 1         Tier 2        Tier 3          Tier 4        Tier 5
──────────────────────────────────────────────────────────────────────────────────
（工坊建成自动可用）
  灯塔              ─→ 侦察队加速   ─→ 前哨站       ─→ 前哨站优化
  采集基础           ─→ 蒸汽采集     ─→ 高级采集     ─→ 采集优化       ─→ 终极采集
  猎人装备           ─→ 猎人策略     ─→ 温室         ─→ 工业温室
  加热器             ─→ 蒸汽枢纽     ─→ 房屋设计     ─→ 房屋改造       ─→ 房舍再开发
  锯木厂             ─→ 钢厂         ─→ 蒸汽钢厂     ─→ 高级钢厂
  医疗站升级         ─→ 医务所       ─→ 医疗选择     ─→ 医疗自动化
  煤矿               ─→ 蒸汽煤矿     ─→ 高级煤矿     ─→ 采煤机优化
```

**结构特征**：
1. **宽分支+浅深度**：7-8条并行线，每线4-5层Tier
2. **Tier 解锁依赖前置Tier的任一项研究**：只要在同一分支点了足够数量，就解锁下一Tier
3. **无跨分支依赖**：煤炭线不需要医疗线前置（符合末日逻辑——活着比治病更优先）
4. **双倍工程师加速**：不是解锁条件，但影响研究节奏

### 法典树拓扑

```
（初始可用）
  │
  ├── 适应路线 ──┬── 对抗 ──┬── ...
  │              │          └── 新秩序
  │              └── 维持生命 ──┬── 额外配给 ── 私酿酒
  │                             └── ...
  │
  └── 秩序/信仰 ──┬── 秩序线 ── 邻里守望 → 晨间集会 → 警卫站 → 监狱 → 宣传中心 → 新秩序
                  │
                  └── 信仰线 ── 祈祷室 → 晚祷 → 神殿 → 信仰守护者 → 公开忏悔 → 新信仰
```

法典结构是**平层的二择分支**，不是深度树。每层选一项→进入下一层。

### 链条长度

- **科技树最短链**：1层（初始科技）
- **科技树最长链**：5层（从Tier 0到Tier 5采集/医疗线）
- **法典树**：7-8个法律层级（但只是依次选择，无前置依赖）

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| **灯塔** | Tier 0 | 解锁侦察队→可外出探索（从封闭→开放世界） |
| **蒸汽枢纽** | Tier 1 加热器线 | 从单核心热源→辐射热源网络 |
| **温室** | Tier 2 食物线 | 从打猎→稳定食物（但不点法典），质变 |
| **前哨站** | Tier 3 | 可从地图外部稳定获取资源 |
| **法典：秩序/信仰** | 法典树 | 路线第一次分叉，决定治理哲学 |
| **新秩序/新信仰** | 法典树末尾 | 终极道德抉择，改变游戏结局 |

## C. 节奏波形

### 独有的"剧本节奏"

Frostpunk 不按自由节奏，而是**每个剧本有固定节奏波形**（温度下降、事件触发、结局审判）。

以「新家」剧本为例：

```
温度
 ▲
 │  ╲                    ← 开局：-20°C 还行
 │   ╲                   ← 第5天：-40°C 开始紧张
 │    ╲                  ← 第10天：-60°C 必须在法典和科技间取舍
 │     ╲                 ← 第15天：暴风雪预警
 │      ╲                ← 第20天：伦敦人事件（道德分裂）
 │       ╲ ╱╲ ╱╲        ← 难民潮
 │        ╲╱  ╲╱         ← 资源压力
 │                       ← 第40天：终局暴风雪 -150°C
 └────────────────────────► 时间（天数）
```

### 节奏波形（玩家心理能量）

```
能量 ▲
     │   ╱╲               ← 刚学会系统，信心高
     │  ╱  ╲
     │ ╱    ╲  ╱╲         ← 暴风雪来袭，重新紧张
     │╱      ╲╱  ╲
     │          ╲  ╲___   ← 绝望中坚持到最后
     │           ╲    ╲
     └────────────────────────► 时间
```

### 节奏设计意图

1. **剧本化节奏**：不是沙盒，是精心编排的绝望交响曲
2. **温度作为节奏器**：每次温度下降 = 必须升级取暖科技 = 加速资源消耗
3. **双树节奏交错**：科技树→解决物理问题，法典树→解决社会/道德问题。两者交替牵引注意力
4. **24小时不间断**：没有暂停/回合的喘息，持续的时间压力
5. **关键是「够」不是「最优」**：不要给玩家时间优化，要让他们永远觉得差一点

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 第2天煤炭耗尽 | 瓶颈 | 学会煤炭是第一优先级 |
| 第5天温度骤降 | 瓶颈 | 开始真正理解热量覆盖 |
| 第10天食物危机 | 瓶颈 | 法典选择（汤 vs 食品添加剂） |
| 伦敦人事件 | **瓶颈** | 道德抉择：镇压还是说服 |
| 第一次度过暴风雪 | **突破** | 学会预测和准备 |
| 终局暴风雪 | **终局审判** | 所有前期决策的后果集中爆发 |
