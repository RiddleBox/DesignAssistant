# Humankind — 建筑类型谱系 + 科技树 + 节奏波形

> 标签：历史4X | 时代文化切换 | 身份断裂争议
> 参考：Batch 2 分析

## A. 建筑类型谱系

Humankind 的建筑体系遵循**区域分区+时代升级**模式。

| 大类 | 子类 | 代表建筑 | 核心机制 |
|------|------|----------|----------|
| **资源采集** | 农业 | 农场、牧民营地 | 食物产出，受地形影响 |
| | 工业 | 矿场、采石场 | 产能产出 |
| | 商业 | 市场、港口 | 金币产出 |
| | 科研 | 研究所、图书馆 | 科技值产出 |
| **城市区域** | 特色区域 | 各文化专属区域 | 每个时代新文化的**标志性区域**是其核心特色 |
| | 基础设施 | 引水渠、粮仓、公共喷泉 | 区域产出的百分比加成 |
| **军事** | 防御 | 城墙、堡垒 | 城市/地块防御 |
| | 军事生产 | 兵营、靶场 | 产能转化为军事单位 |
| **文化/影响力**| 文化 | 石碑、奇观（巨构） | 产出影响力（用于扩张领土和外交） |
| **宗教** | 圣地 | 神社、大教堂 | 信仰产出（影响人口和外交） |
| **奇观** | （独立） | 金字塔、埃菲尔铁塔等 | 整局游戏每座唯一，先到先得 |

### 时代文化切换——最核心设计

```
时代1（远古）→ 选择文化A（如巴比伦：科研加成）
    ↓
时代2（古典）→ 切换文化B（如罗马：军事加成）或保留A
    ↓
时代3（中世纪）→ 切换文化C（如高棉：农业加成）
    ↓
...
    ↓
时代6（当代）→ 切换文化F 或保留E
```

**每次换文化 = 获得新特色区域 + 新特殊能力。旧文化建筑保留但不再获得加成。**

## B. 解锁条件链

### 科技树结构

**单线+时代门控+文化影响**：

```
时代门控：必须完成一定数量科技才能进入下一时代
    ↓
每个时代内科技 = 单线排列（非网状）
    ↓
文化被动加成影响科技获取速度但非解锁条件
```

Humankind 的科技树是**近乎线性的**：
- 没有真正的分叉——每个时代内科技按顺序解锁
- 不同文明的不同在于**先解锁什么更有利**（如科研文化先攀科技树）
- 先到新时代的玩家 **先抢走文化**。

### 前置条件类型

| 条件类型 | 说明 |
|----------|------|
| 前置科技（线性） | 需完成上一科技 |
| 时代门控 | 需积累 7/7 时代之星（完成足够成就） |
| 文化抢占 | 先进入新时代的玩家先选文化！后来者只能选剩下的 |
| 人口门槛 | 城市每2人口解锁一个区域槽 |
| 奇观抢占 | 先研究完科技+释放奇观的人独占 |

### 链条长度

- **最短链**：1层（时代首个科技）
- **最长链**：约 40+个科技（从远古到当代全科技树）
- **文化链**：6次切换（6个时代）

### 关键门控节点

| 门控节点 | 条件 | 为什么是转折点 |
|----------|------|---------------|
| **选择第一个文化** | 游戏开始 | 决定初期路线（巴比伦→早科技，周朝→早美学，哈拉帕→早食物） |
| **时代推进** | 7个时代之星 | 每一次时代推进 = 新文化选择 = 策略大转向 |
| **文化被抢** | 其他文明先进时代 | **最重要的事件**——你规划的路线可能被抢走 |
| **中世纪** | 第3次文化选择 | 宗教和信仰的权重增加 |
| **工业时代** | 第5次文化选择 | 生产力爆炸，可以接近终局 |
| **当代** | 最后一次文化选择 | 终局身份定型，冲刺胜利条件 |

## C. 节奏波形

### 节奏特点

```
文化/身份变化频率
 ▲
 │ ╱╲  ╱╲  ╱╲  ╱╲  ╱╲  ╱╲
 │╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲
 │    文化切换  文化切换  ...
 └────────────────────────────────► 时代
 远古  古典  中世纪  ...   当代
```

每次时代推进都是「文明身份重塑」。但这引发了核心争议：**身份断裂感**。

### 节奏争议（值得研究的设计问题）

**争议 1：文化跳跃是否破坏沉浸？**
- 一些玩家认为"从巴比伦到罗马再到蒙古"的历史跳跃破坏了文明连续性
- 另一些玩家认为这正是 Humankind 的独特乐趣——「如果历史不是注定呢？」

**争议 2：时代之星系统**
- 时代之星 = 每个时代的"成就清单"（如"获得3个科技之星""获得2个军事之星"）
- 玩家按清单做→达成→推进时代
- **批评**：把文明演化变成了 checklist，降低了涌现感

### 节奏设计意图

1. **时代切换 = 决策爆发点**：每次时代切换是全场注意力的巅峰
2. **文化抢占焦虑**：第一个进入新时代的人先选文化→激励加速
3. **中间段线性科技**：每个时代内的线性科技链提供可预测的进步感
4. **终局冲刺**：当代6个胜利条件（科技/军事/文化/外交/经济等）全部开放，选择冲刺方向

### 瓶颈 & 突破

| 时刻 | 类型 | 描述 |
|------|------|------|
| 规划的文化被别人抢了 | **瓶颈** | Humankind 最独特的挫折体验 |
| 时代之星凑不满 | 瓶颈 | 卡在当前时代，看着别人冲前 |
| 城市区域槽不够 | 瓶颈 | 人口增长太慢→无法新建区域 |
| 切换到一个完美适合局势的文化 | **突破** | "刚好我需要这个"的满足 |
| 独占一座奇观 | 突破 | 全局唯一的建筑成就感 |
| 当代胜利冲刺 | **终局** | 一路的文化积累在最后时代兑现 |
