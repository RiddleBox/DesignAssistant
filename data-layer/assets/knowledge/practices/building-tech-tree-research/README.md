## 关键发现速览

- **不存在"正确"的建筑树**：15款游戏7种不同的解锁驱动模式
- **瓶颈→突破波形**是所有优秀游戏的共性节奏
- **四种审判时刻**（灾难周期/日夜季节/人口波动/时代审判）是节奏锚点
- **终局六种角色**：终结者/放大器/新游戏+/展示/路线终局/无终点
- 对文明Roguelite的建议：随机池+事件触发+阶段审判的混合模式
