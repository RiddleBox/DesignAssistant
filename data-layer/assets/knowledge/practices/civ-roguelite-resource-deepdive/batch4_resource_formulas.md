# Batch 4：模拟经营 / 工程反馈 / 瓶颈升级 — 资源经济公式深度拆解

---

## 1. Factorio

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 铁矿/铜矿/煤矿/石材/铀矿 | 基础矿物 | 原料层 |
| 铁板/铜板/钢/塑料/电路/齿轮 | 中间品 | 加工层 |
| 红/绿/蓝/紫/黄/白科学包 | 科研消耗品 | 研究层 |
| 电力 | 全局能源 | 产能乘数 |
| 石油/水/硫酸/润滑油 | 流体资源 | 特殊转化层 |

### 收集公式（分层）
```text
原料层：矿石 = 采矿机 × 矿脉丰富度 × 电力
加工层：铁板 = 矿石 / 冶炼时间（1:1转化，瓶颈在冶炼机数量）
研究层：科学包 = 多层原料链压缩（紫瓶需要 7 层链）

全局产出 = min(
  采矿速率,
  传送带运力（item/s）,
  冶炼速率,
  组装速率,
  终端消耗速率
)
```

每一项都是一个独立瓶颈。任一环节缓慢 → 全链停滞。

### 消耗公式
```text
科学包 = 持续消耗（研究不中断则消耗不停止）
弹药 = 防御消耗（虫族来袭频率 × 炮塔数量）
电力 = 所有机器的持续消耗（峰值决定电厂规模）
```

### 转化机制
```text
核心不等式：产出 ≤ min(采集, 运输带宽, 加工, 需求)

玩家不是在管理库存，而是管理"流速"。
库存 = 系统病态（说明某环节堵塞或过剩）。
理想状态 = 零库存、满流速。
```

转化升级链：手搓 → 初级自动化（铁铜）→ 中级自动化（石油化工）→ 高级自动化（模块/信标/无人机）→ 蓝图复用（元级转化）

### 节奏波形
```text
流动式：
  瓶颈浮现（30s-2min）→ 诊断 → 修复 → 流速恢复 → 下个瓶颈浮现
  无固定周期，瓶颈自然推动游戏节奏
```

### 可迁移公式
```text
文明瓶颈链：
  神殿信仰产出 = min(
    信众规模,
    祭司团执行力,
    异端干扰程度,
    治理注意力投入
  )
  最弱环节卡全局 → 玩家诊断 → 投注意力疏通

关键：不要让玩家管理资源数值，让玩家看到"流速"。
  神殿→信众→教团的信仰流量可视化
  农田→城市→仓库的粮食流量可视化
```

## 2. Oxygen Not Included

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 氧气 | 呼吸必需 | 基础生存 |
| 食物 | 卡路里 | 能量供给 |
| 水/污水 | 液体循环 | 多用途流体 |
| 电力 | 能源 | 产能乘数 |
| 氢气/天然气/CO₂/氯气 | 气体 | 副产物/可回收 |
| 温度 | 全局热力学 | 隐藏的终极约束 |
| 病菌 | 生物危害 | 扩散风险 |
| 压力/士气 | 复制人心理 | 行为控制 |
| 建筑材料/精炼金属/塑料 | 物质资源 | 基建+升级 |

### 收集公式
```text
氧气：电解水 → 2H₂ + O₂（产氧副产氢，氢可发电）
食物：种植（消耗水/泥土/光照/温度窗口）
水：间歇泉（天然但有限速率）、净水器（污水回收）
电力：跑步机（人力）→ 煤炭 → 氢气 → 天然气 → 太阳能 → 蒸汽涡轮

核心：收集 = 建立物质/能量循环。每次循环有副产物，副产物需要再处理。
```

### 消耗公式
```text
多维度并行消耗：
  氧气 = 复制人数 × 100g/s
  食物 = 复制人数 × 1000kcal/周期
  水 = 电解 + 种植 + 研究 + 卫生
  电力 = 所有机器的瞬时功耗之和

消耗的复合性：
  你生产氧气 → 消耗水 → 水不够需要污水回收 → 回收需要电力 → 电力不够需要新电厂 → 新电厂产生热量 → 热量需要冷却 → 冷却需要更多电力...

每解决一个问题 = 引入 2-3 个新问题。
```

### 转化机制
```text
维恩图的能量/物质循环：
  H₂O → O₂ + H₂（电解）
  H₂ + O₂ → 电力 + H₂O（氢气发电机）
  净效果：电力（但损失热量和转换效率）

关键公式：
  系统效率 = 产出 / (投入 + 副产物处理成本)
  如果副产物处理成本 > 产出价值 → 这个方案不可持续
```

### 可迁移公式
```text
文明系统的副产物设计：
  工业化 → 污染 + 劳工不满（副产物）
  符文化 → 梦境噪声 + 祭司独裁（副产物）
  教团化 → 异端压力 + 世俗反抗（副产物）

  每个方案 = 解决 A → 产生 B + C（B和C需要再处理）
  玩家乐趣 = 设计能消化自身副产物的文明系统
```

## 3. RimWorld

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 食物（生食/熟食）| 生存基础 | 卡路里链 |
| 材料（木材/钢铁/零部件/布/皮）| 建造+装备 | 物资层 |
| 药品/闪光药 | 医疗 | 稀缺关键资源 |
| 电力 | 能源网络 | 产能乘数 |
| 殖民者心情/健康/关系 | 人格系统 | 行为驱动 |
| 研究点 | 科技解锁 | 长期进度 |

### 收集公式
```text
食物 = 种植作物 × 季节 × 种植技能 × 光照
材料 = 采矿/拆解/贸易
零部件 = 拆解机械/贸易（最稀缺资源，所有高级物品需要它）

关键：资源获取速率 = f(殖民者技能, 心理健康, 事件干扰)
      一个崩溃的殖民者会打断整条采集链。
```

### 消耗公式
```text
需求层级（马斯洛金字塔映射）：
  L1 生理：食物 + 睡眠 + 温度
  L2 安全：防御 + 医疗 + 避难所
  L3 社交：娱乐 + 聊天 + 仪式
  L4 精神：心情 + 艺术 + 信仰

每一层不满足 → 角色行为异常 → 连锁事故。
底层崩溃比上层更致命（饿比无聊危险）。
```

### 转化机制
```text
Storyteller（AI调度器）控制资源压力波形：
  Randy：完全随机（不可预测）
  Cassandra：递增压力（可预测但不可避）
  Phoebe：长放松+强化危机（松弛→紧张）

设计意图：不是均匀随机，而是有心理节奏。
```

### 可迁移公式
```text
文明主体需求层级：
  生存层：粮食/安全 → 节点正常运行
  权力层：自主权/话语权 → 阶层忠诚度
  意义层：信仰/文化/认同 → 文明凝聚力

  底层崩溃 = 文明解体
  顶层崩溃 = 文明失去方向和身份
```

## 4. Frostpunk

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 煤炭 | 热能 | 生存底线 |
| 食物（生食/口粮）| 卡路里 | 人口维持 |
| 木材/钢铁/蒸汽核心 | 建材+科技 | 发展物资 |
| 劳动力（工人/工程师/儿童）| 人口分配 | 执行能力 |
| 希望值 | 民众精神 | 道德健康度 |
| 不满值 | 民众愤怒 | 爆发风险条 |

### 收集公式
```text
煤炭 = 煤矿/炭窑 × 分配工人 × 温度修正（越冷效率越低）
食物 = 温室/猎人小屋 × 工人 × 温度修正
希望值 = 满足承诺 + 通过法案 + 不处决
不满值 = 延长工时 + 儿童劳动 + 死伤 + 不满足承诺

物质资源和道德资源使用不同的获得机制——但相互耦合。
```

### 消耗公式
```text
温度 = 倒计时审判的杠杆：
  -20°C：煤炭消耗 = 基准 × 1
  -40°C：煤炭消耗 = 基准 × 2
  -60°C：煤炭消耗 = 基准 × 3
  -80°C：煤炭消耗 = 基准 × 5
  -100°C+：煤炭消耗 = 基准 × 8

关键：消耗不是线性的！每降一档消耗暴增。
      玩家永远不知道"准备够了没"。
```

### 转化机制
```text
道德-物理兑换率：
  签署儿童劳动法 → 劳动力 +15% → 不满 +15%
  签署秩序法 → 新警察岗位 → 安全感上升 → 希望变化
  签署极端法 → 短期大幅增益 → 但文明走向独裁

核心：每次制度选择 = 物质资源与道德资源的兑换。
      这是一张不可逆的兑换表。
```

### 可迁移公式
```text
文明制度的道德-物理兑换：
  选择工业化 → 生产力 +50% → 劳工不满 +30% → 需要压制或安抚
  选择神权制 → 信仰统一 +40% → 科技发展 -20% → 异端概率上升
  每个制度 = 改变一种资源成本，引入一种新风险
```

## 5. Timberborn

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 水 | 生存+农业 | 底层瓶颈资源 |
| 食物（多种作物）| 卡路里 | 生存链 |
| 木材/板材/齿轮/金属 | 建材+科技 | 加工链 |
| 科学技术点 | 科技树 | 长期解锁 |
| 劳动力（海狸）| 人数 × 幸福度 | 执行能力 |

### 收集公式
```text
水 = 河流自然流量（旱季归零）× 水库储备
食物 = 农田 × 水 × 分配农夫
木材 = 伐木场 × 分配伐木工 × 森林密度
科技 = 发明家岗位 × 科技建筑

底层公式：
所有产出 = 基础值 × f(是否有水)
水 = 0 → 作物不生长 → 食物链断裂 → 海狸饥饿 → 劳动力清零
```

### 消耗公式
```text
旱季审判：
  水流归零 → 水库水位持续下降
  消耗 = 海狸数 × 饮水率 + 农田 × 灌溉率
  如果水库在旱季结束前见底 → 全灭

核心：只有一种资源是瓶颈（水），但这个瓶颈的影响是全局级的。
```

### 转化机制
```text
水利投资 → 储水能力 → 旱季生存率 → 扩张能力 → 更多水利投资

正反馈循环：越扩张 → 越需要水 → 越需要水坝 → 越需要扩张获取建材
负反馈压力：旱季越来越长 → 储水需求越来越大
```

### 可迁移公式
```text
文明底层瓶颈资源：
  设计 1-2 种"底层资源"——不是所有资源都平等。
  底层资源（如信仰合法性/粮食安全）一旦枯竭 → 所有下游系统连锁崩塌。
  玩家必须持续投资底层资源，不能只发展顶层。
```

### Dwarf Fortress 特别剖析

**资源公式：多层级模拟**
```text
层级1（物质）：食物/酒/建材/装备/工艺品
层级2（精神）：心情/需求/记忆/人格
层级3（关系）：友谊/仇恨/家庭/宠物
层级4（世界）：气候/地质/文明年龄/传说
```

**核心公式**：
```text
矮人行为 = f(当前物质状态, 近期记忆, 长期人格, 关系网络, 酒精水平)
产出质量 = f(矮人技能, 工具品质, 材料品质, 心情修正)
失败 = 系统中一个看似无关的小变量，通过因果链放大为文明级事故
```

关键洞察：资源管理的乐趣不是来自管理资源表，而是来自**追溯因果链**——"为什么铁产量暴跌？因为矿工和铁匠打了架，原因是矿工养的猫被铁匠的狗吃了。"
