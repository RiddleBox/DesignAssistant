# Batch 5：卡牌 / 骰子 / 构筑 Roguelite — 资源经济公式深度拆解

---

## 1. Slay the Spire

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 能量 | 每回合可用行动点 | 单回合行动权 |
| 手牌 | 当前回合可用组件 | 概率抽样 |
| 牌组 | 本局全部卡牌集合 | 可塑形概率池 |
| HP | 生存值 | 资源失误承受力 |
| 金币 | 商店货币 | 移除/购买选择权 |
| 药水 | 一次性强力效果 | 应急缓冲 |
| 遗物 | 永久被动增益 | 本局恒定乘数 |

### 收集公式
```text
战斗奖励：3选1（从职业池中随机3张）
商店购买：金币交换（价格递增）
事件获取：随机事件 → 特定卡/遗物/诅咒

核心：获取 = 概率塑形。
      每次获得新卡 → 改变牌组的概率分布
      多拿攻击牌 → 攻击密度上升 → 防御抽不到
```

### 消耗公式
```text
删牌（最关键操作）：
  商店删牌 = 金币（每次价格递增）
  事件删牌（稀有）
  转化（稀有事件，把废卡变有用卡）

核心公式：牌组强度 = 单卡平均价值 × 抽牌稳定性
         抽牌稳定性 = f(1/牌组大小, 检索能力)
         删牌 > 拿牌（精简提升期望值）
```

### 转化机制
```text
路线锁定（不可逆）：
  Boss遗物选择 → 永久改变规则（如每回合+1能量但不可看意图）
  每层选路线 → 精英怪（高风险高回报）vs 篝火（恢复升级）vs 商店（花钱优化）

关键公式：路线 = 风险暴露度选择
          精英怪路线 = 可能拿好遗物但可能死
          安全路线 = 存活概率高但构筑进度慢
```

### 节奏波形
```text
棘轮式：
  战斗（1-3min）→ 选奖励（不可逆锁定）→ 选路线（不可逆）→ 下一战
  局级（30-60min）：从弱小卡组到成型引擎
  每层Boss = 构筑审计
```

### 可迁移公式
```text
文明制度的"删牌"机制：
  不是所有制度都要保留——废除旧制度 = 提升制度组合效率
  选路线 = 风险暴露度选择（激进改革 vs 保守维持）
  时代Boss = 构筑审计（检测当前制度组合能否应对危机）
  删制度比加制度更重要
```

## 2. Balatro

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 手牌 | 当前回合抽取 | 概率抽样 |
| 弃牌次数 | 重抽机会 | 概率塑形次数 |
| 出牌次数 | 出牌机会 | 行动权 |
| 筹码 | 得分基数 | 基础产出 |
| 倍率 | 得分乘数 | 效率乘数 |
| 小丑牌 | 永久被动效果 | 本局引擎组件 |
| 塔罗牌/星球牌 | 一次性改造 | 塑形道具 |
| 金币 | 购买货币 | 投资能力 |

### 收集公式
```text
核心爆发公式：最终得分 = 筹码 × 倍率 × Π(小丑触发链)

筹码 = 牌面值 × 牌型修正
倍率 = 牌型基础 × 小丑叠加
小丑链 = Σ(触发顺序 × 效果叠加 × 重触发)

关键：收集的不是"更多资源"，而是"更强的小丑链组合"。
      资源收集 = 建立乘法引擎。
```

### 消耗公式
```text
弃牌 = 消耗 1 次重抽机会（极其稀缺）
出牌 = 消耗 1 次得分机会（用完回合结束）
金币消耗 = 买小丑/开卡包（投资）/ 重骰盲注（生存）

关键：出牌次数 > 手牌大小 → 你不可能出所有的牌
      必须弃掉不需要的，留下想要的。
```

### 转化机制
```text
小丑触发链 = 非线性的乘法共振：
  小丑A：每次出牌 +4 倍率
  小丑B：弃掉的牌也计分
  小丑C：最终手牌 +10 倍率
  小丑D：每张人头牌 ×1.5

触发顺序决定最终倍率。调整小丑排列顺序 = 重新设计引擎。
```

### 节奏波形
```text
棘轮式：
  小盲注（热身）→ 大盲注（正常压力）→ Boss盲注（构筑审计）→ 结算奖励 → 下一回合
  每层8个回合，每局8层
  错误的小丑选择无法撤回（棘轮锁定）
```

### 可迁移公式
```text
文明制度的"触发链"：
  工业化法令 + 铁路网络 + 矿工工会 → 生产触发链
  符文学院 + 月相日历 + 祭司法典 → 符文触发链
  制度排列顺序 = 触发顺序（先工业化再劳工法 vs 先劳工法再工业化 结果不同）

关键：文明强度 = 制度触发链的乘法组合，不是制度的加法和。
```

## 3. Slice & Dice

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 骰子 | 每回合随机产出 | 概率资源产出 |
| 骰面 | 每个角色的6种可能行为 | 角色身份映射 |
| 生命值 | 生存值 | 失误承受力 |
| 法力 | 特殊行动资源 | 战术灵活度 |

### 收集公式
```text
升级角色 = 替换骰面（不是提升数值！）
  骰面A（攻击3）→ 替换为骰面B（攻击2+护盾1）→ 角色行为改变

核心：收集 = 改变概率分布的形状，不是增加产出量。
      每个骰面 = 角色可能发生的行为之一。
      6个骰面求和 = 角色的行为签名。
```

### 消耗公式
```text
回合消耗 = 所有骰子用完后结束 → 新的随机产出
生命消耗 = 受到伤害（不可逆，除非有治疗骰面）
选择消耗 = 升级时选择新骰面（放弃其他方案 → 棘轮锁定）
```

### 可迁移公式
```text
文明节点的"骰面"设计：
  神殿的6个骰面：
    [祝福] [审判] [教化] [仪式] [沉默] [布道]
  升级神殿 = 替换一个骰面（如[沉默]→[奇迹]）
  神殿的行为签名 = 6个骰面的概率分布

关键：文明节点不是"等级高数值大"，而是"可执行的行为面改变"。
```

## 4. Dicey Dungeons

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 骰子（点数1-6）| 每回合随机产出 | 通用行动货币 |
| 技能槽位 | 可用的行动选项 | 消费场景 |
| EP（生命）| 生存值 | 失误承受力 |

### 收集公式
```text
每回合掷 N 个骰子（N = 角色等级）
每个骰子 = 一个行动货币
骰点 = 行动货币的面值

核心：同一个骰点在不同槽位的价值完全不同。
      6放在攻击技 = 高伤害
      6放在防御技 = 浪费（因为只需要1点防御）
      6放在状态技 = 可能需要偶数才能用
```

### 消耗公式
```text
骰子消耗 = 放入槽位消费
槽位容量 = 每个装备最多容纳的骰子数
多骰组合 = 某些装备需要多个骰子同时消费

关键：槽位冲突 = 同一骰子可以放入A也可以放入B但不能同时放入。
      玩家每分钟都在做"骰子分配优化"。
```

### 可迁移公式
```text
治理注意力的槽位分配：
  每回合有6点治理注意力（= 6个骰子）
  能投到的槽位 = 可用的文明节点干预手段
  同一个注意力投入不同节点价值不同：
    投给濒临崩溃的边疆 = 极高价值
    投给稳定运行的都城区 = 浪费
    投给新兴的符文学院 = 未来收益

玩家优化的是"注意力分配"，不是"注意力产出"。
```

## 5. Luck be a Landlord

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 符号 | 棋盘上的产出单位 | 可塑形的随机池 |
| 道具 | 永久物品 | 规则修改器 |
| 金币 | 目标分数 | 胜利进度 |

### 收集公式
```text
每回合从池中抽取随机符号填充棋盘
每次选择新符号 → 加入池子 → 改变后续概率
删除符号 = 移除低效符号 → 净化池子

核心公式：池子质量 = 好符号数 / 总符号数
          玩家的操作 = 提高这个比例
```

### 转化机制
```text
符号生态：
  阳光 → 给相邻植物额外产出
  动物 → 消耗植物但产出更多金币
  黄金 → 基础高产但无协同
  特殊符号 → 改变相邻符号的规则

核心：不是单符号最优，是符号生态的整体效率。
      "肥瘦搭配"——你需要消费型符号和产出型符号在一个池子里。
```

### 可迁移公式
```text
文明事件池的"生态搭配"：
  发展型事件（增加产出）权重 × 限制型事件（制造瓶颈）权重 × 危机型事件（审判）
  三者比例不能失衡——全是发展型=无聊，全是危机型=挫败
  玩家通过制度选择改变池子中三者的比例

"每个选择都在污染或净化未来事件池"
```

| Cobalt Core | 能量/护盾/闪避/导弹 | 意图预告+位置对齐 | 倒计时 | 文明危机预告+防守对齐窗口 |

### Monster Train 特别剖析
```text
多层压力穿透公式：
  顶层（火车楼层）→ 敌人从顶层开始进攻
  中层 → 顶层被破后敌人进入中层
  底层 → 中层被破后进入底层 → 失败

文明映射：
  文明多层防御：
    L1军事防线（物理安全）
    L2制度防线（政治稳定）
    L3信仰防线（精神凝聚力）
    L4心灵底线（文明存续意志）
  敌人不是外敌，是异端/污染/阶层分裂/外部文明压力
  每个危机可以穿透 0-4 层
```

### Inscryption 特别剖析
```text
规则破坏公式：
  通常：骨牌=消耗死亡单位获得，血牌=献祭场上生物
  作弊：某些卡牌让你无视资源需求直接出牌
  元叙事：规则本身是被一个"角色"控制的，你可以和这个角色谈判

文明映射：
  不同文明路线改变底层规则：
    工业路线：资源=矿物×劳动力（线性转化）
    符文路线：破坏规则 → 资源=仪式洞察（跳过线性链）
    心灵路线：改变规则定义 → 资源=共识强度（没有实体对应物）
```

### Wildfrost 特别剖析
```text
倒计时+站位公式：
  每个敌方单位有倒计时条 → 到0时攻击
  我方单位也有倒计时 → 到0时触发技能
  站位决定谁先被攻击

核心乐趣：你看到敌人3回合后攻击，这3回合内你可以：
  移动到安全位置
  使用护盾技能
  在敌人攻击前先发动攻击
  用道具刷新倒计时

文明映射：
  时代危机的"可干预倒计时"：
  预告：5回合后符文潮汐 → 玩家看到倒计时条
  干预：分配治理注意力延缓/减轻/转化危机
  反馈：干预后的结果 vs 不干预的结果（可见对比）
```

## 批次5 核心公式归纳

```text
这 11 款游戏的共同主题：资源 = 可塑形概率。

1. Slay the Spire: 牌组 = 概率分布，删牌 > 拿牌
2. Balatro: 触发链 = 乘法引擎，排列顺序 = 设计逻辑
3. Slice & Dice: 骰面 = 角色身份，升级 = 换行为不是加数值
4. Dicey Dungeons: 骰子×槽位 = 资源价值由消费场景决定
5. Luck be a Landlord: 符号池 = 可塑形生态系统
6. Wildfrost: 倒计时 = 可干预的延迟审判
7. Monster Train: 多层战场 = 压力从上到下穿透
8. Inscryption: 规则破坏 = 文明路线的语法变更
9. Cobalt Core: 意图预告 = 危机可预判可应对
10. Shogun Showdown: 极简棋盘 = 少数节点+因果透明

对文明 Roguelite 的关键迁移：
- 文明制度 = 可塑形的事件池分布
- 制度组合 = 触发链乘法引擎（非加法）
- 路线选择 = 不可逆的棘轮锁定
- 时代危机 = 可预判可干预的倒计时审判
```
