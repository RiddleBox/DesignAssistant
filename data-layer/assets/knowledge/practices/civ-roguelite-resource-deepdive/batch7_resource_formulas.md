## 1. King of Dragon Pass / Six Ages

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 牛/货物/魔法/人口/土地 | 基础5类 | 部族资产 |
| 神灵态度 | 对每个神的关系值 | 超自然汇率 |
| 邻族关系 | 对每个邻族的外交值 | 安全/冲突汇率 |
| 部族声誉 | 全局声望 | 外交乘数 |
| 派系（顾问）意见 | 内部政治张力 | 决策约束 |

### 收集公式
```text
基础资源获取 = 社会关系绑定：
  劫掠邻族 → 获得牛/货物 + 关系恶化 + 可能招来报复
  贸易 → 获得资源 + 建立外交 + 开放外交新选项
  祭祀 → 改变神灵态度（消耗牛/货物）+ 影响年景
  冒险 → 高风险高回报的事件链

核心：没有"中立获取"。每种获取都绑定至少一种社会关系变化。
```

### 消耗公式
```text
每季行动槽位（通常4个）= 固定瓶颈：
  选了祭祀 → 不能选外交
  选了探索 → 不能选建设
  选了劫掠 → 不能选贸易

行动槽位 = 治理注意力的物理体现。
资源多不能增加行动数。
```

### 转化机制
```text
世界观解释 = 资源转化率：
  同样的事件：河流决堤
    追随Orlanth（风暴神）的顾问：修建堤坝+献祭
    追随Ernalda（大地神）的顾问：迁移+祭祀（用不同仪式）
    理性顾问：修堤坝+增加劳力分配（不涉及神灵）

选择不是数学最优，而是"你相信这个世界怎么运作"。
世界观 × 选择 → 不同的资源消耗组合 → 不同的文明身份。
```

### 可迁移公式
```text
文明事件 = 解释框架的竞争：
  同一危机 → 4种文明视角 → 4种解法 → 4种身份塑造
  工业视角：修堤坝（耗费劳动力+木材+注意力）
  符文视角：仪式安抚河灵（耗费符文矿+祭司）
  教团视角：神罚→祭祀赎罪（耗费牛+信众虔诚）
  心灵视角：集体意识安抚河魂（耗费共识+时间）
```

## 2. Suzerain

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 预算 | 政府资金 | 财政能力 |
| 政治资本 | 立法+任命+外交 | 政治行动权 |
| 个人财富 | 非公资金 | 灰色操作空间 |
| 民众支持度 | 舆论风向 | 合法性基线 |
| 国际关系 | 大国博弈位置 | 外交空间 |
| 承诺债务 | 已做出的承诺列表 | 未来必然支出 |

### 收集公式
```text
预算 = 税收 − 支出 − 腐败
政治资本 = 议员支持 − 反对 − 丑闻
承诺债务 = Σ(竞选承诺 + 外交承诺 + 派系承诺)

核心：每个承诺 = 一张未支付的支票。
      承诺时获得支持（收入），兑现时消耗预算/资本（支出）。
```

### 消耗公式
```text
承诺债务 = 核心消耗公式：
  对工人承诺福利 + 对资本家承诺减税 = 不可能同时兑现
  对邻国承诺开放贸易 + 对军阀承诺国防扩张 = 预算超支

债务爆炸 = 承诺太多 → 兑现时预算不足 → 必须违约 → 失去支持 → 权力崩塌
```

### 转化机制
```text
政治资本 ↔ 预算 ↔ 支持度的三角兑换：
  花预算（福利）→ 换民众支持
  花政治资本（立法）→ 换预算增长（改革经济）
  花支持度（做出不受欢迎的决策）→ 换政治资本（强行通过法案）

核心：三角不能全满。每项转化都损耗一部分。
```

### 可迁移公式
```text
文明制度的"承诺债务"系统：
  选灌溉制度 → 承诺维护水利 → 每时代消耗治理注意力
  选神权制度 → 承诺维护祭司特权 → 每时代消耗稳定性
  选商业制度 → 承诺保护商路 → 每时代消耗军事资源

  承诺过多 → 资源枯竭 → 被迫违约 → 制度解体
  制度选择 = 延期支付的资源成本
```

## 3. Frostpunk 2

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 热量/物资/劳动力/核心 | 物理资源 | 生存基础 |
| 派系支持 | 各派系的关系值 | 政治资源 |
| 立法权 | 通过法案的能力 | 路线定义权 |
| 城市未来"解释权"| 派系争夺的对象 | 元资源 |

### 收集公式
```text
传统资源收集（同Frostpunk 1）
+ 派系支持 = f(政策符合派系诉求, 过往承诺兑现率, 当前危机严重度)
```

### 消耗公式
```text
接受派系支持 = 放弃路线自主权：
  派系A支持你 → 法案必须偏向A → 派系B不满
  你今天为了过关接受支持 → 明天你的可选政策空间被缩小

核心：支持不是免费的。代价是未来的路线自主权。
```

### 转化机制
```text
派系不是加减好感度条——他们争夺"城市未来应该是什么样子"。

  冰血派：城市应该继续以牺牲个体为代价求生存
  技术派：城市应该靠科技和理性走出寒冬
  信仰派：城市应该靠信仰和传统凝聚

每个派系支持你 = 把他们的愿景写入法律
一旦写入 → 你被法律绑定 → 改变路线需要革命级成本
```

### 可迁移公式
```text
文明内部派系 = 路线定义权竞争者：
  每个阶层/派系不只是"好高度条"
  他们争夺"文明未来应该走什么路线"
  接受一个阶层的支持 = 部分放弃文明路线的定义权
  改变路线 = 背叛旧支持者 + 引发内乱
  
派系系统 = 关系 × 路线自主权的转化公式
```

### Citizen Sleeper 特别剖析
```text
骰子+多时钟公式：
  每天掷 N 个骰子（1-6）
  每个骰子可分配到不同的"时钟"（任务/关系/生存）
  骰点越高 → 成功率越高/Loot更好
  
  多个时钟并行推进：
    生存时钟（吃饭/治病）→ 最紧迫
    任务时钟（赚钱/完成任务）→ 中期
    关系时钟（建立信任/友谊）→ 长期

核心：骰子是有限的，时钟是并行的，你必须选择"今天优先推进哪个"。
      放弃某个时钟 → 它可能恶化（关系疏远/任务过期/健康恶化）
```

### Wildermyth 特别剖析
```text
事件留痕公式：
  英雄遭遇事件 → 做出选择 → 获得永久改变：
    失去一只眼 → 外观改变 + 能力修整
    被魔法感染 → 获得新能力 + 逐渐变异
    与同伴结下特殊羁绊 → 协作加成 + 情绪依赖

核心：事件不是改变数值，是改变"这个角色是谁"。
      留痕 = 永久的、可见的、影响后续玩法的改变。
      10个事件后，角色已经不是一开始那个人了。
```

### Sir Brante 特别剖析
```text
路线门槛公式：
  早期选择（5-7岁）→ 决定初始社会地位
  青少年选择 → 决定教育/技能/信仰方向
  成年选择 → 受前两阶段约束 → 可走路线大幅收窄
  关键节点 → 某些路线门槛不够 → 路线永远关闭

核心：人生不能回头。早期选择 = 路线门槛。
      不是"有A或B两条可选"，而是"你不够格走A，只能走B或C"。
```

## Batch 7 核心公式归纳

```text
这 10 款游戏的共同主题：资源 = 关系 + 承诺 + 解释权。

1. KoDP/Six Ages: 行动槽位=治理瓶颈，世界观=资源转化率
2. Suzerain: 承诺债务=延期支付成本→违约=系统崩塌
3. Frostpunk 2: 派系支持代价=路线自主权的让渡
4. Sir Brante: 早期选择=路线门槛→锁死后期
5. Yes Your Grace: 回访=过去判断被验证/回击
6. The Pale Beyond: 信任=f(兑现一致性)→崩溃曲线
7. Roadwarden: 有限时间×关系网×信息不对称
8. Citizen Sleeper: 骰子分配=多时钟并行管理
9. Wildermyth: 事件留痕=永久身份改变
10. Six Ages 2: 神话学习=世界观渐近掌握

对文明 Roguelite 的关键迁移：
- 事件不是"读题奖励"——是关系+承诺+身份的综合改变器
- 承诺债务系统：每个制度选择产生未来必须支付的资源
- 解释权竞争：不同派系/阶层争夺"文明应该怎么走"的定义权
- 永久留痕：事件改变文明身份，而不只是改变资源数值
- 回访机制：过去的选择在后续时代回来追讨
```
