# Batch 3：RTS / 少资源高压决策 — 资源经济公式深度拆解

---

## 1. StarCraft II

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 晶体矿 | 基础矿物 | 通用建造/生产资源 |
| 高能瓦斯 | 高级气体 | 科技/高阶单位门槛 |
| 人口补给 | 单位上限 | 扩张节奏约束 |
| 时间（timing） | 科技/生产速度 | 窗口期资源 |
| 信息（侦察） | 对手状态 | 不可见但最重要的资源 |

### 收集公式
```text
晶体矿 = 矿骡/农民数量 × 采矿速率
高能瓦斯 = 采气农民 × 采气速率
人口 = 补给站/王虫数量

核心公式：
收入速率 = f(农民数, 矿脉数)
最优农民数 = 矿脉数 × 2（晶体矿）/ 矿脉数 × 3（瓦斯）

超饱和惩罚：农民超过最优数 → 单农民效率下降但总收入微增
```

### 消耗公式
```text
生产消耗：单位/建筑的矿+气一次性消耗
维持消耗：人口上限（补人口站花钱）
机会成本：钱花在出兵上就不能花在开矿/科技上

Timing = 消耗效率的数学极值：
  特定时间点把钱全部转化为部队 → 达到最大战斗力 → 发起进攻窗口
```

### 转化机制
```text
钱的转化率取决于建筑数量：
  1个兵营每回合出1个枪兵
  10个兵营每回合出10个枪兵
  但10个兵营 = 1500矿（本可以出20个枪兵）

关键公式：
兵力增长速度 = min(收入, 生产建筑数 × 生产速率)
瓶颈 = 你的矿够但暴不动兵 → 需要更多生产建筑
```

### 节奏波形
```text
流动式：
  持续采矿 → 持续生产 → 侦察 → 调整 → 扩张 → 新矿点
  每5-10分钟一个攻防周期
  全局 15-30 分钟一局
```

### 可迁移公式
```text
少资源可行的前提：
  1. 产出速率不是自动的（需要分配人口/注意力）
  2. 消耗有窗口期（timing attack 类比文明危机的倒计时）
  3. 信息不对称制造决策压力

文明版两资源：
  治理注意力 = 晶体矿（通用行动权）
  稳定度 = 瓦斯（高级制度门槛）
  文明主体的"暴兵能力" = 事件处理速度 × 制度效率
```

## 2. Age of Empires

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 食物 | 村民生产+军队 | 人口扩张+兵种 |
| 木材 | 建筑+船只+农田 | 基建+海军 |
| 黄金 | 高阶单位+科技 | 晚期优势 |
| 石头 | 城堡+城墙+奇观 | 防御+标志 |

### 收集公式
```text
每种资源绑定一个战略方向：
  食物 → 爆村民（经济扩张）或爆骑兵（rush）
  木材 → 爆弓箭手或海军
  黄金 → 爆骑士/火炮（晚期决战）
  石头 → 爆城堡控制地图

采集 = 村民分配 × 采集点距离 × 采集效率
```

核心设计意图：**每种资源暗示一种路线**——多挖金 = 暗示走骑兵路线。

### 消耗公式
```text
时代升级 = 固定资源组合（如升封建 = 500食物）
   升级消耗 = 当前劳动力 × 升级时间（升级时村民不能干活）

战损 = 永久不可恢复的资源投入
   每死一个骑士 = 60食物+75金币永久消失
```

### 转化机制
```text
关键转化：村民 = 可转换资源获取器
  农民 → 猎人 = 食物速率提升
  农民 → 伐木工 = 木材速率提升
  转换成本 = 走路时间 + 采集建筑成本

经济 vs 军事的转化：
  村民 → 消耗食物（经济投资）
  士兵 → 消耗资源（军事投资）
  士兵可以杀敌但不能采集（不可逆）
```

### 节奏波形
```text
脉冲式（时代驱动）：
  黑暗时代（开局经济）→ 封建时代（初战）→ 城堡时代（核心战斗）→ 帝王时代（决战）
```

### 可迁移公式
```text
文明资源 = 路线暗示系统：
  不是"我有铁所以能造剑"
  而是"我开采的结果暗示我应该走工业路线"
  不同资源在不同时代/视角下价值不同
```

## 3. Warcraft III

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 金币 | 主资源 | 建造+训练+研究 |
| 木材 | 副资源 | 特定建筑+科技 |
| 食物 | 人口上限 | 军队规模约束 |
| 英雄经验 | 英雄等级 | 本局构筑进度 |
| 宝物 | 装备 | 可携带增益 |
| 野怪资源 | 野怪掉落 | 地图控制奖励 |

### 收集公式
```text
金币 = 农民 × 采金速率（矿有限，耗尽后换矿点）
木材 = 农民 × 伐木速率
英雄经验 = 击杀野怪/敌人 × 经验系数
宝物 = 击杀特定野怪（单次掉落，不可重复）

核心：野怪 = 不可再生资源 = 地图控制竞赛
```

### 消耗公式
```text
食物 = 军队规模上限：
  低级单位 2 食物，高级单位 3-5 食物
  维持费：食物超过低维护线 → 金币收入率下降
  高维持 = 鼓励玩家主动交战而非无限囤兵
```

### 转化机制
```text
英雄系统 = 资源转化器：
  高级英雄 = 战力乘法器（光环/技能）
  英雄死亡 = 失去战力乘法器 + 复活金币成本 + 等待时间
  英雄宝物 = 永久增益（不可掉落）

核心：英雄是"不可替代资产"——不像士兵可以再造。
```

### 可迁移公式
```text
文明"英雄"系统：
  文明代表性主体（君主/大祭司/首席科学家/心灵导师）
  文明事件提升其能力 → 能力改变全局资源乘数
  主体死亡 = 文明大震荡 → Orders骤减 + 继承危机
```

## 4. They Are Billions

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 金币 | 建造+军队 | 通用资源 |
| 木材/石材/铁矿/石油 | 建筑+科技 | 分层门槛 |
| 食物 | 人口维持 | 扩张约束 |
| 工人/能源 | 建筑运行 | 产能瓶颈 |
| 殖民者 | 人口=劳动力 | 规模基础 |

### 收集公式
```text
食物：猎人小屋/农场 × 地块
金币：房屋 × 居民 × 市场修正
木材/石材/铁矿：对应采集建筑 × 矿脉/森林
石油：油田平台（中后期）
```

### 消耗公式
```text
尸潮审判（周期消耗暴增）：
  每 N 天一波尸潮，强度递增
  审判消耗 = 防御建筑 + 兵力 + 城墙 + 维修
  一波失败 = 防线被突破 → 连锁崩塌 → 游戏结束

关键：审判消耗不是数值减法，是"防线的物理空间消耗"。
```

### 转化机制
```text
扩张 vs 防御的转化：
  每块新地 = 更多资源 → 但需要更长的防线
  扩张收容比 = 新产出 / (新防线长度 × 防线厚度)
  如果收容比 < 1 → 扩张是亏损的
```

### 节奏波形
```text
脉冲+倒计时：
  建设期（3-5天数）→ 尸潮预警 → 尸潮来临 → 战后修复 → 下一周期
  全程有下一波倒计时（可见压力）
```

### 可迁移公式
```text
文明危机 = 可见倒计时 + 物理/系统防线：
  提前告知"3回合后大旱"
  显示"信仰防线：祭司团正在瓦解"
  玩家必须决定：扩张（获取新资源）还是加固（保护现有资产）
```

## 5. Bad North

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 金币 | 升级/补充兵员 | 有限通用资源 |
| 单位 | 小队（不可再生）| 永久资产 |
| 岛屿 | 地图（用完消失）| 不可逆空间 |

### 收集公式
```text
金币 = 防守岛屿成功后的奖励
单位 = 开局给定 + 偶尔可招募（极稀有）
```

### 消耗公式
```text
每场战斗：
  单位伤亡 = 永久不可恢复
  金币消耗 = 升级/补充
  岛屿消耗 = 守过的岛不能重打

核心：每次损失是永久的——这创造极度紧张感。
```

### 可迁移公式
```text
文明永久损失机制：
  灭亡的阶层不能复活
  被摧毁的城市不能重建（只剩遗址）
  失去的信任不能恢复（只能建立新关系）
  每次损失让文明走向不同方向
```

## 6. Kingdom Two Crowns

### 资源类型（极简）
| 资源 | 定义 | 本质 |
|------|------|------|
| 金币 | 唯一通用资源 | 选择权本身 |

### 收集公式
```text
金币来源：打猎（弓箭手自动）、农场、商人税、宝箱
产金速率 = 农民数 × 农场产出 × 季节修正
```

### 消耗公式
```text
投币 = 通用消耗动作：
  投弓手招募牌 → 1金币 = 1弓手
  投城墙 → 1金币 = 一段墙
  投铁匠铺 → 升级工具
  投商船 → 离港赚钱

所有行动 = 投币。没有菜单、没有二级资源。
```

核心公式：**1 金币 = 1 次选择权。执行选择和选择什么分离。**

### 节奏波形
```text
脉冲式（日夜循环）：
  白天 = 建设+攒金（安全期）
  黄昏 = 补充防御（过渡期）
  夜晚 = 怪物来袭（审判期）
  冬天 = 所有产出减半（长周期压力）
```

### 可迁移公式
```text
极简资源 = 最优雅设计：
  治理注意力 = 全局唯一点击资源
  每次投注 → 文明节点变化 → 连锁反应 → 新危机浮现
  操作复杂度为 1，决策深度由系统反馈链提供
```

## 7. Tooth and Tail

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 食物 | 唯一资源 | 建造+单位+科技 |

### 收集公式
```text
唯一资源是食物 = 建磨坊 → 自动产生
没有农民：玩家用指挥官吃资源点 → 转换为食物产量
```

### 消耗公式
```text
食物 → 单位（一次性）
食物 → 建筑（一次性）
食物 → 科技（一次性）

全部是单资源系统——但深度来自兵种克制和地形。
```

### 可迁移公式
```text
单资源的深度不来自资源种类，来自：
  1. 消耗时机（现在花还是等更多）
  2. 转化方向（变成军事还是经济还是科技）
  3. 空间约束（兵营位置决定战斗力展开速度）
```

## 8-10. Creeper World / Dune: Spice Wars / Diplomacy is Not an Option

### Creeper World 速查
| 维度 | 值 |
|------|-----|
| 核心资源 | 能量（单资源，通过收集器从地形获取）|
| 独特机制 | 流体敌人持续扩散 → 能量分配=进攻+防御+扩张 |
| 核心公式 | 推进 = 能量产出 > 敌人扩散速率 |
| 迁移 | 文明"污染/异端"可视化为流体扩散压力 |

### Dune: Spice Wars 速查
| 维度 | 值 |
|------|-----|
| 核心资源 | 香料/索拉里/水/人力/影响力/霸权/情报 |
| 多维度 | 政治+经济+军事三线并行压力 |
| 特殊机制 | Landsraad（议会投票）+ CHOAM（市场操纵）|
| 迁移 | 多维度平行压力同时结算 → 注意力分散 |

### Diplomacy is Not an Option 速查
| 维度 | 值 |
|------|-----|
| 核心资源 | 金币/木材/石材/铁矿/食物/人口 |
| 节奏 | 纯脉冲（纯粹生存塔防+海量敌人）|
| 评级 | C 级（塔防维度过重，不适合文明演化迁移）|
