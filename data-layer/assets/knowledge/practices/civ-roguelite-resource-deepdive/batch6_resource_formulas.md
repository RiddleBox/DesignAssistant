# Batch 6：文明演化 / 神话 / 抽象世界模拟 — 资源经济公式深度拆解

---

## 1. Spore

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| DNA点数 | 各阶段通用货币 | 进化能量 |
| 部件（嘴/脚/武器/感官/社交）| 生物能力组件 | 能力定义器 |
| 食物 | 细胞/生物阶段 | 生存消费 |

### 收集公式
```text
DNA = 进食 × 阶段修正 + 完成目标奖励
部件 = DNA购买（解锁条件 = 找到/击败/社交获得）

核心：收集 = 解锁"形态的可能性"，不只是数值增长。
      新部件不只是+1攻击，而是改变了你可以做什么。
```

### 消耗公式
```text
部件选择 = 不可逆的身份锁定：
  选肉食嘴 → 不能吃植物 → 必须猎杀
  选社交部件 → 攻击力弱 → 只能通过外交

关键：每个部件选择缩小后续的可能性空间，同时定义本阶段的玩法语法。
```

### 转化机制
```text
阶段跃迁 = 资源体系大转向：
  细胞阶段：食物 → 成长
  生物阶段：DNA → 部件 → 身体形态
  部落阶段：食物 → 人口 → 工具
  文明阶段：金币 → 城市 → 军事/经济/宗教胜利
  太空阶段：香料 → 殖民 → 银河级互动

每个阶段玩法语法变一次。
```

### 可迁移公式
```text
文明时代跃迁 = 资源体系完全重构：
  采集时代：食物 = 人口 = 一切
  工业时代：煤炭 = 能源 = 扩张
  符文时代：符文矿 = 能量+解释权
  教团时代：信仰合法性 = 统治基础
  心灵时代：共识强度 = 存续根基

每跃迁一次，旧资源贬值，新资源成为瓶颈。
旧资源的掌控者（阶层）会反抗。
```

## 2. Terra Nil

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 树叶/能量（可回收）| 建设消耗 | 有限行动点数 |
| 生物量/湿度/温度 | 生态状态 | 环境健康度 |
| 地形（可用格子）| 操作空间 | 操作边界 |

### 收集公式
```text
建设消耗的"树叶"是有限的（起始固定数量）
生态状态 = f(建筑配置, 地形, 相邻效应)
不收集资源——修复环境，然后回收建筑，离开。
```

核心：**逆向公式**——传统城建是扩张，Terra Nil 是修复 → 回收 → 撤退。

### 消耗公式
```text
树叶有限（不可补充）→ 每一步都是不可回收的机会
建筑可以回收 → 回收后返还树叶 → 净消耗 = 最终留下的痕迹
目标：让环境健康度达标，同时最大化回收。
```

### 可迁移公式
```text
文明衰退 ≠ 失败：
  某些文明路线可以选择"净化"——消除工业痕迹、恢复自然环境
  衰退本身可以是一种文明路线选择
  不是所有文明都要走向"更大更强"
```

## 3. Dorfromantik

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 地块 | 六边形地形片 | 拼图组件 |
| 任务 | 完成需求=新地块 | 进度驱动 |
| 空间 | 地图面积 | 成形美感 |

### 收集公式
```text
新地块 = 完成匹配任务（如"连接50棵树"）
无资源产出、无采集——纯拼图匹配
```

### 消耗公式
```text
地块放置 = 不可逆（放了就不能移）
匹配 = 相邻地块种类相同 → 完成任务
放置错误 = 破坏整体成形美感 → 后期难以匹配
```

### 可迁移公式
```text
文明地图的渐进成形感：
  每个文明节点的放置是永久可见的
  整个地图逐渐成形为一种"文明风格"
  不是功能性扩张，而是视觉/文化成形的满足
```

## 4-12. 速查表

| 游戏 | 核心公式 | 节奏 | 可迁移点 |
|------|---------|------|---------|
| The Universim | 神力干预=变量投放→文明自行响应 | 呼吸 | 低成本干预+观察涌现 |

| Niche | 遗传性状→后代变异→跨代适配 | 棘轮 | 制度/文化的跨代后果 |

### Evolution 特别剖析
```text
性状=生态位公式：
  食性（肉食/植食/杂食）→ 决定可吃谁、被谁吃
  体型 → 决定战斗力+食物需求
  特殊性状（壳/毒/合作）→ 改变互动规则

核心：每种性状 = 一种声明——"我适合这种生态位"
      但环境变化时，最适应的可能不是最强的。
      长脖子在树木高大时是优势，树木消失后是累赘。
```

### Niche 特别剖析
```text
跨代后果公式：
  选什么样的一对繁殖 → 后续代遗传性状组合
  近亲繁殖 → 遗传病风险
  迁移到新岛屿 → 面临新环境 → 需要新性状

核心：当前选择 = 未来5-10代的约束
      你选的配偶决定了你的后代能否适应环境变化
```

### From Dust 特别剖析
```text
物质操控公式：
  玩家直接抓取物质（岩浆/水/沙/植物）→ 放置到地形上
  岩浆遇水 → 造陆
  水遇低洼 → 成湖
  植物遇水 → 繁殖

核心：不是通过菜单操作，是直接操控世界物理元素。
      结果是即时的、可见的、有因果链的。
```

## 批次6 核心公式归纳

```text
这 12 款游戏的共同主题：资源 = 形态变化 + 可见反馈 + 阶段跃迁。

1. Spore: 部件=能力定义器，阶段跃迁=资源体系重构
2. Terra Nil: 逆向公式——修复→回收→撤退
3. Dorfromantik: 地块匹配=渐进成形满足感
4. The Universim: 低成本干预→观察文明自演
5. WorldBox: 变量投放→世界涌现
6. Evolution: 性状=生态位声明
7. Niche: 跨代后果=当前选择约束未来
8. Sapiens: 解锁新生活方式=文明能力质变
9. From Dust: 物质操控=直接物理因果
10. Islanders: 建筑包随机=风格塑形
11. Reus: 多维度协同干预
12. Cell to Singularity: C级（仅演化树可视化参考）

对文明 Roguelite 的关键迁移：
- 文明跃迁 = 资源体系完全重构（Spore/Spore式阶段）
- 文明衰退 = 合法路线（Terra Nil式净化/退出）
- 渐进成形 = 地图/文化风格的可视化满足（Dorfromantik）
- 跨代后果 = 当前选择约束未来所有选择（Niche/Evolution）
```
