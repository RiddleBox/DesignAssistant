# Batch 2：文明身份与路线大转向 — 资源经济公式深度拆解

---

## 1. Civilization VI

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 科技值 | 科技树进度 | 解锁新能力 |
| 文化值 | 市政树进度 | 解锁政策 |
| 生产力 | 建造速度 | 时间兑换率 |
| 食物 | 人口增长 | 劳动力扩张 |
| 金币 | 购买+维护 | 灵活交换媒介 |
| 信仰 | 宗教单位+购买 | 宗教文明专用 |
| 战略资源 | 马/铁/硝石/石油/铝/铀 | 兵种+发电门槛 |
| 使者/伟人点 | 城邦/伟人进度 | 外交+特殊加成 |

### 收集公式
```text
产出 = 地块产出 × 人口分配 × 建筑修正 × 政策修正 × 宜居度修正
范例：科技 = Σ(学院区域+建筑) × 科技政策 × 宜居度
```

关键：收集 = 多层乘数叠乘。裸地块产出极少，但挂上人口+建筑+政策后放大 5-10 倍。

### 消耗公式
```text
建造：一次性生产力消耗（城市项目）
维护：建筑 + 金币/回合
军队：维护费 + 战略资源/回合
伟人：伟人点累积 → 兑换

加速机制（不可逆）：
- 砍树 = 一次性生产力（环境不可逆）
- 砍资源 = 移除地块产出（失去长期收益）
```

### 转化机制
核心转化链：**尤里卡系统**——完成特定行为 → 科技/市政进度加速 40%。

```text
沿海建城 → 航海科技尤里卡
击杀野蛮人 → 青铜器尤里卡
建采石场 → 砌石尤里卡

这是"行为→认知"的转化：文明做什么，就会更快学会什么。
```

### 节奏波形
```text
流动式+呼吸式：
  城市建设（5-15回合周期）
  科技/市政（错峰完成）
  时代切换（40-60回合）
  奇观竞赛（与AI竞争）
```

### 可迁移公式
```text
"尤里卡系统"可迁移为文明身份生成器：
  大量使用符文 → 自然解锁符文深化路线
  大量镇压异端 → 自然解锁宗教专制路线
  大量迁徙 → 自然解锁游牧文明路线
  文明的身份由"你一直在做什么"决定，不是由"你选了哪个科技"
```

## 2. Old World

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| Orders（命令点） | 全局行动资源 | 行动权瓶颈 |
| 食物/铁矿/石材/木材 | 传统4X资源 | 建造材料 |
| 金币 | 购买+外交 | 灵活资源 |
| 公民（人口） | 城市产出基数 | 生产力 |
| 训练（军事） | 军队经验 | 战力乘数 |
| 科技 | 随机抽卡式 | 概率塑形 |

### 收集公式
```text
Orders/回合 = 统治者能力 + 制度修正 + 顾问修正
城市产出 = 人口 × 建筑 × 总督能力
科技 = 每回合随机从当前时代池中抽取（非固定树）
```

### 消耗公式
```text
Orders是全局瓶颈：
  移动军队 = 1 Order
  建造建筑 = 1 Order
  发动外交 = 1 Order
  处理继承 = 1 Order
  镇压叛乱 = 1 Order

每回合 Orders 有限（通常 6-12），所有行动竞争同一个资源池。
```

### 转化机制
```text
统治者系统 = 资源乘数波动器：
  优秀统治者 → Orders+3，产出+20%
  年老统治者 → Orders-2，反应慢
  统治者死亡 → Orders骤降，家族内斗 → 继承危机消耗大量Orders
```

核心：文明效率 = f(统治者, 家族关系, 继承稳定性)。

### 节奏波形
```text
棘轮式+呼吸式：
  统治者生命周期（20-40回合）
  继承危机（突发消耗波）
  家族需求（周期性外交）
```

### 可迁移公式
```text
Orders系统 = 治理注意力模型：
  所有文明行动竞争一个稀缺资源池
  制度选择 = 改变Orders的获取速率和分配优先级
  文明衰退 → Orders骤减 → 被迫放弃某些节点
```

## 3. Stellaris

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 能量币 | 通用货币 | 维护+购买+贸易 |
| 矿物 | 建造+合金原料 | 工业基础 |
| 食物 | 人口维持 | 生存约束 |
| 消费品 | 人口幸福度 | 内政稳定 |
| 合金 | 军舰+巨型建筑 | 军事/工程能力 |
| 稀有战略资源 | 高级建筑+舰船组件 | 等级门槛 |
| 科研（物理/社会/工程） | 三维科技树 | 非对称发展 |
| 统合度 | 帝国规模惩罚抵抗 | 管理能力上限 |
| 影响力 | 扩张+外交+法令 | 政治行动权 |
| 人口 | 劳动力+产出基数 | 规模基础 |

### 收集公式
```text
基础资源 = 人口岗位产出 × 科技修正 × 建筑修正 × 种族特质 × 帝国修正
科研 = Σ(科研岗位 × 科研建筑 × 科学家 × 种族特质)
合金 = 矿物 → 铸造厂 × 冶金学家岗位

多层级转化链：
矿物 → 合金 → 军舰 → 舰队实力 → 领土控制 → 更多矿物
```

### 消耗公式
```text
持续维护：
  舰队维护（能量币+合金/月）
  建筑维护（能量币/月）
  人口消费品（消费品/月）
  领袖维护（能量币+统合度/月）

帝国规模惩罚：
  扩张越大 → 规模越超 → 科技/传统成本递增 → 扩张边际收益递减
```

### 转化机制
```text
飞升路线（不可逆大转向）：
  基因飞升 → 人口改造 → 种族特制化
  灵能飞升 → 进入虚境 → 灵能科技 + 灵能实体风险
  合成飞升 → 全种族机械化 → 新资源需求结构
  机械飞升 → 全种族数字化 → 不同的经济模型

每条路线彻底改变资源系统的运作方式。
```

### 节奏波形
```text
呼吸式+棘轮：
  探索期（快速扩张）→ 中期（外交+科技竞赛）→ 后期危机（银河级审判）
  飞升选择（不可逆，中期锁定）
  终局危机（150-200年后，审判所有文明）
```

### 可迁移公式
```text
飞升路线 = 资源系统的语法变更器：
  工业 → 符文飞升：能源从煤炭转为符文矿 → 新资源类型 + 新危机
  符文 → 教团飞升：合法性从技术转为神谕 → 旧工业阶层失势
  教团 → 心灵飞升：人口不再吃粮而是吃意义 → 物质生产系统崩溃
```

## 4. Humankind

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 食物/工业/金币/科技 | 传统4X产出 | 基础运营 |
| 影响力 | 文化扩张+市政 | 软实力资源 |
| 人口 | 城市劳动力 | 规模基础 |
| Fame（名望） | 唯一胜利条件 | 总进度条 |

### 收集公式
```text
每时代可选新文化（6选1，不可重复）：
  选择埃及 → 工业建筑 + 金字塔奇观
  选择罗马 → 军事扩张能力
  选择英国 → 殖民+海军

产出 = 当前文化能力 × 前时代遗留基础设施
```

核心：每时代文化切换 = 资源乘数重新分配。

### 消耗公式
```text
切换成本：选择文化 → 锁定该时代路线 → 旧时代文化能力永不可再选
Fame成本：做非文化偏向的事不产生 Fame → 纯粹的生存无意义
```

### 转化机制
```text
文化拼接 = 资源体系大转向：
  埃及（工业）→ 罗马（军事）→ 可汗（扩张）→ 日本（科技）
  每次切换改变哪些资源更重要、哪些可以放弃
```

### 可迁移公式
```text
时代转向 = 资源价值重定义：
  工业时代：矿、铁、煤 = 一级资源；符文 = 异端
  符文时代：符文矿 = 一级资源；煤炭 = 过时
  教团时代：信仰合法性 = 超级资源；技术 = 辅助
  每个转向让玩家重新评估一切已有资产
```

## 6. Endless Legend

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 食物/工业/金币/科技/尘埃 | 基础5维 | 运营基底 |
| 影响力 | 外交+帝国计划 | 政治资源 |
| 战略资源 | 玻璃钢/钛等 | 高级单位门槛 |
| 奢侈品 | 激活加成 | 文明激活器 |

### 收集公式
```text
强非对称派系：
  破碎领主：金币=食物（不用种田，用钱买人口）
  亡灵：不能用食物增长，必须从敌人获取人口
  菌菇族：只能建一个城市，其他靠前哨站
  龙族：只有一条龙和少量单位

每个派系彻底改变"资源从哪来、怎么用"。
```

### 消耗公式
```text
冬季系统（周期审判）：
  所有产出 -30%~-50%
  移动力衰减
  视野缩减
  每15-20回合一个冬季
```

### 可迁移公式
```text
文明的"强非对称"不要做成数值差异。
要做成：
  海洋文明：人口=贸易节点，土地=负担
  草原文明：迁徙=发展，定居=倒退
  不同文明看到同一块地价值完全不同
```

## 7. Age of Wonders 4

### 资源类型
| 维度 | 值 |
|------|-----|
| 核心资源 | 金币/法力/知识/食物/生产力/帝权 |
| 特殊机制 | 文明+魔典双路线构筑 |

### 收集/消耗公式
```text
帝权 = 主线进度（完成目标获取）
法力 = 魔典需求 + 战斗消耗（持续压力）
知识 = 解锁新魔典（魔典树，非完整科技树）

双路线特点：
  文明建设线 → 城市产出 + 种族转化
  魔典研究线 → 法术解锁 + 单位变异
  两线独立但不冲突 → 玩家可以同时推进
```

### 可迁移公式
```text
文明+信仰/符文双路线并行：
  文明线：物质建设、军事、外交
  超自然线：符文掌握、心灵力量、仪式能力
  两线产生交叉效果：符文技术+军事工业 = 符文坦克
```
