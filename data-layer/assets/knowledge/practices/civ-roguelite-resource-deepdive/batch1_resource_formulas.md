# Batch 1：非传统多资源采集短循环 — 资源经济公式深度拆解

---

## 1. Stacklands

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 卡牌（实体物品） | 任何可拖拽的对象（村民/浆果/木材/金币/工具） | 既是资源也是操作单位 |
| 时间（计时槽） | 卡牌放入槽位后倒计时 | 唯一转换成本 |
| 金币 | 卡包货币 | 元级资源投注 |

### 收集公式
```text
采集：村民卡 → 拖入浆果丛卡 → 等待计时 → 产出浆果卡
购买：金币 → 购买卡包 → 随机卡牌
战斗：村民+武器 → 拖入怪物卡 → 等待 → 产出战利品
繁殖：村民+村民+房屋 → 等待 → 婴儿卡 → 成长为村民
```

核心机制：收集 = 卡牌组合 × 时间投资。不存在"每秒产出 X"。

### 消耗公式
```text
食物消耗：村民定期消耗食物卡（无食物 → 死亡）
工具耐久：每次使用后工具降级/消失
空间消耗：卡牌越多，桌面管理成本越高（非数值压力）
```

关键：消耗不是数值减法，是卡牌消失——玩家能看到"村民没了食物"的具体画面。

### 转化机制
```text
合成链：原木 + 石头 + 村民 → 篝火 → 烤浆果
进阶链：篝火 + 铁矿石 → 熔炉 → 铁锭 → 铁剑
空间链：资源多 → 需要仓库/储存箱 → 空间管理 = 瓶颈
```

瓶颈特征：旧卡不消失，新卡没地方放 → 自然形成整理压力。

### 节奏波形
```text
脉冲式：
  采集期（攒卡）→ 合成期（组合爆发）→ 整理期（清理冗余）→ 下一轮
  周期：2-4 分钟一个循环
```

### 可迁移公式
```text
文明资源不一定是数值条。
把"文明主体"做成可组合卡牌：
  - 工坊卡 + 祭司卡 + 符文矿卡 = 符文教团卡
  - 合成后旧卡消耗/转化，新卡携带两者的能力+矛盾
```

## 2. Slipways

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 星球产出/需求 | 每个星球生产一种、需要一到两种 | 供需网络节点 |
| 科技 | 改变网络连接效率或解锁新连接类型 | 规则修改器 |
| 空间（连接数） | 每颗星球有连接上限 | 瓶颈资源 |

### 收集公式
```text
产出 = 星球固有产出 × 科技修正 × 连接饱和度
不存在"采集"动作——建连接即产出
```

### 消耗公式
```text
需求满足 = Σ(上游星球供给) ≥ 需求值
未满足需求 → 星球不升级 → 网络卡死
```

### 转化机制
```text
连接 = 转化器：
  A产矿物 + B需矿物 → 建立连接 → A产出流向B需求 → 两星球同时受益
  科技升级 → 连接效率提升 → 同一网络产出增加
```

核心：转化是拓扑级的，不是数值级的。

### 节奏波形
```text
流动式：
  评估网络 → 建关键连接 → 一轮升级爆发 → 新缺口浮现 → 再评估
  每个决策有分钟级后果（连接不可撤回）
```

### 可迁移公式
```text
文明节点网络 = 供需拓扑：
  工坊产出"技术产品"，需求"原料+劳动力"
  神殿产出"信仰合法性"，需求"信众+仪式资源"
  玩家建的不是道路，是需求-供给匹配关系
每次连接改变多层节点的产出乘数
```

## 3. Thronefall

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 金币 | 白天建设消耗、夜晚战斗奖励 | 唯一通用资源 |
| 建筑槽 | 每类建筑有数量上限 | 空间选择权 |
| 兵力 | 自动战斗单位，需要建筑支持 | 安全兑换率 |

### 收集公式
```text
白天收入 = 经济建筑产出 × 存活率
夜晚收入 = 击杀敌人掉落 × 存活建筑奖励
核心：收入 = 前一晚防御效率的延迟结算
```

### 消耗公式
```text
建筑成本 = 固定金币数（不递增）
夜间消耗 = 兵力伤亡 × 建筑损毁
机会成本：选经济建筑 = 放弃防御建筑
```

### 转化机制
```text
金币 → 建筑 → 兵力/收入/防御
夜间：兵力 × 防御建筑 = 存活率
存活率 → 白天收入 → 再投资循环
```

关键转化率：**1 金币投经济 vs 投防御**的选择决定了下一轮的生存概率。

### 节奏波形
```text
脉冲式：
  白天建设（30-60s）→ 夜晚战斗（60-90s）→ 结算奖励 → 下一白天
  完整循环 = 2-3 分钟
```

### 可迁移公式
```text
文明时代的"日/夜"结构：
  建设期：分配治理注意力到各节点
  审判期：时代危机同时检验所有分配
  结算：幸存节点 = 下一时代资产 + 新问题
```

## 4. Reigns

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 教会值 | 0-100 | 宗教势力容受度 |
| 人民值 | 0-100 | 民众支持度 |
| 军队值 | 0-100 | 军事控制力 |
| 财政值 | 0-100 | 经济健康度 |

### 收集公式
```text
不存在收集——每条只有增减。
每次二选一 = 四个条中 2-3 条同时变化 ±5~20。
```

### 消耗公式
```text
任何条归零或爆满 → 统治者死亡 → 王朝结束
核心：不是"用完"而是"失衡"导致失败
```

### 转化机制
```text
选择A（同意增税）：
  财政 +15 | 人民 -10 | 可能触发军队不满事件

关键特性：
- 没有资源间转化
- 每个选择 = 零和/非零和变更
- 资源条互相独立但通过事件联动
```

### 节奏波形
```text
脉冲式：
  读卡（3-5s）→ 判断（1-2s）→ 看到条变化 → 下一张卡
  分钟级：关注"哪条快爆了"
  局级：一个王朝存活时间 = 资源管理能力
```

### 可迁移公式
```text
文明状态维度简化：
  稳定度 | 信仰凝聚力 | 技术扩散度 | 阶层满意度
  每条 0-100，不收集只增减
  事件选择同时影响多条 → 平衡 = 存活
```

## 5. Cultist Simulator

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 卡牌 | 金钱/理性/激情/健康/秘传/追随者/影响/工具 | 一切皆卡 |
| 动词槽 | 工作/研究/探索/谈话/入梦/仪式 | 卡牌的消耗器 |
| 时间（计时） | 每个槽位独立倒计时 | 异步时钟 |

### 收集公式
```text
金钱：健康卡 → 工作槽 → 等待计时 → 产出金钱卡（可能附带伤病）
秘传：理性卡 + 文献卡 → 研究槽 → 秘传卡
追随者：秘传卡 + 谈话槽 + 熟人卡 → 信徒卡
影响：入梦槽 + 激情/理性 → 随机影响卡
```

核心：收集 = 卡牌 × 槽位 × 时间 × 风险（受伤/被抓/发疯）。

### 消耗公式
```text
恐惧：积累到 3 张 → 绝望 → 游戏结束
证据：积累到 3 张 → 被抓捕
伤病：占用健康槽 → 限制行动
时间消耗：所有槽位并行计时，玩家必须多线管理
```

### 转化机制
```text
低阶 → 高阶链：
  理性 → 博闻秘传 → 高阶秘传 → 仪式材料
  熟人 → 信徒 → 门徒 → 具名者
  每级转化 = 时间 + 风险 + 低阶卡消耗
```

核心特性：转化不是线性的——仪式可能失败、秘传可能引来猎人、高阶追随者可能叛离。

### 节奏波形
```text
呼吸式：
  多个槽位独立计时（15s/30s/60s/90s）
  玩家在多个时钟间跳转分配注意力
  没有统一回合——节奏完全由玩家管理
```

### 可迁移公式
```text
文明事件系统 = 多时钟并行：
  神殿仪式倒计时 | 饥荒预警倒计时 | 技术突破倒计时 | 边疆战事倒计时
  玩家分配治理注意力到不同时钟
  每个时钟独立推进 → 文明状态自然涌现
```

## 6. Six Ages / King of Dragon Pass

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 牛 | 财富/食物/祭品 | 通用价值载体 |
| 货物 | 贸易品 | 外交资源 |
| 魔法 | 仪式消耗 | 超自然干预能力 |
| 人口 | 战士/农民/工匠 | 劳动力+军事力 |
| 土地 | 神殿/农田/牧场 | 固定产能基础 |

### 收集公式
```text
牛：自然繁殖 + 劫掠 + 贸易
魔法：祭祀（消耗牛）+ 探索圣地
人口：自然增长 + 收容难民 + 联姻
货物：生产（消耗人口）+ 贸易收入
```

核心：每种资源获取都绑定至少一种社会关系（劫掠=得罪邻族 / 贸易=建立外交 / 收容=文化同化问题）。

### 消耗公式
```text
仪式消耗：牛 + 货物 + 魔法 + 人口（牺牲）→ 神灵态度变化
战争消耗：人口减少 + 牛群损失 + 邻族关系恶化
外交消耗：货物送出 + 承诺债务
季节消耗：每季粮食（牛）+ 神殿维护（货物）
```

### 转化机制
```text
牛 → 祭祀 → 魔法 → 仪式 → 丰收/胜利/治疗
人口 → 训练 → 战士 → 劫掠 → 牛群扩大
外交 → 联姻 → 部族联盟 → 军事支持 → 领土扩大

关键：每条转化链都绑定"世界观解释"——
你祭祀河神是因为神话逻辑，不是因为数值最优。
```

### 节奏波形
```text
呼吸式：
  季节为主线（春耕/夏伐/秋收/冬祭）
  事件随机插入（劫掠/外交/仪式/冒险）
  年际周期（年度结算 → 长期规划）
```

### 可迁移公式
```text
文明资源必须绑定"世界观解释框架"：
  同一资源在不同文明视角下价值不同
  工业视角：符文矿 = 能源
  祭司视角：符文矿 = 亵渎
  心灵视角：符文矿 = 集体潜意识的物化
```

## 7. Against the Storm

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 食物（复合） | 多种原料各满足不同种族 | 多需求并行 |
| 建筑材料 | 木板/砖块/织物 | 基建扩张 |
| 加工品 | 面粉/容器/奢侈品 | 需求满足门槛 |
| 女王急躁度 | 0-14 | 时间压力条 |
| 声望 | 胜利进度 | 目标进度 |
| 蓝图（随机） | 建筑解锁选项 | 工具箱约束 |

### 收集公式
```text
基础采集：营地 → 林地节点 → 固定速率产出
加工：原料 → 加工建筑 → 加工品（需蓝图解锁 + 劳动力）
贸易：加工品 → 商人 → 其他稀缺品
事件：开林地 → 随机资源+随机惩罚

核心：产出 = 蓝图随机性 × 劳动力分配 × 林地资源分布
```

### 消耗公式
```text
种族需求：每族有食物/服务/温暖等多个需求维度
  海狸：要木材加工+工程+温暖
  蜥蜴：要肉食+温暖+奢侈品
  人类：要面包+宗教+教育
女王急躁度：需求未满足 → 急躁上升 → 到 14 游戏结束

复合消耗：同时维持 3-4 条生产链 + 2-3 个种族需求 + 森林危险事件
```

### 转化机制
```text
劳动力 → 建筑 → 加工品 → 满足需求 → 声望 → 新蓝图
                    ↑
            林地资源（随机分布）
            危险事件（风险/回报）

核心转化瓶颈：蓝图随机 → 你可能没有加工某种食物的建筑
```

### 节奏波形
```text
棘轮式+倒计时：
  选蓝图（不可撤回）→ 建生产链 → 满足需求 → 声望提升 → 新蓝图 → 风暴季审判
  每局 30-60 分钟
  每次蓝图选择锁定后续可能性
```

### 可迁移公式
```text
文明时代 = 一局 Against the Storm：
  时代工具箱随机（初始可用制度/技术不同）
  多文明主体各有需求（不可能全满足）
  时代结束 = 审判结算 → 文明基因改变 → 下一时代新工具箱
```

## 8. dotAGE

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 人口（老/中/青） | 按年龄分层 | 延迟性劳动力池 |
| 食物 | 生存必需 | 周期性压力 |
| 材料 | 建筑/工具 | 基建消耗 |
| 知识 | 科技解锁 | 长期投资 |
| 预言 | 灾难预告信息 | 信息=资源 |

### 收集公式
```text
食物：农田 × 分配农民 × 季节修正
材料：采集 × 分配工人
知识：学院 × 分配学者
人口增长：青年结婚 → 婴儿 → 多年后成年
```

### 消耗公式
```text
老龄化消耗：老年人消耗食物但不产出
灾难消耗：预言预告的灾害来临时额外消耗
时间成本：人口从出生到工作有多年延迟
```

### 转化机制
```text
青年 → 分配职业 → 农民/工人/学者/士兵
  分配是不可撤回的（训练时间成本极高）
  人口年龄结构决定长期产出趋势
```

### 节奏波形
```text
倒计时+脉冲：
  预言预告（3-7回合）→ 准备期 → 灾害结算 → 恢复期 → 新预言
  代际周期（15-30回合）：人口结构的缓慢转变
```

### 可迁移公式
```text
文明人口节奏：
  制度选择 → 影响人口结构（多年轻人 vs 老龄化）
  人口结构的后果是延迟的——当前选择在 5-10 回合后才显现
  老年化文明：稳定但不扩张
  年轻化文明：有活力但不安定
```

## 9. Northgard

### 资源类型
| 资源 | 定义 | 本质 |
|------|------|------|
| 食物 | 生存+人口增长 | 核心约束 |
| 木材 | 建筑+维护 | 扩张成本 |
| 克朗 | 贸易+佣兵 | 灵活资源 |
| 石材/铁矿 | 升级+高级建筑 | 稀有瓶颈 |
| 幸福度 | 人口增长速度 | 增长乘数 |
| 知识 | 科技解锁 | 长期路线 |
| 军事经验 | 战斗力乘数 | 冲突资源 |

### 收集公式
```text
食物：村民转猎人/农民/渔夫 × 地块产出
木材：村民转伐木工 × 森林地块
克朗：商人 × 贸易路线
石材/铁矿：矿工 × 矿脉（有限矿量）
```

核心：所有收集 = 人口转职业，但职业转换有时间成本。

### 消耗公式
```text
冬天（周期审判）：
  食物消耗 × 2-3（供暖+生存）
  木材消耗 + 50%
  幸福度持续下降
  军事不能出征 → 无法扩张

扩张消耗：殖民新地块 = 大量食物一次性消耗
```

### 转化机制
```text
人口（有限）→ 分配到各职业 → 产出对应资源
  猎人产食物 vs 伐木工产木材 → 同一个村民不能同时做两件事
  冬天 → 所有产出效率下降 × 消耗上升 → 双倍压力

核心：转化率的季节性波动 = 玩家必须在秋天提前调整职业分布
```

### 节奏波形
```text
脉冲式（季节驱动）：
  春夏（扩张+采集）→ 秋天（储备调整）→ 冬天（生存审判）→ 结算幸存
  完整季节循环：6-10 分钟
  年循环：30-60 分钟
```

### 可迁移公式
```text
文明节奏的季节性：
  每个时代 = 一年
  春季（前1/3）：建设+扩张
  夏季（中1/3）：稳定产出
  秋季（后1/3）：预警出现+储备调整
  冬季（时代末）：时代危机审判
```

# Batch 1 总结：核心公式参数表

| 游戏 | 资源数 | 收集模式 | 消耗模式 | 节奏 | 核心公式 |
|------|--------|---------|---------|------|---------|
| Stacklands | ~20种卡 | 卡牌组合+计时 | 卡牌消失 | 脉冲 2-4min | 产出=卡A×卡B×时间 |
