# 自然/灵力科技线 — 设计规范

> 版本：v0.1-tests | 2026-07-23

---

## 设计决策

- **D-01**: 解锁驱动类型 = 随机蓝图选择
  - 来源：用户需求 + Against the Storm 参考
  - 理由：与 civil-game 的 roguelite 定位一致，每局不同体验

- **D-02**: 科技线深度 = 3层（阶段1→3）
  - 来源：用户需求
  - 理由：测试范围限定，完整版应扩展至10阶段

- **D-03**: 每阶段随机候选数 = 3选1（固定建筑+2个随机候选）
  - 来源：Against the Storm 蓝图模式
  - 理由：固定建筑保证底线，随机候选创造差异。3选1比2选1更有选择感但不过载

- **D-04**: 风格基调 = 自然灵力（图腾崇拜+生态共生混合）
  - 来源：用户需求 + 推断
  - 理由：部落阶段的自然信仰自然过渡到定居阶段的系统化祭祀

- **D-05**: 建筑命名规范 = 自然意象命名（非工业/机械术语）
  - 例：灵泉（非"水井"）、风语塔（非"瞭望塔"）、祖灵图腾（非"纪念碑"）

## 约束

- 所有建筑必须属于五职能之一且**仅一个主职能**（DR-C-022）
- 建筑=能力载体，不产出可累积资源（DR-C-015）
- 不使用回合/行动点，时间约束用"冷却/建造时间"表达（DR-C-028）
- 必须包含火种补充机制（K-07 火种驱动约束）
- 每阶段至少覆盖 3 项职能

## 5 项 Timeline 分岔保障

| 保障 | 本 timeline | 对比其他timeline |
|------|------------|-----------------|
| 专属建筑 | 灵泉、祖灵图腾、风语塔 | 军事timeline：兵营、铁匠铺、城墙 |
| 专属科技名 | 通灵仪式、大祈雨术 | 军事timeline：锻造术、骑兵冲锋 |
| 不同的初始资源偏好 | 关注灵脉分布 | 军事timeline：关注矿脉分布 |
| 专属事件池 | 动物迁徙、瘟疫、旱灾预警 | 军事timeline：外敌入侵、内部叛乱 |
| 不同的终局状态 | 与自然共生=文明永续 | 军事timeline：征服=版图统一 |

## 选择理由

选择随机蓝图而非固定科技树：civil-game 的核心乐趣之一是"每局不同"，随机蓝图模式天然支持这一点。固定建筑（每阶段1个）保证底线体验，随机候选保证重玩差异。
